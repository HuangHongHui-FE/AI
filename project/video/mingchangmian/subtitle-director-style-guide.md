# 动态字幕导演风格库

> 6 种视觉风格 + ASS 实现技法 + 节奏编排策略。用于搞笑/名场面类视频的解说字幕制作。

---

## 一、核心原则

1. **相邻不重复**：同一风格不在连续两段出现，强制视觉变化
2. **位置随构图**：不固定底部居中，根据画面留白区和主体位置动态摆放
3. **大小随语气**：吐槽小号带呼吸感，咆哮大号撑满安全区，内心戏微小若蚊蝇
4. **进出有节奏**：快节奏弹射出现，慢节奏幽幽浮现，与视频情绪同步

---

## 二、六大风格详解

### 🟩 风格A — 暴躁吐槽弹幕风

**适用**：快节奏吐槽、弹幕式短评

| 属性 | 值 |
|---|---|
| 字体 | 黑体 Bold（SimHei） |
| 字号 | 画面高度的 4-5%（约 44px @1080p） |
| 字色 | 亮黄 `#FFD700`，1px 黑色描边 |
| 位置 | 画面中上部（y: 180-280），水平居中偏左 |
| 入场 | `\move` 从右侧屏外飞入到目标位置，350ms |
| 退场 | `\fad(100,250)` 快速淡出 |
| 停留 | 1-2 秒，无多余动效 |

**ASS 实现**：
```
{\an5\pos(midX, y)\move(W+200, y, midX, y, 0, 350)\fad(100, 250)}文案
```

**变体技巧**：连续多段弹幕时，y 坐标 ±60px 错开避免重叠；可调整飞入速度（200ms=极快，500ms=稍缓）。

---

### 🟧 风格B — 夸张综艺花字风

**适用**：高能梗点、名场面标注、需要视觉冲击的强调

| 属性 | 值 |
|---|---|
| 字体 | 黑体 Bold（SimHei），超粗 |
| 字号 | 画面高度的 7-9%（约 76-90px @1080p） |
| 字色 | 多色渐变：粉(`#FFD744`)、橙(`#FFA21F`)、黄(`#FFAA0E`) 轮换 |
| 描边 | 白色 4px + 深色投影 3px |
| 位置 | 画面正中或主角手势/头顶旁，灵活 |
| 入场 | **逐字弹入**：每个字独立 Dialogue，间隔 60ms 错时出现 |
| 退场 | `\fad(0,300)` 快速淡出 |

**ASS 实现（逐字拆分）**：
```
// 伪代码：每字一行，x 递增偏移，startTime 递增 60ms
chars.forEach((ch, i) => {
  x = centerX - totalWidth/2 + i * charWidth;
  start = baseStart + i * 0.06;
  {\an5\pos(x, y)\fad(80, 300)\fs76\b1\1c&H<color>&\bord4\shad3}<ch>
});
```

**注意事项**：
- 中文每字约 70px 宽（76px 字号），据此计算整体居中偏移
- 标点符号可跳过或合并到前一字
- 字数 > 6 时考虑分两行，行距 90px

---

### 🟦 风格C — 阴险内心OS风

**适用**：内心戏、小声吐槽、反转铺垫

| 属性 | 值 |
|---|---|
| 字体 | 楷体斜体（KaiTi），纤细 |
| 字号 | 画面高度的 2.5-3%（约 26-28px @1080p） |
| 字色 | 半透明白 `&H66FFFFFF&`（约 40% 不透明） |
| 描边 | 无 |
| 位置 | 画面左上/右上角（x: 180 或 W-180，y: 100-200） |
| 入场 | `\fad(600, 0)` 缓慢淡入 |
| 退场 | `\fad(0, 800)` 缓慢淡出 |
| 动画 | `\move` 缓慢上飘 40px，模拟"想法气泡冒出" |

**ASS 实现**：
```
{\an5\pos(x, startY)\move(x, startY, x, startY-40, 400, durationMs)\fad(600, 800)\fs26\1c&H66FFFFFF&\bord0\shad0}文案
```

**位置规则**：偶数段放左侧、奇数段放右侧；连续内心OS时 y 坐标 ±50px 错开。

---

### 🟪 风格D — 复古故障/Glitch风

**适用**：节奏突变、荒诞梗、错愕瞬间

| 属性 | 值 |
|---|---|
| 字体 | 黑体 Bold（SimHei） |
| 字号 | 画面高度的 5-6%（约 56-64px @1080p） |
| 字色 | 纯白 `#FFFFFF` |
| 位置 | 画面中下部（y: 560-640），水平居中 |
| 入场 | `\fad(50, 0)` 极快闪入（模拟 3 帧闪白） |
| 退场 | `\fad(0, 100)` 快速消失 |
| 特效 | **色散分离**：3 层副本错位叠加 |

**ASS 实现（三层色散）**：
```
// 第1层 — 白色主体（最清晰）
{\an5\pos(cx, y)\fad(50, 100)\fs64\b1\1c&HFFFFFF&}文案

// 第2层 — 洋红偏移 +3px 右，半透明（延迟 30ms）
{\an5\pos(cx+3, y)\fad(30, 80)\fs64\b1\1c&HCC55CC&\alpha&H88&}文案

// 第3层 — 青橙偏移 -2px 左，半透明（延迟 60ms）
{\an5\pos(cx-2, y+1)\fad(30, 100)\fs64\b1\1c&HFF8844&\alpha&H99&}文案
```

**注意事项**：
- 三层 startTime 各延迟 30-60ms，制造色散残影
- 可额外加一层黑色半透明底条（`\bord0\3c&H66000000&\bord` 宽边框充当背景）
- 故障文本宜短（≤ 6 字），太长看不清

---

### 🟥 风格E — 咆哮崩溃大字风

**适用**：情绪爆发、笑点高潮、终极强调

| 属性 | 值 |
|---|---|
| 字体 | 黑体 Bold（SimHei），最粗 |
| 字号 | 画面高度的 10-12%（约 110-130px @1080p） |
| 字色 | 炸裂橙红 `#FF3333`（`&H003333FF&`） |
| 描边 | 白色 6px + 深色阴影 5px |
| 位置 | 画面正中偏上（y: 380-440） |
| 入场 | `\fad(30, 0)` 瞬间出现 |
| 退场 | `\fad(0, 150)` 快速消失 |
| 特效 | **震动**：4 层微偏移副本，间隔 60ms 交替出现 |

**ASS 实现（四帧震动）**：
```
// 震动层 x4（不同偏移量，快速交替）
shakes = [{dx:0,dy:0}, {dx:6,dy:-4}, {dx:-4,dy:3}, {dx:3,dy:-2}];
// 每层间隔 60ms，每层持续约 200ms

// 主层（叠加在所有震动层之上，最清晰）
{\an5\pos(cx, cy)\fad(80, 200)\fs112\b1\1c&H003535FF&\bord6\shad5}文案
```

**注意事项**：
- 字号极大，文案必须短（≤ 6 字），否则溢出画面
- 震动偏移量控制在 6px 以内，太大会晕
- 咆哮段之间至少隔 2 段其他风格，保持冲击力稀缺

---

### 🟨 风格F — 文艺冷幽默风

**适用**：反衬搞笑、正经解说伪装、首尾呼应

| 属性 | 值 |
|---|---|
| 字体 | 思源宋体（NotoSerifSC-VF），极细 |
| 字号 | 画面高度的 3%（约 32-36px @1080p） |
| 字色 | 暖白/香槟金 `#F5F0E7`（`&H00E7F0F5&`） |
| 描边 | 无 |
| 位置 | 画面下方黄金分割线（y: 680-740），水平居中 |
| 入场 | `\fad(1200, 0)` 极长淡入模拟墨迹洇开 |
| 退场 | `\fad(0, 1500)` 极长淡出模拟柔光溶解 |

**ASS 实现**：
```
{\an5\pos(cx±80, y)\fad(1200, 1500)\fs32\1c&H00E7F0F5&\bord0\shad0\fnNotoSerif SC}文案
```

**变体技巧**：
- 偶数段 x 偏左 80px，奇数段 x 偏右 80px
- 如需竖排，用 `\frz-90` 旋转，配合 `\pos` 调整至画面左侧或右侧
- 可叠加 ffmpeg `noise` 滤镜模拟旧电影颗粒（见第五章）

## 三、节奏编排策略

### 3.1 基本节奏公式

```
引入期（0-20%）：文艺F + 内心OS C 为主，建立调性
升温期（20-50%）：弹幕A + 综艺B 交替，节奏加快
爆发期（50-80%）：咆哮E + 故障D + 综艺B 轮换，高密度冲击
收尾期（80-100%）：文艺F + 弹幕A，呼应开头
```

### 3.2 风格使用频率建议

| 风格 | 占比 | 最短间隔 | 适用场景 |
|---|---|---|---|
| A 弹幕 | 25% | 1 段 | 填充过渡、快速吐槽 |
| B 综艺 | 20% | 2 段 | 高能标注、名场面点名 |
| C 内心OS | 15% | 1 段 | 铺垫、反转前兆 |
| D 故障 | 10% | 3 段 | 荒诞瞬间、节奏突变 |
| E 咆哮 | 15% | 3 段 | 情绪顶点、笑点高潮 |
| F 文艺 | 15% | 2 段 | 开场、收尾、反差幽默 |

### 3.3 禁止组合

- 综艺 B → 综艺 B（连续花字审美疲劳）
- 咆哮 E → 咆哮 E（冲击力稀释）
- 故障 D 连续出现（混乱感叠加）

## 五、ASS 能力边界 & 替代方案

| 想要的效果 | ASS 能否实现 | 替代方案 |
|---|---|---|
| 粒子炸裂、碎开 | 否 | 改用 After Effects 或 Web Canvas 逐帧渲染 |
| 弹性缩放（0→150%→100%） | 否 | 用两行不同字号快速交替模拟"弹"感 |
| 真实呼吸缩放循环 | 否 | 跳过，或用两行字号差 2px 交替 |
| 逐字出现 | 是 | 拆成每字独立 Dialogue，stagger 60ms |
| 线性移动 | 是 | `\move` |
| 色散/Chromatic Aberration | 近似 | 3 层不同颜色副本，±3px 偏移 + `\alpha` 半透 |
| 震动/摇晃 | 近似 | 4 层微小偏移副本快速交替（60ms） |
| 淡入淡出 | 是 | `\fad` |
| 旋转 | 是 | `\frz`（仅 2D 平面旋转） |
| 墨迹洇开 | 近似 | 长 `\fad(1200,0)` 模拟缓慢浮现 |
| 打字机效果 | 近似 | 逐字拆分，每字比前一字延迟 40-60ms |
| 旧电影颗粒 | 是 | ffmpeg `noise=alls=2:allf=t` 滤镜 |
| 底部雾状渐变 | 是 | ffmpeg `geq` 生成渐变 PNG 叠加 |
| 不规则形状底框 | 否 | 用宽 `\bord` + `\3c` 模拟矩形底条 |

## 六、完整 Prompt 模板（One-Shot）

```
你是一个动态字幕导演。为这段 [视频类型] 添加解说字幕，严格遵守：

【风格规则】
从以下 6 种风格中为每段字幕选择最匹配的一种，相邻两段不重复：
- A 弹幕风：亮黄粗体 44px，右飞入急停→甩出，中上部
- B 综艺风：逐字弹入 76px，粉橙黄渐变，白描边+投影，居中灵活
- C 内心OS：楷体斜体 26px 半透白，淡入上飘，贴角落
- D 故障风：白字三层色散偏移 56px，快闪，中下部
- E 咆哮风：血红超粗 112px，四帧震动，正中
- F 文艺风：思源宋体 32px 暖白，极长淡入淡出，下方黄金线

【位置规则】
不固定底部居中。弹幕放中上，OS 放角落，咆哮放正中，文艺放下方，综艺跟主角。

【节奏规则】
0-20%引入→20-50%升温→50-80%爆发→80-100%收尾。
梗点用B/E，铺垫用C/F，过渡用A，荒诞用D。

先出文案+风格对照表，确认后生成 ASS 字幕烧录到视频。
```

## 七、文件模板（Node.js 生成脚本结构）

```javascript
// 1. 定义 6 种风格的 Dialogue 生成函数
function styleA_Danmaku(sub, i) { ... }
function styleB_Variety(sub, i) { ... }
function styleC_InnerOS(sub, i) { ... }
function styleD_Glitch(sub, i) { ... }
function styleE_Roar(sub, i) { ... }
function styleF_Literary(sub, i) { ... }

// 2. 定义字幕数据
const segments = [
  { start:0.0, end:2.5, style:'F', text:'...' },
  { start:2.5, end:4.5, style:'A', text:'...' },
  // ...
];

// 3. 生成 ASS + ffmpeg 烧录
const styleFns = { A: styleA_Danmaku, B: styleB_Variety, ... };
segments.forEach(sub => events += styleFns[sub.style](sub, i).join('\n'));
// → 写入 .ass → ffmpeg -vf ass=xxx.ass → 输出 mp4
```

> 完整可运行脚本参考 `process.js`（同目录）。
