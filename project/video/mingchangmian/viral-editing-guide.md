# 名场面视频爆款剪辑指南

> 目标：把素材剪成能在抖音/B站/视频号等平台跑出完播率和互动的爆款短视频。
> 配合现有工具链：`process.js`（ffmpeg + ASS 字幕）+ 6 种字幕风格库。

---

## 一、先搞清楚：平台在奖励什么

短视频平台不奖励"剪辑技术"，只奖励这三个指标，**按优先级排**：

| 指标 | 权重 | 含义 | 决定它的环节 |
|---|---|---|---|
| **完播率** | ★★★★★ | 多少人看完了全片 | 前 3 秒 + 节奏 + 长度 |
| **互动率** | ★★★★ | 点赞/评论/转发/收藏 | 情绪爆点 + 引导话术 |
| **关注转化** | ★★★ | 看完关注你 | 片尾钩子 + 账号定位 |

> **铁律**：前 3 秒没人划走，后面才有意义。所有剪辑决策都要先回答："前 3 秒观众凭什么不划？"

---

## 二、素材筛选标准（剪之前先过这一关）

不是所有"名场面"都能火。接到素材后先过 5 个筛选条件：

- [ ] **反差感强**：画面 / 台词 / 表演有明显的"意料之外"（圣剑=破烂、严肃=搞笑）
- [ ] **有情绪锚点**：能让人发笑、震惊、共情、想吐槽
- [ ] **3 秒内能看懂在讲什么**：观众没耐心看铺垫
- [ ] **有可截图/可做成表情包的瞬间**（这是二次传播的关键）
- [ ] **时长可控**：原始素材最好能剪到 **15–30 秒**，最长不超过 45 秒

> 不满足 ≥3 条的素材，建议放弃或拆成片段用，别硬剪。

---

## 三、黄金 4 段结构（剪辑骨架）

不管素材多长，**剪出来都要能套进这个结构**：

```
┌──────────┬──────────┬──────────┬──────────┐
│  钩子     │  铺垫     │  高潮     │  收尾    │
│ 0-3s     │ 3-8s     │ 8-18s    │ 18-25s   │
│ 留人      │ 制造期待   │ 情绪爆点  │ 引导互动  │
└──────────┴──────────┴──────────┴──────────┘
```

### 1. 钩子（0–3 秒）—— 不留人等于零

**做法**：把素材里**最炸的瞬间**剪到开头 0–3 秒，制造"我在看什么？"的悬念。

- 选画面：表情最夸张 / 动作最离谱 / 台词最反常的那 1–2 秒
- 配字幕：用 **🟥 咆哮风** 或 **🟪 故障风**（视觉冲击最强）
- 配音效：加一个"叮""咻"或重音，强化注意力

> ❌ 反例：开头先放片头 LOGO、先念旁白"今天给大家看一个…"。观众已经划走了。

### 2. 铺垫（3–8 秒）—— 制造"为什么会这样"

**做法**：倒叙或正叙交代背景，**让观众产生"接下来会发生什么"的期待**。

- 节奏：2–3 个短镜头切换，每个 1–1.5 秒
- 字幕：**🟩 弹幕风** 或 **🟦 内心 OS 风**（吐槽/解说感）
- 留白：在爆点前留 **0.3–0.5 秒静音或慢动作**，给观众"预感"的时间

### 3. 高潮（8–18 秒）—— 名场面本体

**做法**：这里才是真正的"名场面"，要给足画面和情绪。

- 放慢 / 重复：关键瞬间可以用 **0.5x 慢动作** 或 **重复 2–3 次**（参考综艺"回放"手法）
- 字幕：用 **🟧 综艺花字风** 逐字弹入，或 **🟥 咆哮风** 撑满
- 音效：爆点处加重音 boom、笑声罐头、或突然静音（反差）

### 4. 收尾（18–25 秒）—— 引导互动

**做法**：不要"自然结束"，要主动引导。

- 留个**未解的梗 / 开放式问题**（"如果是你会怎么做？"）
- 字幕：**🟨 文艺风** 收一下格调，或 **🟩 弹幕风** 直接喊"三连关注"
- **绝不要**拖到 40 秒以上还硬讲道理——观众已经划走了

## 四、镜头剪辑 6 招（提升信息密度）

| 招式 | 什么时候用 | 怎么做 |
|---|---|---|
| **快切** | 节奏快的段落（铺垫/钩子） | 每 0.5–1s 切一个镜头 |
| **慢放** | 爆点瞬间 | 0.3–0.5x，让观众看清表情 |
| **重复** | 高能瞬间（笑声/翻车） | 同一画面剪 2–3 次，每次配不同字幕 |
| **缩放推近** | 引导注意力到细节 | Ken Burns 效果，1.0→1.3x 缓推 |
| **静默/黑场** | 爆点前的"呼吸" | 0.3s 静音或切黑场，制造反差 |
| **反转/倒放** | 搞笑类素材 | 关键动作倒放，意外感强 |

> **ffmpeg 实现**（可直接加到 `process.js` 的 filter 里）：
> - 慢放：`setpts=2.0*PTS`
> - 缩放推近：`zoompan=z='min(zoom+0.0015,1.5)':d=125:s=1922x1080`
> - 反转：`reverse`（注意要先抽帧再合成，否则音频会错位）

## 五、字幕文案怎么写才有人互动

字幕不只是"翻译台词"，**是第二叙事层**。你的 6 风格库刚好对应不同情绪：

| 风格 | 文案怎么写 | 互动作用 |
|---|---|---|
| 🟩 A 弹幕 | 短促吐槽："就这？？""离谱开门了" | 共鸣 / 引发评论 |
| 🟧 B 综艺 | 强调梗点："名！场！面！""教科书翻车" | 强化记忆 / 截图传播 |
| 🟦 C 内心OS | 解读潜台词："细节全在眼神里" | 深度解读 / 引发讨论 |
| 🟪 D 故障 | 反常/无厘头："不对劲#@%" | 悬念 / 吸引停留 |
| 🟥 E 咆哮 | 情绪爆发："哈哈哈哈！！" | 感染情绪 / 点赞 |
| 🟨 F 文艺 | 总结升华："一帧一画皆是名场面" | 调性 / 关注转化 |

**文案 4 条铁律**：
1. **每句 ≤ 10 字**（手机竖屏一行能看完）
2. **不要念台词**，要吐槽/解读/玩梗（观众看得懂画面）
3. **用感叹号、问号、省略号** 制造语气，不用句号
4. **相邻段不重复风格**（你已经在 `process.js` 里这么做了，继续保持）

## 六、音效与配乐（70% 的"爽感"来自这里）

### BGM 选曲原则
- **节奏卡点**：选有明确鼓点的（电子、Trap、Dubstep 优先）
- **情绪匹配**：搞笑用轻松/荒诞曲，高能用史诗感
- **音量**：人声 -5dB，BGM -20dB 以下，**别盖过台词**
- **长度**：BGM 的高潮点要对齐视频高潮（通常在第 8–10 秒）

### 卡点音效清单（必备素材包）
| 音效 | 用在 |
|---|---|
| Whoosh（咻） | 镜头快速切换 |
| Impact（boom 重音） | 爆点瞬间 |
| Ding（叮） | 注意力钩子 |
| Record scratch（唱片刮擦） | 反转/尴尬瞬间 |
| Laugh track（罐头笑声） | 搞笑点 |
| Heartbeat（心跳） | 悬念铺垫 |

> **ffmpeg 加音轨**：`ffmpeg -i video.mp4 -i sfx.mp3 -filter_complex "[1:a]adelay=8000|8000[sfx];[0:a][sfx]amix=inputs=2" -c:v copy out.mp4`

## 七、平台适配（一条素材出 N 个版本）

不同平台完播曲线差异巨大，**同一素材要剪不同版本**：

| 平台 | 比例 | 时长 | 节奏 | 文案重点 |
|---|---|---|---|---|
| **抖音** | 9:16 竖屏 | 15–25s | 极快，前 1.5 秒定生死 | 短平快，吐槽式字幕 |
| **快手** | 9:16 竖屏 | 15–30s | 稍慢，重视"接地气" | 口语化，多玩梗 |
| **视频号** | 9:16 竖屏 | 20–40s | 中速，受众偏大龄 | 字幕要大，少用网梗 |
| **B站** | 16:9 横屏 | 30–60s | 可铺陈，重视内容 | 弹幕梗，深度解读 |
| **小红书** | 9:16 / 3:4 | 15–30s | 中速，重颜值 | 标题党，封面美 |

**实操**：原始 16:9 素材，用 ffmpeg 一键转竖屏 + 居中裁剪：
```
ffmpeg -i input.mp4 -vf "crop=ih*9/16:ih, scale=1080:1920" vertical.mp4
```
（注意：如果名场面的主体不在画面中央，要手动调 crop 偏移）

## 八、封面 + 标题（决定了多少人来点开）

> **封面和标题决定了点击率，点击率 × 完播率 = 推荐量**。再好的视频没人点也白搭。

### 封面公式（3 选 1）
1. **情绪特写 + 大字**：人物最夸张表情 + 一行 ≤6 字大字幕
2. **对比图**：上下/左右分屏，"以为的 vs 实际的"
3. **疑问脸 + 文字**：角色懵逼表情 + "？？？" 或 "这合理吗"

### 标题模板（替换填空）
- 「**[角色] [反常行为]，[网友反应]**」
  → 例：「圣剑登场就这？网友笑疯了」
- 「**当 [情境]，[结果]**」
  → 例：「当导演认真拍搞笑片，全程名场面」
- 「**[数字] 个 [领域] 名场面，[情绪]**」
  → 例：「3 个动画名场面，看一次笑一次」

**标题禁忌**：
- ❌ 别用句号结尾
- ❌ 别超过 25 字（手机显示不全）
- ❌ 别标题党到货不对板（平台会限流）

## 九、完整工作流（结合你现有的 `process.js`）

拿到一个新名场面素材后，按这个顺序走：

### Step 1 · 看素材 + 标记爆点（10 分钟）
- 全速看 1 遍，用纸笔/笔记记下 **3–5 个"高能时间点"**
- 选出**前 3 秒钩子**用哪个瞬间

### Step 2 · 写文案分镜（15 分钟）
- 打开 `copywriting.md`，套用现有表格格式
- 每段填：时间 / 风格（A–F）/ 文案 / 位置 / 动画
- **强制约束**：总段数 ≤ 8 段，相邻不重复风格

### Step 3 · 同步到 `process.js`（5 分钟）
- 把 `segments` 数组（`process.js:183`）改成新的文案
- 改 `inputFile` / `outputFile` 变量
- 确认 `VIDEO_W` / `VIDEO_H` 与素材一致

### Step 4 · 处理素材本体（可选，按需）
- 裁剪到目标时长（`-ss` / `-to`）
- 转竖屏（见第七节命令）
- 加慢放/反转（见第四节命令）

### Step 5 · 跑脚本（2 分钟）
```bash
node process.js
```
- 生成 `subtitles.ass`
- 烧录成 `xxx-动态字幕导演版.mp4`

### Step 6 · 加 BGM + 音效（5 分钟）
- 用剪映 / Premiere / DaVinci 二次处理（可视化更准）
- 或用 ffmpeg 加音轨（见第六节命令）

### Step 7 · 出封面 + 写标题（10 分钟）
- 从视频里截一帧最炸的（`ffmpeg -i video.mp4 -ss 00:00:08 -vframes 1 cover.jpg`）
- 加大字（用 Canva / 醒图 / PS）
- 套标题模板

### Step 8 · 平台发布
- 按第七节，**每个平台单独发适配版本**（不要一个横屏发所有平台）
- 发布后 1 小时盯完播率，<30% 说明开头钩子不行，下次改

## 十、发布前自检清单

剪完之后，发布前一条条过：

- [ ] 前 3 秒有没有"凭什么不划"的钩子？
- [ ] 总时长 ≤ 30 秒？（竖屏平台）
- [ ] 字幕字号在手机上能看清？（不小于画面高度 4%）
- [ ] 相邻段字幕风格不重复？
- [ ] 爆点处有没有音效/慢放强化？
- [ ] BGM 没盖过人声？
- [ ] 封面有没有大字 + 情绪？
- [ ] 标题 ≤ 25 字、没句号、有钩子？
- [ ] 竖屏版本主体在画面中央？（不被裁掉）
- [ ] 片尾有没有引导互动/关注？

> 全部打勾再发。任何一条不过，先改。

## 附：参考指标（自己对照）

发完一周后看数据，对照下面的基准判断片子是否"合格"：

| 指标 | 合格线 | 爆款线 |
|---|---|---|
| 完播率（竖屏） | ≥ 35% | ≥ 55% |
| 点赞率 | ≥ 3% | ≥ 8% |
| 评论率 | ≥ 0.5% | ≥ 2% |
| 关注转化 | ≥ 1% | ≥ 3% |

> 达不到"合格线"的片子，回头分析是**钩子** / **节奏** / **封面** 哪一环出了问题，下次针对性改。
