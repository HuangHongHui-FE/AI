### 选名原则（对照番茄热门作者生态）

1. **2-4 字为主**，好记、好搜、不打错。
2. **不撞大神**：避开三九音域/燕北/杀虫队队员/弈青锋/妖夜等现役名字。
3. **记忆点 > 华丽**：读者要点「追更」能记住你，市井反差、数字意境都比堆砌形容词强。
4. **有「爽」的气质**：硬、利、狠、烟火气，贴合都市逆袭调性。
5. 定稿前在**番茄作家助手 App** 搜一下确认没被占用。

## 二、作者签名（个人简介）写法

番茄作者签名特点：**20-50 字**，三要素：

```
【招牌句/调性】+【写什么】+【更新承诺】
```

- **写什么**：都市逆袭爽文 / 战神神豪 / 普通人翻身
- **更新承诺**：日更两更 / 从不拖更 / 量大管饱（番茄读者极看重更新稳定性）
- **招牌句**（可选）：一句有辨识度的话当记忆点

> 反面教材：只写「大家好我是作者，希望大家喜欢我的书」——没有记忆点、没有承诺，读者划走就忘。
