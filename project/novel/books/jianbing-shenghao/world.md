# 世界观：摊煎饼的我，签到成了神豪

## 一句话世界观

> 一座三四线县城「平安县」，一条烟火气十足的夜市街。主角在夜市摆煎饼摊，靠着「签到系统」在规则之内一步步把小摊做成全县第一，带动整条街、整个县城逆袭。

## 空间设定

- **平安县**：三四线县城，老城区+新城区。主角摆摊在「朝阳路夜市」（本地人口中"夜市一条街"）。
- **夜市一条街**：煎饼摊、烧烤摊、糖葫芦、水果摊、奶茶铺……市井烟火核心区。主角的煎饼摊叫「陈记煎饼」。
- **新城区**：商业街、写字楼，张少家的拆迁产业、县城新贵聚集地。
- **老城区**：陈默家和陈妈的缝纫铺所在，人情味重、街坊熟人。

## 力量体系（本作无超自然武力，靠财富/商业/人情规则破局）

| 层级 | 说明 |
|---|---|
| 摊贩圈 | 夜市摆摊的小老板们，主角起点的世界 |
| 县城新贵 | 拆迁户、开发商、餐饮连锁老板（张少、包工头、餐饮老板） |
| 县城龙头 | 本地餐饮集团、商会、隐藏大人物（后期解锁） |
| 县外势力 | 上市餐饮资本、网红MCN、连锁品牌（中后期卷进来） |

## 系统规则（金手指的「规矩」——核心爽点来源）

1. **每日签到**：每天 0 点后可签到一次，奖励随机（现金/技能/物品/人脉/商机）。
2. **唯一铁律：所有奖励只能在「规矩之内」使用**。系统会随机给每次奖励附加限制：
   - **地域锁**：钱只能花在平安县 / 只能花在朝阳路夜市
   - **用途锁**：只能买指定类别（食材/设备/房子/请客/捐款）
   - **对象锁**：只能花给特定的人（如卖糖葫芦的哑叔、环卫工）
   - **时效锁**：当天必须花完
3. **越守规矩，奖励越离谱**：老老实实按限制花，第二天签到升级；违规乱花，系统沉默/惩罚。
4. **规矩是枷锁也是商机**：主角靠「被迫花在特定地方」反而盘活整条街——谁被系统选中当花销对象，谁就沾光，成为主角的铁杆。

> 设计意图：这条「规矩锁」就是神豪县城流爆款公式（《每天六千万，只能在县城花?》90万在读）的核心——钱必须有去处、必须有意义、必须落地在具体的人和地方，逼出剧情的烟火气。

## 本作基调

轻松幽默、烟火气、反内卷。打脸爽快但不越界，主角靠合法商业/人情/头脑碾压。系统奖励「又爽又离谱」但永远在规矩内。
