# 全篇剧情蓝图：摊煎饼的我，签到成了神豪

> 本文件是全书剧情总纲。**每章必须对照本蓝图 + `history.md`（剧情进度）来写**：蓝图定「这章干什么」，history 记「已写什么/伏笔在哪」。写下一章时先读两者，保证剧情不断档、伏笔不漏收。
> 章节标题为建议，写时可微调，但剧情节点不变。

## 主线

> 被裁程序员陈默回县城夜市摆煎饼摊，靠「签到系统」在规矩之内滚雪球——从夜市小摊做到全县第一煎饼品牌，带动整条朝阳路、整个平安县逆袭，最后打脸所有看不起他的人，成为县城传奇。
> **核心主题：小人物在规则内优雅破局，烟火气里的英雄主义。**

## 全书节奏

- 每 3 章至少 1 个完整打脸闭环（反派先踩 → 主角亮底牌 → 围观震惊 → 反派失态）
- 每章 ≥1 个落地爽点 + 章尾钩子
- 系统签到是章尾钩子常客（「明天签到的奖励，会是什么？」）

### 夜市立身·下（21-40章）
- **21**《入会》：陈默入商会，见识县城餐饮格局 → 商会内派系暗流（张老三也是一派）→ 钩子：商会会长对陈默说「你这煎饼摊，动了很多人的蛋糕」。

- **24**《小人物的大厂底牌》：陈默的架构师底子终于用上——给合作社搭数字化结算系统（自己写代码），摊贩们叹为观止 → 效率翻倍 → 钩子：资本方派来谈判的人，发现陈默写代码的手速后愣住了。
- **25**《冷库之争》：陈默盘下一处旧冷库改冷链中心 → 张老三抢先使坏（恶意抬价/找房东施压）→ 陈默用对象锁「绑定冷库周边环卫工家庭」+合作社筹款拿下 → 钩子：冷库交接那天，有人发现冷库墙角藏着一条旧保险柜的线索。
- **26**《旧保险柜》：保险柜里是一套「老县城餐饮老字号」的配方账簿（几十年前平安县餐饮协会的）→ 陈默顺着查，牵出老字号背后的往事 → 钩子：账簿上有一个名字，和张老三他爹有关。
- **27**《老字号之谜》：陈默调查发现，几十年前县里老字号「宝和堂」因一场恶性竞争倒闭，疑似被张老三家族联手做局 → 历史真相线展开 → 钩子：账簿某页被撕，关键证据缺失。
- **28**《张老三的急》：陈默摸到老字号线索，张老三坐不住了，亲自约陈默「喝茶」→ 表面示好、暗中威胁（你妈在县城过得安稳，不想她出什么事吧）→ 陈默第一次真正动怒 → 钩子：陈默说「张总，这梁子，我记下了」。
- **29**《护住家人》：陈默给陈妈/陈静安排守护（系统奖励安保+搬离老宅线索区）→ 兄妹谈心，陈静第一次知道哥哥这些年扛的事 → 钩子：陈静说「哥，我帮你查，我在学校能查档案」。
- **30**《档案》：陈静通过县教育局档案，查到当年老字号倒闭的关键文件（土地批文异常）→ 张老三家族疑似用不正当手段拿到宝和堂地块 → 钩子：证据还差一环，张老三已经察觉陈静在查。
- **31**《张老三动手》：张老三派人盯上陈静，制造学校教学事故（污蔑陈静体罚学生）想把她赶出县一中 → 陈默怒极，第一次用「规矩外的手段」也不行，必须合法反击 → 钩子：陈默动用合作社+商会+县里王主任三方力量护妹。
- **32**《护妹之战》：陈默借「视频+证据+舆论」澄清陈静被诬陷，施压方灰溜溜撤诉道歉 → 陈静转正，兄妹感情线升级 → 钩子：张老三第一次在县城公开场合被当众打脸，颜面扫地。
- **33**《反击的号角》：陈默决定正面刚张老三家族 → 从「老字号账簿」切入，联合当年宝和堂后人，准备翻案 → 钩子：商会内部开始站队，县城暗流汹涌。
- **34**《当年的一顿饭》：宝和堂后人回忆当年细节：张老三父亲设鸿门宴逼宝和堂老掌柜签字 → 关键证人浮出（当年饭店一个跑堂，如今县城养老院老人）→ 钩子：跑堂老人提出一个条件。
- **35**《养老院条件》：老人条件：要陈默把「宝和堂」的招牌，在县城重新立起来 → 陈默答应 → 钩子：老人拿出一张泛黄的照片，照片背后是当年土地转让协议的复印件一角。
- **36**《双线并进》：陈默一边查证（补全土地证据链），一边筹备「宝和堂」老字号复兴（用签到系统，规矩内合法复刻老配方）→ 张老三开始反扑（买通养老院想抢证人）→ 钩子：证人突然失联。
- **37**《证人失联》：陈默查证人下落，发现被张老三软禁在县城某处 → 合法渠道（报警+媒体）+合作社力量救出证人 → 钩子：证人手里还有一张关键底牌没亮。
- **38**《关键底牌》：证人交出当年张老三父亲签名的土地转让补充协议（涉嫌伪造公章）→ 证据链补齐 → 钩子：张老三狗急跳墙，决定最后一搏。
- **39**《狗急跳墙》：张老三用最后一招：举报陈默「食品安全/偷税」+ 放火烧冷库的暗示 → 陈默借直播+合作社+县里督查自证清白 → 反手把伪造公章证据移交 → 钩子：县里成立专案组，开始查张老三家族。
- **40**《卷末·第一桌饭》：张老三家族被查（虽不至于立即倒，但金鼎项目黄了、张少被限制消费）→ 陈默在「宝和堂」旧址重开老字号，第一桌饭请全街摊贩+宝和堂后人+证人 → 卷末大高潮：夜市改造项目落地，朝阳路成县城名片 → 钩子：卷末彩蛋，系统弹出「第二卷·县城风云」新任务，奖励与「平安县餐饮商会」息息相关。

## 第二卷 · 县城风云（第41-80章）

**阶段目标**：从夜市摊主，做成县城餐饮新贵，陈记成为平安县第一品牌。

### 阶段锚点（每10章一个高潮，写前细化）
- **41-50 品牌立县**：注册「陈记煎饼」品牌+门店化扩张 → 系统签到升级「县界锁」（奖励只能花在平安县内，倒逼深耕本地）→ 张老三余党（铁算盘刘经理）投靠陈默当「财务副手」反向效忠 → 50章高潮：陈记三店同开，平安县新贵名单上出现「陈默」。
