# 热点自动发文 Skill（主流程 · 入口）

> 项目根目录：`/Users/zcy1/code_self/AI/project/wechat-img`
> 调用方式：用户说「写热点文章」「今天发」「来一波热点」之类，Claude 抓榜展示，**用户自己从热榜选热点**，然后找图、生成、推草稿——**选热点是用户，找图后须用户再确认图片**，写完自查 AI 痕迹与微信规范
> 本文件是**入口串接器**，只写总纲（触发 + 执行原则 + 低创作度红线）+ 步骤链清单。各步骤细节拆分到独立 skill 文件，按需查阅。

## 触发条件

用户说「写热点文章」「今天发热点」「来几篇热点」「发一波」之类，要的是**当下实时热点**，不是用户指定主题。

**执行原则**：触发后**不再问任何澄清问题**，直接跑——抓榜 → **①等用户选热点（中途停手点）** → 去重检查 → 找图 → **②用户确认图片（第二个停手点）** → 生成 → 自查 → 推草稿 → 写日志。中途的模糊判断（标题怎么起、CTA 选哪类、哪张图更贴、时段怎么排）自己定。**两个停手点：选热点等用户拍板、找图后等用户确认图**，不自己跳过；除非真正阻塞（接口全挂、所有图都下不下来），才停下来报告。

## ⚠️ 低创作度规避红线（对照微信官方《低创作度案例解析》2026-07-18）

2026-07-16 一批文章被微信判低创作度停推。微信官方把低创作度分四类（见 `mp.weixin.qq.com/s/SF41klqVOhHbMLZT_3PspQ` 官方案例解析），我的旧流程踩中三类，逐类对照规避：

**一、同质化**（官方案例：①重复发表②框架一致——结构完全一致套固定格式+短期大量发表）。**踩坑**：旧标题全「XX，我X了」、正文全六段+每段引言+每段加粗+讲真收口，25+篇同框架。**规避**：标题不得「我X了」收尾；禁六段全套模板，三件套（编号小标题+每段引言+每段加粗）至多用两件；**每篇结构+排版 theme 须与近 5 篇不同形**（短期多篇套同一框架=同质化铁证）。

**二、疑似抄袭搬运**（官方：大篇幅复述、机械拼接洗稿、不含个人观点分析增量）。**规避**：不能只「热点复述+套话感悟」机械拼接，每篇须有**个人观点/分析增量**——对事件有自己的判断、类比、追问，而非照搬新闻+套情绪词。

**三、低信息量**（官方：简单拼凑无意义、图文无关/看图说话、引用存疑数据、无依据夸大）。**踩坑**：旧文全文情绪议论零事实。**规避**：每篇 ≥3 条可查证事实（人名/数字/时间/地点/引语），选点后先 curl 抓新闻正文补事实；**内文图须与正文强相关、图说明有信息增量，非看图说话**；引用数据须有出处、不夸大。

**四、低价值 AIGC**（官方反面：直接用 AI 生成原文不改；正面：AI 辅助但融入大量个人经验和思考，非照搬 AI 生成）。**踩坑**：旧文是 Claude 直接生成批量制造。**规避**：每篇须**融入个人经验/思考增量**（具体生活场景、亲历类比、独到判断），而非照搬 AI 生成的套话；口头禅（讲真/我愣了/看懵了/咋说呢/说白了/笑归笑等）跨篇去重，一周不重复，每篇记日志。

**总则**：不过关的回炉重写或弃写，**不为凑数推残次品**。短期多篇同框架、AI 套话批量、零事实情绪文，是三大死穴，任一命中即判低创作度。

## 执行流程（步骤链）

按顺序跑完整流程，各步骤细节见对应 skill 文件：

### ① 抓热榜 → [[01-hotlist]]
并行抓头条 / 百度 / 抖音 / B站 / 微博五榜，输出全榜（原样展示，标注跨榜重叠）。**知乎抓不到**（401），不补。

### ② 用户选热点（停手等用户拍板）
把五榜展示给用户，**用户自己挑要写的热点**（1~N 个），Claude 不自动选。用户选定后，做**精简检查**（不再自动选题，只挡写不了的）：
- **历史已写过的不写**：扫 `logs/*.md` 的「话题」列 + `grep -h` 候选热点的人名/事件名/地名，语义重复即提醒用户换一个
- **适性过滤**（只挡写不出的）：游戏版本/充值活动、纯政策口号、纯国际战况简报——提醒用户这类写不出中年叙事
- **时政外交红线**：涉政治人物评价、未审案件定性的，提醒用户换角度或弃写
- 极火爆跨多平台热点若历史写过，可提醒用户「可换角度再写一篇」

### ③ 找图 + 用户确认 → [[02-find-image]]
按热点原词实体批量找图（`--batch` ≥20 张），下载到 `input/` → **把候选图清单给用户确认（第二个停手点）** → 用户删图后只用删剩图，封面用「主图」那张。

### ④ 抓正文取事实 → [[03-fetch-facts]]
curl 搜狗新闻→必应→百度 m 站多源兜底链，摘出人名/数字/时间/地点/原话，**每篇 ≥3 条可查证事实**。

### ⑤ 写作维度轮换 → [[04-writing-pools]]
先跑 `node src/recent.js 5` 读近 5 篇已用维度喂 prompt；按账号定位 + 生成要求 + 标题贴原词 + 各轮换池（开头钩子/结构配方/叙事口吻/切入角度/段间衔接/CTA/格式池/收口方式）每篇随机抽、与近 5 篇不撞。

### ⑥ 生成 + 自查 + 推草稿 + 写日志 → [[05-generate-publish]]
生成 article.json（正文禁引封面文件）→ preflight.js 硬门 → 自查 A/B/C（不过回炉）→ 串行推草稿（禁并发）→ 写日志（字段格式不可变，recent.js 靠它解析）。
