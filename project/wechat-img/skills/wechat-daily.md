## 文章生成要求（必须遵守）

### 长度与结构
- 800-1200 字
- 用 `## 一` `## 二` `## 三` 分 **6 段**（不用 `###`）
- 段落长短交错（1-8 行穿插，不要都 3-5 行）
- 每段不超过 5 行

### 文字风格
- 像跟朋友聊天，多用短句少用长句
- 加 2-3 处生活化表达：「我们家那位」「我认识一对夫妻」「前段时间我一个朋友」
- 情感有「岁月感」——经历事情后的理解，不是年轻人热恋
- 不粉饰太平，不贩卖焦虑，复杂不非黑即白
- 细节代替说教

### 反 AI 味清单
- 删除：「值得注意的是」「总而言之」「此外」「综上所述」「在当今社会」「不仅...而且」「既...又...」
- 不要工整的排比和对仗
- 偶尔一段只有一句话；偶尔用省略号结尾
- 开头不用「在快节奏的现代社会中...」
- 标题要有故事感，不要 AI 味

### 标点与高亮
- 用 `**加粗**` 标 3-5 处情绪高点（自动渲染成橙色 + 底色高亮）
- 用 `> 引言` 标 1-2 处冲击力的金句（自动渲染成左色条引言块）
- 用 `---` 分隔章节（自动渲染成 `· · ·`）

### JSON 字段
```json
{
  "title": "≤22字，有钩子但不标题党",
  "digest": "≤54字摘要",
  "cover_slogan": "≤14字封面标语",
  "body_markdown": "正文 markdown",
  "cta_question": "具体到场景/对象/反应的互动提问",
  "cta_follow": "点 个 关 注 不 迷 路"
}
```

### CTA 提问模板（按文章主题选）
- **身份类**：被一句话戳穿「你也没多了不起」——是什么时候？
- **故事类**：你被谁的一句话，记了很多年？/ 你记忆里最深刻的一场 X，是哪场？/ 你有没有一手绝活，AI还学不会？
- **反应类**：被家人戳到时，你是回嘴还是憋着？
- **三选一类**：父母、伴侣、孩子，谁一句话让你记最久？

提问要扣住文章高潮，问具体时刻而不是有没有。详见下方「结尾 CTA 卡片」章节的选型规则。

## 结尾 CTA 卡片（必须按此结构生成）

文章正文结束后，自动追加一个 CTA 卡片。**结构固定，每次都这样**，只有「提问」和「关注引导」两个变量会变。

### 视觉结构（从上到下）

1. **容器**：渐变橙底（`#FFF4EC → #FFEEE0`）+ 圆角 10px + 浅橙描边（`#FFE0CC`）+ 内边距 22×20px + 居中文字
2. **标签**：白底圆角胶囊，文字「留 言 互 动」，橙色（`#FF6B35`），字号 12px，字间距 3px
3. **提问**（加粗深色，字号 16px，行高 1.6）：来自 `cta_question` 字段
4. **引导文字**（字号 14px，浅褐 `#7a4a2a`，行高 1.7）：「评论区聊聊，是哪句话戳穿了你？<br/>点赞 + 在看，让更多中年人看见。」
5. **分隔线**：浅橙色细线，宽度 60%，居中
6. **关注引导**（字号 13px，灰色）：「👇 长按关注，每天一篇中年人的心里话」
7. **关注按钮**：橙色渐变胶囊（`#FF6B35 → #FF9A6B`），白字加粗，字号 14px，字间距 2px，带橙色阴影。文字来自 `cta_follow` 字段，默认「点 个 关 注 不 迷 路」
8. **图标行**（字号 13px，灰色，字间距 4px）：「❤ 点赞 · 在看 · 转发」

### 为什么这个结构有效

- 标签 + 提问双层抓住注意力，标签像「彩蛋」让人想看下文
- 提问具体到场景/对象/反应（不是「你有没有过...」这种 yes/no 问题），读者脑子会自动浮现故事
- 引导文字明确告诉读者三个动作：评论、点赞、在看
- 「👇 长按关注」用 emoji + 具体动作，比「关注我」更有召唤力
- 渐变按钮是整页唯一的高饱和色块，视觉重心，引导点击
- 图标行最后兜底，给那些不想评论但愿意点赞的读者一个轻量动作出口

### CTA 提问选型规则

每篇文章的 `cta_question` 按主题选：

- **身份/自我认知类**（被戳穿、被定义、被替代）→ 用身份类提问
- **回忆/共鸣类**（看球、家乡、青春）→ 用故事类提问，问具体时刻
- **反应/冲突类**（被怼、被误解、被夸）→ 用反应类提问，问当时怎么回应
- **多方关系类**（家庭、职场）→ 用三选一类，给三个具体对象让读者选一个说

提问要扣住文章高潮那句话，问「是什么时候 / 是哪场 / 是哪一句」，不问「有没有」。

## 执行流程（每日 3 篇）

### 0. 预检查

```bash
ls input/    # 看有几张图、文件名是什么
```

确认图的张数和文件名。文件夹名直接用文件名（去 `.jpg`）。

### 1. 看图理解内容

对每张图用 `sharp.resize(900)` 生成预览版（原图可能太大 Read 不进来），再用 Read 工具看。

### 2. 生成文章 JSON

对每篇文章，按本 skill 要求生成 JSON，写到：
```
output/YYYY-MM-DD/NN-话题/article.json
```

**复用规则**：如果 `output/YYYY-MM-DD/NN-话题/article.json` 已存在且内容合理（用户没要求重写），直接复用，不重新生成。这在调试时频繁发生。

### 3. 并行推到草稿箱

**关键技巧**：3 篇可以**并行推送**——在一条消息里发 3 个 Bash 调用，会同时跑，节省等待时间。

```bash
cd C:/Users/31672/AI/project/wechat-img
node src/index.js --image "input/01-话题1.jpg" --out-dir "output/YYYY-MM-DD/01-话题1/"
node src/index.js --image "input/02-话题2.jpg" --out-dir "output/YYYY-MM-DD/02-话题2/"
node src/index.js --image "input/03-话题3.jpg" --out-dir "output/YYYY-MM-DD/03-话题3/"
```

每篇终端打印 `草稿 media_id` 后，该篇就在草稿箱。**记下 media_id 写日志要用。**

### 4. 写日志

更新 `logs/YYYY-MM-DD.md`，记录 3 篇的标题、话题、media_id、发布时段建议。

## 已知坑

1. **微信剥样式**：所有样式必须 `style="..."` 内联，`<style>` 和 class 会被剥光（已修）
2. **marked v12 签名**：`heading(text, level)` 不是 `{text, depth}`，改 renderer 要注意（已修）
3. **sharp 中文渲染**：依赖系统字体（微软雅黑），文字渲染失败会回退到无文字封面，不会让管线挂
4. **token 2 小时过期**：脚本自动缓存 `cache/token.json`，过期前 5 分钟刷新
5. **IP 白名单**：已配置 `124.90.104.29`，换网络环境跑不动时去公众号后台「基本配置 → IP 白名单」加新 IP
6. **中文路径 cp 报错**：Windows 上 `cp src dst` 含中文路径会失败，改用 `cd` 进目录后 `mkdir -p 文件夹名 && cp 文件 文件夹/`，或直接用 Write 工具写文件
7. **大图 Read 失败**：原图太大 Read 不进来，先用 `sharp.resize(900).jpeg({quality:75})` 生成预览版
