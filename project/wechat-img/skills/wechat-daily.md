# 微信公众号每日 N 篇贴图发文 Skill

> 项目根目录：`C:\Users\31672\AI\project\wechat-img`
> 调用方式：用户在会话里给 1~N 个主题（纯文本，不放图），Claude 自己搜图、下载到 `input/`、生成文章 JSON、跑脚本推到草稿箱

---

## 触发条件

用户说「帮我生成对应文章」「发几篇」「今天发」之类，并直接在会话里给了若干个主题文字（1 个、2 个、3 个都行，不再要求预先放图，也不强制 3 个）。

示例：
- 用户发「给你一个主题：吴艳妮女子100米栏夺冠」→ 生成 1 篇
- 用户发「给你三个主题：1、吴艳妮夺冠。2、F1奥地利一练。3、陈妤颉百米夺冠」→ 生成 3 篇

文件命名约定：`NN-话题.jpg`（如 `01-吴艳妮女子100米栏夺冠.jpg`），按用户给的顺序从 `01` 开始编号。**话题直接从用户消息里取，不让用户重复说一遍。** 篇数 = 用户给的主题数。

**执行原则（重要）**：用户提供主题之后，**不要再问任何澄清问题**，直接按本 skill 完整流程跑完——搜图、下载、看图、生成 article.json、推草稿、写日志。中途遇到模糊判断（标题怎么起、CTA 选哪类、时段怎么排、哪张图更贴主题）自己定，不要回头问用户。除非遇到真正的阻塞错误（API 调不通、所有候选图都下不下来等），才停下来报告。

## 文章生成要求（必须遵守）

### 长度与结构（重点：去模板化，否则被判低价值AIGC）
- 800-1200 字（下限 800 必须达到，用具体细节/对话/场景/事实铺开，不堆废话）
- **不再强制 6 段 `## 一/二/三`**。结构灵活：2-6 段均可，可用 `##` 副标题（副标题要有内容，不能是「一/二/三」），也可不分小标题纯自然段。**每篇结构须与近 5 篇不同形**——别篇篇一个模子。
- **禁止「六段全套模板」同时出现**：`## 一~六` 六段 + 每段一个 `>` 引言 + 每段一句 `**加粗**` + 第六段「我跟家里念叨」+ 结尾「讲真，XX——XXX」收口。这套被微信判定为低价值 AIGC/同质化的铁证（2026-07-16 实测账号被限推荐）。三件套（编号小标题 + 每段引言 + 每段加粗）至多用两件，结尾不得每篇「讲真」收口。
- 段落长短不均（1-8 行穿插，至少 1 段只 1-2 句、1 段 6-8 行），不要每段等长——等长是 AI 痕迹。

### 文字风格
- 像跟朋友聊天，多用短句少用长句
- 加 2-3 处生活化表达：「我们家那位」「我认识一对夫妻」「前段时间我一个朋友」
- 情感有「岁月感」——经历事情后的理解，不是年轻人热恋
- 不粉饰太平，不贩卖焦虑，复杂不非黑即白
- 细节代替说教

### 事实增量（必做，否则判低信息量）
- **先介绍热点，再写感悟**（2026-07-18 用户明确纠正）：文章开头 1-2 段必须把热点事件讲清楚——什么事、涉及谁、何时何地、经过、结果、为何重要。**不能上来就「我」的感悟**。自我感悟放在事实介绍之后，占比 ≤ 事实介绍。旧文「刷到条消息→我愣了→我琢磨」三段全情绪、零事件介绍，是反面教材。
- **每篇 ≥ 3 条可查证事实**：具体人名 / 数字 / 时间 / 地点 / 当事人原话。少于 3 条不合格重写。
- **事实/资料占比 ≥ 情绪议论**。不能全篇「我有点小激动」「我们这代人太熟了」这类空洞抒情，必须有实打实的信息点支撑。
- 热点文章尤须先 curl 抓新闻正文补事实（见 [[hotspot-publish]]「抓正文取事实」步骤），不能只靠榜单标题脑补感受。例：写「纯国产卡训出万亿模型」须答出哪家公司、卡型号、模型名、参数量、耗时、对标国外哪档——答不出说明事实没抓够，别发。

### 内文插图（2026-07-18 新增，热点文章必备）
- 除头图外，**正文中段加 2-3 张热点相关图**（现场图/人物图/数据图/对比图/剧照图），打破纯文字长文、增强信息量。
- 找图时多下 2-3 张到 `input/NN-话题-内图1.jpg` 等，在 `body_markdown` 里用 markdown 图片语法标记插入位置：`![图说明](input/NN-话题-内图1.jpg)`。
- `src/index.js` 会自动扫描 body 里的本地图片路径、上传为微信正文图 URL、替换路径后渲染（见下方「内文图上传」）。Claude 只管在 body 里写图片标记，上传由脚本处理。
- 图说明用一句具体说明（「重庆垮塌救援现场」「茅台出厂线」），不要空 alt。

### 展现形式多样化（2026-07-21 新增，提信息密度、破纯文字）
- 每篇至少用 1 种「非纯文字段落」展现形式，替代部分文字、增层次。可选（不固定，按热点选最合适的）：
  - **表格**：人物对照、多方观点、方案对比、数据罗列。例：悼念原话对照表、各方立场表。
  - **有序列表**：时间线、事件经过步骤、排行情理。例：人物生平节点、事件演变节点。
  - **无序列表**：要点、并列现象、清单。例：几个关键信号、几种常见误区。
  - **对照块**：用表格或并列段落做「A vs B」对比。
  - **emoji 箭头流程**：用 `→` 连接的文字流程（微信正文不渲染 mermaid 流程图，别用代码块画图，会被当乱码）。
- `src/html.js` 已给 table/th/td/ul/ol/li 注入内联样式（配色跟 theme），微信正文显示有边框、有缩进，直接写 markdown 即可。
- **禁忌**：不为了用而用——表格只列 2-3 项硬塞就没意义；列表项至少 3 个才用。展现形式是替文字提密度，不是凑数。

### 格式元素随机组合（强制,2026-07-21）
正文不能只写纯文字,太单调被判低信息量。**能用就用,不限制一篇文章用多少种、每种用多少次,只要合理**——格式是替文字提密度增层次,合理就上,不用省着。组合跨篇轮换(与近 5 篇不撞,记日志「格式组合」列)。

**微信正文可用 md 格式池**（标准 + GFM + 自定义扩展,`src/html.js` 全支持）：

| 格式 | 语法 | 渲染 | 用法 |
|---|---|---|---|
| 副标题 | `## 标题` | 主题色条+标题 | 章节切换,标题要有内容 |
| 加粗 | `**文字**` | 主题色+渐变底 | 强调重点 |
| 加粗斜体 | `***文字***` | 加粗+斜体组合 | 强调中的强调 |
| 斜体 | `*文字*` | 真 italic+muted | 轻度点睛 |
| 背景高亮 | `==文字==` | 主题浅底+主题色字 | 关键词标亮 |
| 删除线 | `~~文字~~` | 删除线灰字 | 转折/否定 |
| 行内代码 | `` `文字` `` | 灰底圆角等宽 | 关键词/术语标记 |
| 上标 | `^文字^` | 上标小字 | 公式/注脚式标注 |
| 引用块 | `> 文字` | 浅底+左色条 | 金句/原话 |
| 分隔线 | `---` | `· · ·` | 章节切换 |
| 有序列表 | `1. ` | 数字序号 | 时间线/步骤/排行 |
| 无序列表 | `- ` | 圆点 | 要点/并列/清单 |
| 表格 | `\| a \| b \|` | 主题色边框 | 对照/对比/数据 |
| 图片 | `![说明](url)` | 图+说明 | 内文图 2-3 张 |
| 内联HTML | `<span style="color:...">` | 自定义颜色/背景 | 需特定颜色时 |
| 提示框 callout | `:::warning 文字 :::` | 彩色边框+浅底 | 注意/警示(4 色:info/tip/warning/danger) |
| 时间线节点 | `:::time 1936 内容 :::` | 左色条+年份加粗 | 人物/事件年表 |
| 数据卡片 | `:::stat 89岁 说明 :::` | 大字数值+小字说明 | 关键数据凸显 |
| 引语署名 | `:::quote 原话 \| 署名 :::` | 引用块+署名落款 | 名人/当事人原话 |
| emoji shortcode | `:fire:` `:warn:` | emoji 字符 | 点缀(也可直接写 emoji 字符 ❤) |

**微信正文真不可用（技术限制,加了也不渲染,用了会乱码,别用）**：
- 链接 `[文字](url)` / 自动链接 `<>` — 微信屏蔽非白名单外链变纯文本
- 任务列表 `- [ ]` — checkbox 不渲染
- 脚注 `[^1]` — marked 不支持 + 微信不渲染
- 下标 `~text~` — 与删除线 `~~` 冲突,不实现
- 数学公式 `$...$` — 微信不跑 JS,不渲染
- mermaid 流程图 — 微信不跑 JS,不渲染
- 锚点/目录 `[TOC]` — 不渲染

**规则**：
- **能用就用,不限种数不限次数,只要合理**——新规(2026-07-21 放开旧「4-6 种」上限)。
- 唯一硬约束:**三件套**(编号小标题 + 每段引言 + 每段加粗)**至多用两件**,不得三件全上；**禁六段全套**。
- 跨篇轮换:格式组合与近 5 篇不撞(记日志)。
- 配色全跟 theme(加粗/高亮/色条/边框/卡片),callout 四色是固定语义色(不跟 theme)。
- `src/html.js` 已支持全部可用格式(em 真斜体 / `==高亮==` / `:::callout/time/stat/quote` / `^上标^` / `:emoji:` / 表格列表内联样式 / span 透传 / 删除线 / 行内 code)。

### 主题升华（强制,2026-07-21，破「没内涵」）
- **每篇必有升华段（不少于 3 句）**——从具体热点拔到普遍/历史/时代意义,给文章内涵。无升华段 = 没内涵 = 低信息量,弃写回炉。由 Claude 根据热点总结,不固定角度,可选：
  - 历史纵深：这事在更长的时间线里是什么位置（一代人凋零 / 一个时代转折 / 周期轮回）。
  - 普遍命题：这事戳中的人性 / 社会普遍命题（信任 / 代际 / 利益 / 体面）。
  - 结构观察：这事背后是什么结构性问题（制度 / 行业 / 代际 / 城乡）。
  - 类比拔高：跟历史上同类事对照，说清它为什么不一样或一样。
- 升华 ≠ 个人情绪碎念，是对热点的深度提炼，要有判断有落点。**个人感受文字要少**（抽象情绪议论占比 ≤ 30%），用具体场景 + 升华替代空泛抒情。

### 科普增量（2026-07-21 新增,各种类型都行）
- 每篇根据热点尽量加一段相关科普——把热点背后的科学/健康/物理/机制讲明白,通俗讲,给读者信息增量和内涵。类型不限,按热点选合适的:
  - 健康/医学:食品卫生、疾病机制、养生辟谣（如切开西瓜为何细菌繁殖）
  - 科学/物理:光热电站聚光储热原理、微塑料、电磁辐射
  - 自然/生物:水晶兰为何无叶绿素、城市地下生态、鱼类如何进入下水道
  - 工程/技术:城市排水管网、桥梁结构、电动车电池
  - 社会/制度:庆典安全冗余、证券开户流程、法律定性
- **科普须有学科依据**（可查证的科学常识,非个人臆测）,用通俗讲法把「为什么」讲清楚。**生活常识 ≠ 科普**:「细菌会繁殖」是结论不算科普,「西瓜切开后果糖水分成温床,常温下细菌两小时翻倍」带原理才算。
- 不强求每篇都有（有的热点无科普空间）,但能加就加,科普是信息密度和内涵的硬增量,也常配表格/列表/图作展现形式。
- 科普段也纳入 C 段③自查:科普里的科学常识须可查证,不编造数据/原理。

除了「主题升华」和「科普增量」,每篇可按热点选其他维度结合,给文章更多内涵和增量。**能用就用,合理就上,不限维度数**——维度跟格式一样,跨篇轮换(与近 5 篇不撞,记日志「写作维度」列)。

- 维度跨篇轮换,与近 5 篇不撞（记日志「写作维度」列）。
- 维度内容也须过 C 段四类:历史数据/统计数据须可查证带来源,不编；观点判断要有落点不空泛。

### 反 AI 味清单
- 删除：「值得注意的是」「总而言之」「此外」「综上所述」「在当今社会」「不仅...而且」「既...又...」
- 不要工整的排比和对仗
- 偶尔一段只有一句话；偶尔用省略号结尾
- 开头不用「在快节奏的现代社会中...」
- 标题要有故事感，不要 AI 味
- **跨篇去重口头禅**（一周内不得重复使用同一个）：`讲真` `我说一句实在的` `我愣了` `看懵了` `咋说呢` `说白了` `我一琢磨` `我这心一下子` `笑归笑` `慌归慌` `乐归乐` `替他高兴` `说真的` `退一步说`。每篇用到的口头禅记进当日日志，下一篇避开。多篇重复同一口头禅 = 同质化铁证。
- **标题禁用「XX，我X了」句式**（看懵了/愣了下/笑了/慌了/乐了/有点小激动/看很久）——2026-07-16 被点名 6 篇标题全此格式。标题须含一个具体信息点（人名/数字/事件名）+ 轻钩子。

### 标点与高亮（去模板化）
- 用 `**加粗**` 标 2-4 处情绪高点（自动渲染成橙色 + 底色高亮），不必每段都加粗
- `> 引言` 选 0-1 处冲击力金句（不必每篇都有），**与编号小标题、每段加粗不同时出现**（三件套同时 = AI 痕迹）
- 用 `---` 分隔章节（自动渲染成 `· · ·`）

### CTA 提问类型（20 类随机轮换，2026-07-23 扩自四类）

原 4 类「按文章主题选」非随机，连发多篇易撞。现扩到 20 类随机轮换，每篇抽一种、与近 5 篇不撞、尽量贴主题、记日志。提问要扣住文章高潮，问具体时刻/场景而非有没有。

| # | 类型 | 骨架 | 示例 |
|---|---|---|---|
| 1 | 身份类 | 被戳穿/被定义——什么时候 | 被一句话戳穿「你也没多了不起」——是什么时候？ |
| 2 | 故事类 | 你记忆里最…的…是哪… | 你记忆里最深刻的一场告别，是哪场？ |
| 3 | 反应类 | 当时你是…还是… | 被家人戳到时，你是回嘴还是憋着？ |
| 4 | 三选一类 | A/B/C 谁让你… | 父母、伴侣、孩子，谁一句话让你记最久？ |
| 5 | 经历类 | 你有没有过… | 你有没有过一脚踩空才反应过来的时刻？ |
| 6 | 类比类 | 换你会怎么… | 换你开车出国半路车机黑屏，你会怎么办？ |

## 结尾 CTA 卡片（必须按此结构生成）

文章正文结束后，自动追加一个 CTA 卡片。**结构按 theme 分 2/3/4 层**（minimal 2 层 / cool 3 层 / warm 4 层），**标签、引导语、图标行文案按标题 hash 从文案池确定性轮换**（非每篇一字不差，破同质化），只有「提问」和「关注按钮文字」两个变量由文章字段指定。配色全跟 theme，按钮不再是固定橙。`src/html.js` 实现，详见该文件 `CTA_TAGS`/`CTA_MIDS`/`CTA_ICONS` 池。

### 视觉结构（从上到下）

> ⚠️ 以下为旧「全橙」规格的历史描述，保留作字段含义参考。实际配色随 theme（容器底=t.bg、标签色=t.accent、按钮=t.btnBg），文案随标题 hash 从池轮换，**以 `src/html.js` 的 `ctaBlock` 实现为准**。

1. **容器**：渐变橙底（`#FFF4EC → #FFEEE0`）+ 圆角 10px + 浅橙描边（`#FFE0CC`）+ 内边距 22×20px + 居中文字
2. **标签**：白底圆角胶囊，文字「留 言 互 动」，橙色（`#FF6B35`），字号 12px，字间距 3px
3. **提问**（加粗深色，字号 16px，行高 1.6）：来自 `cta_question` 字段
4. **引导文字**（字号 14px，浅褐 `#7a4a2a`，行高 1.7）：「评论区聊聊，是哪句话戳穿了你？<br/>点赞 + 在看，让更多人看见。」
5. **分隔线**：浅橙色细线，宽度 60%，居中
6. **关注引导**（字号 13px，灰色）：「👇 长按关注，每天一篇心里话」
7. **关注按钮**：橙色渐变胶囊（`#FF6B35 → #FF9A6B`），白字加粗，字号 14px，字间距 2px，带橙色阴影。文字来自 `cta_follow` 字段，默认「点 个 关 注 不 迷 路」
8. **图标行**（字号 13px，灰色，字间距 4px）：「❤ 点赞 · 在看 · 转发」

### 为什么这个结构有效

- 标签 + 提问双层抓住注意力，标签像「彩蛋」让人想看下文
- 提问具体到场景/对象/反应（不是「你有没有过...」这种 yes/no 问题），读者脑子会自动浮现故事
- 引导文字明确告诉读者三个动作：评论、点赞、在看
- 「👇 长按关注」用 emoji + 具体动作，比「关注我」更有召唤力
- 渐变按钮是整页唯一的高饱和色块，视觉重心，引导点击
- 图标行最后兜底，给那些不想评论但愿意点赞的读者一个轻量动作出口

- **身份/自我认知类**（被戳穿、被定义、被替代）→ 优先 身份类/反问类/判断类
- **回忆/共鸣类**（看球、家乡、青春）→ 优先 故事类/回忆类/共鸣类
- **反应/冲突类**（被怼、被误解、被夸）→ 优先 反应类/选择类/评价类

## 找图流程（用户只给主题，Claude 自己找图）

用户在会话里给若干个主题后，Claude 按以下步骤为每个主题找一张相关图、下载到 `input/NN-话题.jpg`：

### 1. 搜图（主策略：必应图片 async 接口 + curl）

**实跑验证过的工作路径**（WebSearch 工具在本环境实际不可用；**搜狗 `pic.sogou.com/pics` 及 napi 接口 2026-07-18 实测返 `forbid` 已失效；百度图片 acjson 返 `bfe_log_id` 被反爬拦**）。现用**必应图片 async 接口**最稳：

```bash
cd <项目根目录>
UA="Mozilla/5.0 (Macintosh; Intel Mac OS X 10_15) AppleWebKit/605.1.4 Mobile/15E148 Safari/604.1"
enc=$(python3 -c "import urllib.parse,sys;print(urllib.parse.quote(sys.argv[1]))" "主题词")
curl -s -m 12 -A "$UA" "https://cn.bing.com/images/async?q=$enc&first=1&count=35&mmasync=1" -o /tmp/bing.html
# 用 python 正则 re.findall(r'murl&quot;:&quot;([^&]+)&quot;', html) 取图URL，逐张 curl 下载 >30KB 留
```

URL 编码：主题里的中文要 `%E5%90%B4%E8%89%B3%E5%A6%AE` 这样编码。Bash 里 `python3 -c "import urllib.parse;print(urllib.parse.quote('吴艳妮 100米栏 夺冠'))"` 现编现用。

查询词建议：主题 + 「`夺冠`」「`图片`」「`高清`」之一，命中新闻图的概率高。

**备用源**（必应无结果或跑偏时）：360 图片 `https://image.so.com/j?q=<URL编码>&sn=0&pn=30`（json `list[].img`，但批量下几条后会封 IP 返「访问异常出错」HTML，单条可用）。

### 2. 下载到 input/

```bash
curl -sL --max-time 30 \
  -H "User-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/120.0.0.0 Safari/537.36" \
  -H "Referer: https://pic.sogou.com/" \
  "<候选URL>" -o "input/NN-话题.jpg" -w "HTTP:%{http_code} size:%{size_download}\n"
```

**验收标准**：
- HTTP 200
- 文件大小 > 30KB（小于这个一般是错误页或缩略图）
- 如果 curl 报 403/404 或文件过小，**立刻换下一个候选 URL 重试**，不要回头问用户

**防盗链处理**：新浪图床（`n.sinaimg.cn` / `k.sinaimg.cn`）有 Referer 校验，下不下来时把 Referer 换成 `https://www.sina.com.cn/` 或 `https://www.baidu.com/` 再试。网易 `dingyue.ws.126.net` 通常无防盗链。

### 3. 看图确认相关性

下载完后用 `sharp.resize(900)` 生成预览版（原图可能太大 Read 不进来），再 Read 看一眼：
- 图里出现的人/物/场景确实跟主题相关 → 通过，进入文章生成
- 图是 logo / 广告 / 完全无关的图 → 换下一个候选 URL 重下

**不要跳过这一步**——封面图是文章的门面，下错图等于车祸现场。

### 4. 找不到图怎么办

如果一个主题所有候选 URL 都下不下来（极少见），**不要停下来问用户**，按以下顺序兜底：
1. 改用 Bing 图片搜索（`https://cn.bing.com/images/search?q=<URL编码>`）——本环境 curl 能通，但要注意 Bing 有时会跑偏主题（曾把「吴艳妮」搜成 sparrow 鸟），需用 WebFetch 验证页面相关性
2. 改用 360 图片（`https://image.so.com/i?q=<URL编码>`）
3. 用 Unsplash 搜主题相关场景图（如田径 → `running track`、F1 → `formula 1 car`）作替代
4. 实在连替代图都找不到 → 这一篇跳过，在日志里标「未发（无图）」，另外两篇照常发

### 5. 并行优化

N 个主题可以**并行搜图 + 并行下载**——在一条消息里发 N 个 curl Bash 调用同时跑。看图必须串行（一次 Read 一张）。

## 已知坑

1. **微信剥样式**：所有样式必须 `style="..."` 内联，`<style>` 和 class 会被剥光（已修）
2. **marked v12 签名**：`heading(text, level)` 不是 `{text, depth}`，改 renderer 要注意（已修）
3. **sharp 中文渲染**：依赖系统字体（微软雅黑），文字渲染失败会回退到无文字封面，不会让管线挂
4. **token 2 小时过期**：脚本自动缓存 `cache/token.json`，过期前 5 分钟刷新
5. **IP 白名单**：已配置 `124.90.104.29`，换网络环境跑不动时去公众号后台「基本配置 → IP 白名单」加新 IP
6. **中文路径 cp 报错**：Windows 上 `cp src dst` 含中文路径会失败，改用 `cd` 进目录后 `mkdir -p 文件夹名 && cp 文件 文件夹/`，或直接用 Write 工具写文件
7. **大图 Read 失败**：原图太大 Read 不进来，先用 `sharp.resize(900).jpeg({quality:75})` 生成预览版
