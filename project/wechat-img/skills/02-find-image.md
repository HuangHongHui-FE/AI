# 找图 + 用户确认 Skill

> 项目根目录：`/Users/zcy1/code_self/AI/project/wechat-img`
> 调用方式：主流程 `[[00-hotspot-publish]]` / `[[00-wechat-daily]]` 选点/定题后，本 skill 负责为每个话题**批量找图（≥20 张，强相关，最新）**、下载到 `input/`、**把候选图给用户确认（全流程唯一中途停手点）**、按用户删剩的图定封面与内图
> **⭐ 标准流程（2026-08-29 用户确认固化）：所有找图一律走 `--batch` 批量（`find_img.cjs`），单张 `--wide`/`--news` 仅作备用兜底，不再手写 curl 搜图。** 四渠道（必应时间过滤 + 搜狗图库 + 头条挖图 + 360）已验证可用。
> 三硬性：**每热点 ≥20 张候选 · 跟热点整体相关（非侧写）· 最新（非旧图）**。封面比例硬裁 2.35:1、正文内图 2-3 张，规则见下。

## 批量找图（2026-08-28 升级，替代旧单张搜图）

> **为什么升级**：旧流程每次只下 1 张、关键词用热点侧写（「售楼处 签约」）会命中通用旧图（2019/2021 楼市场景图）、无时间过滤会混历史旧图——被用户点名不达标。现改为**一键批量下 ≥20 张**。

### 命令（首选）

```bash
node src/find_img.cjs --batch "<热点主体词>" "<热点事件词>" "input/YYYYMMDD-NN-话题/" [目标张数=20]
```

例：
```bash
# 房贷40年新政（主体=政策对象，事件=核心动作）
node src/find_img.cjs --batch "个人住房贷款" "期限延长40年" "input/20260828-04-房贷40年/" 20
# 突发事件（主体=地名/人名，事件=事件名）
node src/find_img.cjs --batch "西藏泥石流" "吉隆救援" "input/20260826-01-西藏泥石流/" 20
```

脚本自动执行（无需手写 curl）：
1. **多渠道候选**：必应时间过滤（近7天+近24h，翻5页）+ **搜狗图库**（`pic.sogou.com` 原图直链）+ **360** + **头条搜索挖图**（`byteimg` 图床免签，重试3次）四渠道全接
2. **必应时间过滤（主力保新）**：`qft=filterui:age-lt604800`（近7天）+ `age-lt86400`（近24h）双查询，翻 5 页，**URL 时间戳 >3 月前的旧图弃**
3. **强相关过滤（关键）**：主体词拆实体关键词（「IG战胜TT」→`[IG,TT]`），**多实体须全含**（对阵双方都在才算这场），防「TT 铁三车」单字误伤；标题/URL 含关键词才收，杜绝世界杯/无关图混入
4. **头像/签名图过滤**：`qb-profile`、`avatar`、`*-sign.toutiaoimg.com` 弃
5. **无日期戳的图库图弃**（防旧图/无关图混入），下载按文件头 sniff 转标准 JPEG（防 40137）
6. **编号 + 主图命名**：最宽（比例最大）一张固定为 `001-主图.jpg`（封面候选），其余 `002.jpg...`；生成 `manifest.md` 供用户删图
7. **分层补量到 20**：先下强相关（多实体全含）→ 不足下部分相关（含任一实体）→ 再下新闻图，尽力凑够目标

### 三硬性（每次必查）

| 硬性 | 要求 | 不达标后果 |
|------|------|-----------|
| **≥20 张** | 每热点至少下 20 张候选图；三热点并行时每篇也 ≥20 | 用户没得选，删图后封面/内图凑不齐 |
| **强相关** | 关键词必须用**热点整体**（主体+事件全称），**禁侧写词**（「消防救援」「售楼处 签约」这类部分内容/泛场景） | 下到通用示意图、非本次热点图 |
| **最新** | 图须是热点发生前后的新图，**旧图（明显早于热点发生日）剔除** | 2019 图配 2026 新政，读者一眼穿帮 |

> **侧写词 vs 热点整体的区别**（关键）：
> - ❌ 侧写：「房贷 售楼处 签约」（售楼处是房贷的侧面场景，不是热点本体）
> - ✅ 整体：「个人住房贷款 期限延长40年」（热点就是政策本身）

### 找不到图怎么办

批量失败（新闻图 + 图库 <20）时：
1. 换**更贴的事件词**重跑（`--batch "房贷40年" "新政"`），别用侧写词
2. 仍 <20 → **降到有几张用几张**，如实告知用户（「这热点图库就这些，xx 张都在这了」），不硬凑
3. 完全无图 → 走旧兜底链：必应图片搜索 → 360 图片 → Unsplash 场景图 → 都无则「未发（无图）」

## 下载验收标准（沿用既有硬门）

- **封面**：头图 `--wide`（宽/高≥1.6），封面固定裁 900×383（2.35:1），窄图 2.35:1 硬裁会切掉上下 40%+ 主体
- **>30KB**：小于这个是错误页/缩略图（批量脚本已内置 `downloadAsJpeg` 过滤 <30000 字节）
- **真实格式**：按文件头 sniff 识别 jpg/png/webp 统一转标准 JPEG——**假 jpg（PNG/WebP 后缀）会被微信 40137 拒**（脚本已内置）
- **正文图 <10MB、JPG**
- **正文禁引封面文件**（`src/index.js` 硬拦截，撞了 exit 1）：正文首图必须用 `002.jpg` 等内图，不能用 `001-主图.jpg`

---

## ① 用户先确认图片（必做，2026-08-27 固化）

批量下完后**先停手，把候选图清单展示给用户确认**，不能直接写文章推草稿。给用户的清单要带**内容标注**（每张图的文件名 + 尺寸/宽窄 + Vision 识别的内容摘要 + 建议用途封面/内图），让用户看得懂、选得动。**用户明确说「继续/你选」或确认某几张后，才按剩余图写 article.json 发草稿；删图/换图前停手等用户确认，不自己决定跳过。** 具体事件当事人照片搜不到的（撞名/无公开照），如实告知用户换主题明确的场景图或换热点，不硬凑。

## ② 只用用户删完剩下的图，禁止补图/搜图（必做，2026-08-27 固化）

用户确认后，**只用热点对应文件夹里删剩下的图，有几张用几张**——一张就只用它做封面（正文不配图或用同一张），两张就封面+一张内图，三张就封面+两张内图，以此类推。**发文章过程中绝不自己再找图、补图、重下、换图**（删图 bug、搜不到图都不去补，用现有图写）。若只剩 1 张，正文就不插内图（或仅用该张避免重复），不强行凑图数。

## ③ 带「主图」字样的图 = 主体/封面图（必做，2026-08-27 固化）

用户删图后会把留下的封面图命名为「主图」或「XX-主图」（文件名含"主图"）。**`--image` 封面一律用文件名含「主图」的那张**；其余删剩图按文件名顺序做正文内图。若没找到「主图」，用删剩图里比例最宽的一张做封面（仍不补图）。

---

## 正文内图规则

- **正文内图一律用内图文件（`002.jpg`、`003.jpg`...），严禁在 body_markdown 里引用封面文件 `001-主图.jpg`**——封面已由 `--image` 自动用作封面，正文再引=封面与开局首图重复，2026-08-10 三篇全踩。
- 内文图 2-3 张，从删剩图里选**与对应段落强相关**的（现场/人物/数据/对比），图说明（alt）只写图中确实可见的内容 + 该段文字焦点，禁止编造图中没有的元素。
- 批量下的图里可能含长图（政策解读长图、数据图），适合做内图；封面务必用宽图（`001-主图` 已是按比例最大挑的）。

## 已知坑

1. **搜狗新闻正文配图多为缩略图**（218×160 级），做不了封面，只能当内图补充；「最新」主力靠必应时间过滤（`age-lt604800/86400`），不是搜狗新闻。
2. **360 图片批量下会封 IP**：批量脚本已内置 0.4-0.5s 间隔 + Referer 防盗链，触「访问异常出错」即停 360 换必应，别手写 curl 猛下。
3. **必应时间过滤不严格**：`age-lt86400` 仍会混入旧图（`20240517` 等），必须靠 `urlFresh` URL 时间戳过滤 + 无日期戳图弃双重保险。
4. **新浪图床防盗链**：`n.sinaimg.cn`/`k.sinaimg.cn` 有 Referer 校验，批量脚本已带 Referer；若某图下不下来，换下一张，别卡住。
5. **假 jpg 格式**：`.jpg` 后缀实为 PNG/WebP 会被微信 40137 拒，批量脚本已按文件头 sniff 转标准 JPEG。
6. **单字实体误伤**（2026-08-29 IG 实测）：主体词「IG战胜TT」拆出 `[IG,TT]`，「TT」在电竞=战队、在铁三/自行车=TT 车（`ysroad.co.jp TTバイク`），只含单实体会被误判相关。**必须多实体全含判断**——标题须同时含 IG+TT 才算这场，铁三车（只含 TT）自动过滤。
7. **头条搜索不稳定**：`so.toutiao.com` 约 1/3 请求返全量含图、2/3 返无图 stub，脚本已重试 3 次合并；图床 `byteimg` 免签可下但须传头条系 Referer（传 bing 会 403），`*-sign.toutiaoimg.com` 需签名弃。
8. **抖音/微博/百度图片不可用**（2026-08-29 确认）：抖音搜索要 a_bogus 签名、微博全部 302 访客系统、百度 acjson 反爬——**不投入**，电竞/热点的图靠必应+搜狗图库+360+头条四渠道够用。

## 不要做

- 不用侧写词搜（「消防救援」「售楼处 签约」→ 下到通用示意图）
- 不混入旧图（URL 时间戳 >3 月前 / 无日期戳的图库图，弃）
- 不在用户确认前直接写文推草稿
- 不自己补图/重下/换图（用户确认删完后，有几张用几张）
- 不编造图说明里没有的元素（不确定就写泛的「现场」「剧照」）
