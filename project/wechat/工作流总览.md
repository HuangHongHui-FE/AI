## 每日操作 SOP

### 前一天晚上 / 当天早上 — Claude 做（你 0 分钟）

Claude 自动完成：
1. 搜索对标账号近 3 天爆款
2. 拆解爆款结构
3. 生成 10 个选题卡（含评分）
4. **自动选取总分最高的 4 个选题**
5. 输出选题卡到 `今日选题卡.md`
6. **自动生成 4 篇文章初稿（去 AI 味）**
7. **自动完成排版参数**
8. **自动下载配图（从 Pexels，当天去重）**
9. **自动上传图片到微信 CDN + 创建草稿到后台**

### 你任何时候有空 — 审核（12 分钟）

通读 4 篇成品文章，每篇 3 分钟：
- 标题满意吗？
- 读起来像人写的吗？
- 情绪到位吗？
- 有需要改的地方标注出来，Claude 秒改

### 发布时段 — 你做（8 分钟）

分别在 7:30、12:00、18:30、21:30 发布：
1. 打开订阅号助手 App
2. 草稿箱找到文章
3. 预览确认
4. 点发布

> Claude 已经通过 API 把图片上传微信 CDN + 创建草稿，你的后台草稿箱里直接就有排版好的文章。

**全天你的总投入：12 + 8 = 20 分钟。**

## 技术栈（已验证）

| 环节 | 工具 | 备注 |
|------|------|------|
| 选题搜索 | WebSearch + WebFetch | 多角度搜索，覆盖微信/微博/知乎 |
| 文章 HTML 生成 | Node.js | 组装排版 HTML，嵌入配图 URL |
| 图片下载 | Node.js → Pexels CDN | `images.pexels.com/photos/{id}/` 格式稳定，需预收集photo ID |
| 图片上传 | curl → 微信 API | `/media/uploadimg`（文中图）+ `/material/add_material`（封面） |
| 草稿创建 | Node.js 生成 JSON + curl POST | 用 curl 发 JSON（Node.js HTTPS 在 Windows 上有时返回空） |
| 凭证管理 | `.env` 文件 | 已 `.gitignore`，不会泄露 |
| 发布 | 订阅号助手 App | 微信不支持 API 群发 |

### 踩过的坑

1. **Bash 不认中文路径** → 用 Windows 绝对路径 `C:/Users/...`
2. **Node.js https.request 返回空** → 改用 curl 发送 JSON
3. **Python pip 不可用** → 改用 Node.js（v18 自带，无需安装包）
4. **Token 2小时过期** → 每次操作前刷新
5. **IP 白名单** → 后台加了 `124.90.104.29`
6. **未认证订阅号无 AppSecret** → 已完成微信认证
7. **Unsplash source.unsplash.com 已废弃** → 改用 Pexels CDN（`images.pexels.com/photos/{id}/`）
8. **placehold.co 返回SVG非JPEG** → 微信封面API拒绝SVG（40007），封面必须从Pexels下载真JPEG
9. **curl 处理重定向不稳定** → 图片下载优先用 Node.js `https.get` 手动跟随重定向
