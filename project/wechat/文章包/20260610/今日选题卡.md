### 选题 ① ｜ 推荐指数：⭐⭐⭐⭐⭐

**标题**：同事离职请客吃饭，桌上8个人，只有我没被敬酒
**备选标题**（5个）：
1. 同事离职请客吃饭，桌上8个人，只有我没被敬酒
2. 那顿散伙饭，我一个人喝了七杯，没人敬我
3. 在公司干了三年，连顿体面的散伙饭都换不来
4. 离职那天我才知道，有些同事根本不配叫朋友
5. 饭桌上最安静的那个人，往往是最值钱的

**选题角度**：从一个尴尬的职场社交场景切入，揭示职场人际关系的真相——真正的关系不在酒桌上，而在你离开后谁还记得你。

**目标人群**：25-35岁职场白领，尤其是性格内向、不善社交的技术/专业型人才。

**情绪钩子**：尴尬 + 共鸣 + 反转（后来发现不敬酒的人反而帮了最大的忙）

**文章结构概要**：
  - 引入：同事离职请大家吃饭，席间每个人都被敬酒感谢，唯独跳过了"我"
  - 第1节：反思自己在公司的存在感——不参加团建、不拍马屁、只干活不说话
  - 第2节：三个月后，前同事群里有人创业找人合伙，是当初没敬酒的那个人发来的私信
  - 第3节：职场关系的真相——刷存在感不如刷专业度，酒桌上的热闹保质期只有三天
  - 结尾：留白式反问

**参考来源**：对标"职场人际关系""打工人社交焦虑"方向爆款

**差异化点**：不是写被排挤的委屈，而是写"安静也是一种竞争力"的反转视角

### 选题 ② ｜ 推荐指数：⭐⭐⭐⭐

**标题**：前同事的副业月入五万，然后他把主业的自己举报了
**备选标题**（5个）：
1. 前同事的副业月入五万，然后他把主业的自己举报了
2. 我终于理解了为什么公司禁止员工做副业
3. 副业做到工资的五倍那天，我反而更难过了
4. 当副业收入超过工资的时候，主业就变成了副业
5. "被开除"有时候是一种解脱

**选题角度**：从"副业焦虑"切入，但核心不是教人做副业，而是探讨"当你的价值不再被主业定义时，你会怎么重新认识自己"。

**目标人群**：28-38岁有副业想法或正在做副业的职场人。

**情绪钩子**：好奇 + 震撼 + 反思

**文章结构概要**：
  - 引入：前同事做副业（知识付费/咨询/内容创作），从月入3000做到50000
  - 第1节：主业的尴尬——白天开着无聊的会，手机上是客户的转账通知
  - 第2节：他把自己的副业"举报"给了公司（主动坦白违反竞业协议），逼公司开除自己
  - 第3节：自己被开除后反而轻松了——不是鼓励违法，而是反思"为什么我们不敢承认自己能做更大的事"
  - 结尾：戛然而止，留一个关于"安全感"的问题

**参考来源**：对标"副业"+"职场焦虑"+"自我价值"方向爆款

**差异化点**：不是写副业多赚钱，而是写副业成功后对主业的心理冲击

### 选题 ③ ｜ 推荐指数：⭐⭐⭐⭐

**标题**：35岁那年终于升了总监，但体检报告先到了
**备选标题**（5个）：
1. 35岁那年终于升了总监，但体检报告先到了
2. 拿到晋升通知的那周，我住了三天院
3. 身体用一份体检单告诉我：你不配加班了
4. 熬了八年熬到中层，我的甲状腺说"不行"
5. 升职加薪的那天，老婆说你的脸比工资条黄

**选题角度**：用"升职+体检"的反差制造张力，讨论职场人用健康换职位的真相。

**目标人群**：30-40岁职场中层/准中层，有健康焦虑的加班族。

**情绪钩子**：焦虑 + 共鸣 + 警醒（不贩卖焦虑，给具体的改变路径）

**文章结构概要**：
  - 引入：终于升了总监，HR发来聘用通知的同一天，体检中心打电话让复查
  - 第1节：回顾这八年的"拼命史"——通宵、外卖、咖啡续命、从不请假
  - 第2节：住院那三天想清楚的事——你倒下了公司三天就能找到替代者，但你家人三年都缓不过来
  - 第3节：后来的改变——学会"适度努力"，给自己设了三条边界
  - 结尾：温和收尾，不恐吓、不给建议，只说"我选择了另一种赢法"

**参考来源**：对标"健康焦虑+职场晋升"方向爆款

**差异化点**：不渲染恐惧，不做"保命警告"，而是写一个人主动选择慢下来的心路历程

### 选题 ④ ｜ 推荐指数：⭐⭐⭐⭐

**标题**：公司把工位缩小了一半，说这叫"开放式协作"
**备选标题**（5个）：
1. 公司把工位缩小了一半，说这叫"开放式协作"
2. 搬进新办公室那天，我和隔壁工位的人胳膊肘打架
3. 从独立办公室到共享长桌，我的尊严少了30公分
4. 那个只有60公分宽的工位，装不下一个中年人的体面
5. 工位越变越小，老板的车越换越大

**选题角度**：以"工位缩小"这个具象细节，写大厂/公司"降本增效"背景下普通员工的尊严流失。

**目标人群**：28-40岁在各类公司工作的职场人。

**情绪钩子**：荒诞 + 愤怒 + 共鸣

**文章结构概要**：
  - 引入：公司装修后工位从1.2米缩到0.6米，行政说这叫"敏捷办公"
  - 第1节：同事们的微型求生——有人自带显示器支架抢地盘，有人在消防通道打电话
  - 第2节：一个老员工在周会上说"能不能把工位恢复到原来大小"，领导回了句"你可以去楼下星巴克办公"
  - 第3节：工位缩小的背后——不是空间不够，是公司觉得你不配拥有空间
  - 结尾：荒诞感收尾，不说教，让读者自己品

**参考来源**：对标"打工人尊严""降本增效""大厂办公环境"话题

**差异化点**：不写宏大叙事，从"工位宽度"这个小切口写大情绪

### 选题 ⑤ ｜ 推荐指数：⭐⭐⭐

**标题**：在公司群发了辞职信之后，我先收到的是HR的私聊：撤回
**备选标题**（5个）：
1. 在公司群发了辞职信之后，我先收到的是HR的私聊：撤回
2. 离职群里发了一条消息，HR比我妈回得还快
3. 辞职信发到公司大群以后，老板让我解释"误会"
4. 所有体面的离职，从一条"请撤回"开始
5. 我那条没撤回的辞职信，炸出了七个想走的同事

**选题角度**：以"误发辞职信到公司群"为钩子，写职场中"体面"和"真实"的冲突——公司要体面，员工要真实，两者从来不在一条线上。

**目标人群**：25-35岁有离职想法但不敢行动的职场人。

**情绪钩子**：尴尬 + 荒诞 + 共鸣

**文章结构概要**：
  - 引入：本来要发到闺蜜群的辞职信吐槽，手滑发到了公司全员群
  - 第1节：撤回前的三分钟——各种私聊轰炸、领导的"方便电话吗"
  - 第2节：那封辞职信里写了什么——不是骂人，是一些"在职时不敢说的话"
  - 第3节：第二天去上班——气氛诡异，但意外收到几个同事的悄悄私信"你说出了我想说的"
  - 结尾：没有戏剧化辞职，而是"把发错的变成说对的"，温和但有态度

**参考来源**：对标"职场社死""辞职""职场真实"方向内容

**差异化点**：不写苦情辞职，写"手滑"制造的荒诞喜剧，轻松但有态度
