## 二、排版参数

| 参数 | 取值 | 说明 |
|------|------|------|
| 正文字号 | 15px | 适合中老年读者阅读，不过小不显大 |
| 行高 | 1.75 | 段落内行间距，保证阅读舒适度 |
| 字间距 | 0.5px | 略微拉开，避免文字粘连 |
| 页边距 | 16px | 左右留白，手机端阅读不拥挤 |
| 段间距 | 一个空行 | 段落之间留一行完整空行 |
| 章节标题字号 | 18px | 明显区别于正文 |
| 章节标题加粗 | bold | 视觉层次清晰 |
| 章节标题颜色 | #333333 | 深灰，不用纯黑 |
| 强调句颜色 | #FF6B35 | 暖橙色，温暖不刺眼 |
| 正文颜色 | #3e3e3e | 深灰，比纯黑柔和 |
| 两端对齐 | 是 | 微信图文标准做法 |
| 首行缩进 | 否 | 段间空行已足够区分段落 |

### 图片风格要求

- 整体色调偏暖（暖黄、暖橙、自然光）
- 人物图片选背影或侧脸，不露正面，保持代入感
- 避免摆拍感太强的商业图库照片
- 封面图不要配文字，干净留白
- 所有配图统一加 12px 圆角
