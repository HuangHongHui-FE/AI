### 选题 ① ｜ 推荐指数：⭐⭐⭐⭐⭐
**方向**：爱与夫妻关系

**标题**：结婚十五年我们一直AA制，直到他住院那天我看到了他的银行卡余额
**备选标题**（5个）：
1. 结婚十五年我们一直AA制，直到他住院那天我看到了他的银行卡余额
2. AA制婚姻的第15年，一张住院单打破了所有规则
3. 他手机里的银行App没设密码，我忍不住点开了
4. 中年夫妻最大的秘密不是出轨，是存款
5. 我以为我们只是各管各的钱，后来发现是各过各的日子

**选题角度**：从"AA制夫妻"切入，写婚姻中金钱观的冲突与和解。不是谁对谁错，是两个成年人终于学会把钱放在一起花。

**目标人群**：30-50岁已婚人群，尤其是经济独立的双职工夫妻。

**情绪钩子**：好奇 → 紧张 → 意外 → 温暖

**文章结构概要**：
  - 引入：结婚十五年一直AA，房贷一人一半、买菜轮流买单、孩子学费分摊。直到他突发阑尾炎住院
  - 第1节：帮他缴费时打开他手机银行——余额比我想象的少得多，转账记录里每月都有一笔钱打给他妈
  - 第2节：我坐在医院走廊想了很久——不是生气他瞒着我，是突然发现这么多年我们各管各的钱，也各藏各的难
  - 第3节：他出院后我们第一次坐下来谈钱——不是算账，是说出了各自不敢说的那部分
  - 结尾：留白，"那天下着小雨，我俩从银行出来，开了一个联名账户。十五年了，第一次。"

**参考来源**：对标"中年夫妻财务""AA制婚姻"话题爆款

**差异化点**：不写"AA制不好"，不写谁吃亏——写两个经济独立的人如何重新学会"一起"。

5. 镜子里的情敌：当老公爱上了他自己

**选题角度**：从"老公突然健身"这个常见猜忌场景切入，但反转不是出轨——是中年危机的一种温和表达。轻喜剧风格，不说教。

### 选题 ③ ｜ 推荐指数：⭐⭐⭐⭐

4. 别人婚礼上哭是因为感动，我们差点打起来
5. 为什么有些夫妻从不吵架，但孩子一离家就离婚

**选题角度**：从"从不吵架的夫妻"这个反常识切入，写压抑型婚姻在孩子离家后的真实爆发——不吵架不是恩爱，是没敢说真话。

**目标人群**：45-60岁，孩子刚离家/刚成家的中年夫妻。

**情绪钩子**：震惊 → 紧张 → 扎心 → 反思

**文章结构概要**：
  - 引入：女儿婚礼上一切都好好的，直到散场后我们在酒店大堂，为"谁忘了给男方父母敬茶"这个小事吵了起来
  - 第1节：那场架吵得很凶——不是这件事有多严重，是二十年没吵过的架都在等着这一天
  - 第2节：回放二十年的"相敬如宾"——不是没问题，是每次想说都被"算了算了"咽下去了
  - 第3节：女儿蜜月回来问我们怎么样了，我说"吵了三天，现在好了"——她笑了说"你们终于像正常夫妻了"
  - 结尾：循环呼应，"现在我们会为晚饭吃什么吵架了，吵完他去洗碗，我在沙发上刷剧。这才叫过日子。"

**差异化点**：不写"恩爱夫妻"的样板戏，写"从不吵架"背后的危险——真正的亲密不是相敬如宾，是敢吵架也敢和好。

**目标人群**：30-50岁夫妻，尤其是女方事业上升期的家庭。

**情绪钩子**：好奇 → 共鸣 → 心疼 → 希望

**文章结构概要**：

  - 第2节：我不是嫉妒她成功——我是怕我们的生活在朝两个方向跑，她的世界越来越大，我的世界还是那个工位
  - 第3节：某个周末她没拍视频，拉我去逛菜市场——像以前一样讨价还价、回家一起做饭。她说"我发现我做视频的时候很开心，但跟你在一起的时候才觉得安全"

**差异化点**：不写"女强男弱"的对立——写两个人在变化中找到新的平衡，现代夫妻的真实处境。

**备选标题**（5个）：
1. 跳槽涨薪40%以后，我发现自己开始羡慕那个月薪八千的实习生
2. 月薪从一万五涨到两万一，我的快乐从80分降到了60分

4. 拿到了想要的钱，失去了想要的生活
5. 那个拿八千块的年轻人，笑得比拿两万的我开心多了

**选题角度**：从"涨薪后反而失落"这个反直觉体验切入，写金钱和幸福感的非线性关系。不是教人降薪，是让人想清楚"你到底在用涨薪换什么"。

**目标人群**：28-40岁正在追求涨薪/跳槽的职场人。

**情绪钩子**：意外 → 共鸣 → 反思 → 释然

**文章结构概要**：
  - 引入：终于跳到了那家心心念念的大公司，薪资涨了40%，三个月后我在工位上打开老东家的群聊，看到那个实习生发的午饭照片，突然很难过
  - 第1节：新工作的真相——工资涨了，开会的时间翻了倍，午饭从一小时变成了十五分钟外卖
  - 第2节：那个实习生为什么让我羡慕——不是他钱多，是他还有期待、还有不会做的事、还有人愿意教他
  - 第3节：想清楚了一件事：涨薪的本质是用一部分自由换更多的钱，问题是你愿意换多少
  - 结尾："不是因为涨薪不值得，是涨了之后别忘了一件最重要的事——你是为了什么涨的。"

**差异化点**：不写"逃离大厂"的老套叙事，写一个还在职场中的人对"涨薪"的清醒反思。

### 选题 ⑥ ｜ 推荐指数：⭐⭐⭐⭐

2. 三年不参加公司聚餐的人，工资涨了三次
3. 团建时最安静的那个人，开会时声音最大——不是在饭桌上
4. 不社交的同事教会我一件事：职场上最好的关系是专业
5. 他把参加团建的时间用在了考证上，两年拿了三个证

**选题角度**：从"不参加团建"切入，写职场中"社交能力"和"专业能力"的资源配置问题——不是反社交，是反无效社交。

**目标人群**：25-38岁职场人，尤其是社恐/内向型人才。

**情绪钩子**：好奇 → 共鸣 → 启发 → 释然

**文章结构概要**：
  - 引入：公司团建名单上又少了他——三年了，从不参加。但上个月晋升名单上，他是唯一一个
  - 第1节：他不参加团建不是高冷——团建的时间他用来自学了Python、考了PMP、周末还跑半马
  - 第2节：他的"社交"方式——不是饭桌上敬酒，是跟跨部门的人合作项目、在技术论坛帮人解答问题、每次开会都准备充分
  - 第3节：转折——有一次一个大客户出问题，团建群没人回消息，他第一个在群里发了解決方案
  - 结尾：半截话，"后来我也不去团建了，不是因为学他，是发现那些热闹跟我们最后拿到的东西没什么关系。算了，你自己品吧。"

**差异化点**：不写"内向性格的鸡汤"，写具体的选择和结果——把社交时间花在专业上，不是自闭，是另一种投资策略。

5. 删掉硬盘里三十二年的资料只需要三秒，但脑子里那些画面永远删不掉了

**选题角度**：从"退休删文件"这个仪式感场景切入，写一个普通人的职业生涯终章——不是高光回顾，是那些没人看见的小瞬间构成了三十二年。

**目标人群**：45-60岁临近退休的职场人，以及想提前感受"职业生涯终点"的年轻人。

**情绪钩子**：感伤 → 共鸣 → 释然 → 温暖

**文章结构概要**：
  - 引入：退休前一天在工位上删文件，三十二年的资料三秒清空。然后点开了入职第一天收到的那封邮件
  - 第1节：那封邮件只有三行字：欢迎加入，你的工位在三楼，明天八点半到。落款是一个已经去世了的HR的名字
  - 第2节：三十二年里换过五个领导、搬过四次办公室、经历过三次裁员——都没裁到我，不是因为优秀，是因为运气
  - 第3节：带不走的东西——用了十五年的水杯，抽屉里过期的茶叶，还有窗台上那盆被同事养活的绿萝
  - 结尾：画面定格，"下班铃响的时候，我跟往常一样打卡、坐电梯、出大门。只是这次没回头。"

**差异化点**：不写职业成就，不写告别演讲——写一个普通人的安静退场，每一代人都会有这一天。

**目标人群**：30-50岁有"讨好型人格"困扰的人群，尤其是女性。

  - 第2节：转机——某天在电梯里看到一个女同事自然地说了句"这个我帮不了"，旁边的人没有生气，就是继续聊。我突然意识到：拒绝是可以的

  - 结尾："讨好型人格的人不是在讨好别人，是在害怕不被喜欢。但花了半辈子才明白——你不喜欢我，我也可以好好的。"

**差异化点**：不叙事讨好型人格有多惨——写的是一个具体的、可操作的觉醒和练习过程。

**选题角度**：从"中年人学游泳"这个具体画面切入，写"主动面对恐惧"的成长观——不是鸡汤式"突破舒适区"，是一个普通人用行动向自己证明"你还行"。

**目标人群**：40-60岁有各种"一直想做但不敢做"的心态的中年人。

  - 第2节：为什么现在要学——不是突然勇敢了，是体检报告出来后想通了一件事：怕了一辈子的东西，要死之前还没试过，太亏了
  - 第3节：学的过程——喝了很多水，被孙子笑过，但第六次课的时候我漂起来了，那种感觉比升职还高兴
  - 结尾："现在每周去游两次，游得不好看，但每次从水里出来，都觉得今天的自己比昨天勇敢一点点。"

**差异化点**：不写"中年危机"的沉重——用学游泳这个轻量级具体场景，写出对抗恐惧的快乐。

3. 还了三十年房贷的房子，女儿说太小了不想住
4. 我们这一代人用最好的三十年换了一套房，到底值不值
5. 当房贷终于不是我人生的主语之后，我不知道下一句该说什么

**选题角度**：从"还完房贷"这个节点切入，写房子与人生的关系——不否定买房，也不鼓吹"房奴叙事"，而是一个普通人在拿到"房产证自由"之后的真实感受。

**目标人群**：35-55岁有房贷或即将还完房贷的中年人。

**情绪钩子**：共鸣 → 反思 → 平静 → 释然

**文章结构概要**：
  - 引入：最后一笔贷款扣款成功，手机弹出短信提示。我等这条消息等了三十年，看完之后只是按了锁屏键
  - 第1节：这三十年为了这套房放弃了什么——没敢换工作、没敢创业、没敢跟老板顶嘴、连出国旅游都只去过一次泰国
  - 第2节：房子换来的是什么——孩子在温暖的家长大了、老婆有安全感、父母来的时候有个落脚的地方。不后悔，但总觉得差了点什么
  - 第3节：还完之后的空虚——以前每个月被房贷追着跑，突然没人追了，反而不知道该往哪走
  - 结尾："房贷是这三十年的BGM，突然停了之后才发现，其实我不会跳舞。但现在开始学，也不晚。"

**差异化点**：不抱怨房价高，不歌颂"负重前行"——写还完房贷后那段"然后呢"的空白，以及如何重新定义生活。
