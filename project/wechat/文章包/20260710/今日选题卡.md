### 选题 ① ｜ 推荐指数：⭐⭐⭐⭐⭐
**方向**：夫妻关系

**标题**：老公开始记账后，我才发现这十年我花了多少
**备选标题**：
1. 老公突然记账，把我这十年的花销全照了出来
2. 他记了一个月账，我看完整个人不说话了
3. 婚姻里最尴尬的，是两个人终于把账翻开看
4. 老公记账后我才明白，这十年钱都去哪了
5. 他拉出那张账单时，我才知道自己被看见过
**选题角度**：记账是把婚姻里的钱摊开看，照出的不是谁花得多，是隐形付出从没被看见。
**目标人群**：30-45岁、管家庭开销的已婚女性
**情绪钩子**：共鸣 + 反思（扎心）
**文章结构概要**：
  - 引入：老林突然在手机上记账，记了一个月，月底拉出一张表给我看
  - 第1节：我以为他要嫌我乱花，结果发现自己这十年大头花在孩子和我妈身上
  - 第2节：他记得很细，连我给我妈买的东西都单列，我反而被这张表看得说不出话
  - 第3节：他记账不是查我，是想看看哪里能省下来，给我换个一直想换的净水器
  - 结尾：我盯着那张表，看的不是花了多少，是这十年我花出去的，从来没被问过一句
**参考来源**：近期"婚姻里把规矩摊开"系列爆款的延伸
**差异化点**：别人写AA/分账的矛盾，我写记账作为照见隐形付出的镜子

### 选题 ② ｜ 推荐指数：⭐⭐⭐⭐⭐
**方向**：职场人生

**标题**：公司让大家匿名互评，我收到了三条
**备选标题**：
1. 年终匿名互评，我收到的那条让我愣到下班
2. 同事给我写的那句评价，我反复看了一整晚
3. 匿名互评里那句"心累"，把我十年的习惯照穿了
4. 我以为自己很负责，直到同事匿名说我心累
5. 那三条匿名评价，逼我承认自己扛得太狠
**选题角度**：一条匿名评价，照出"什么都自己扛"在别人眼里其实是负担。
**目标人群**：30-45岁、习惯独扛的职场中年
**情绪钩子**：刺痛 + 反思
**文章结构概要**：
  - 引入：公司年终搞360匿名互评，每人收三条，我打开第三条愣住了
  - 第1节：一条夸靠谱，一条说我太独，第三条写"跟她搭档心累，她什么都自己扛"
  - 第2节：我确实习惯自己扛，怕麻烦人、怕被说不行，带徒弟小周时也不肯放手
  - 第3节：意识到自己扛不是负责，是不信任别人，也把别人挤得没位置
  - 结尾：第三条评价我留到现在。你说，扛成别人眼里的心累，算负责还是自私？
**参考来源**：职场边界/独扛型人格长期共鸣话题
**差异化点**：不写被裁/被替代，写一条匿名评价撕开"独立"的真相

### 选题 ③ ｜ 推荐指数：⭐⭐⭐⭐⭐
**方向**：夫妻关系

**标题**：我决定不再跟老公解释我为什么哭
**备选标题**：

2. 我不再为我的眼泪找理由，他反而安静了
3. 婚姻里最松的一步，是哭的时候不再解释
4. 那次我没解释为什么哭，他没再追问
5. 我把"我为什么哭"这句话，咽了回去
**选题角度**：停止为情绪找合理借口，是承认情绪本身就有资格存在。
**目标人群**：30-50岁、长期压抑情绪的女性
**情绪钩子**：释然 + 觉醒
**文章结构概要**：
  - 引入：我有段时间爱哭，每次哭都跟老林解释清楚因为什么，解释了十几年
  - 第1节：某次又哭，他照常问怎么了，我突然不想解释，说就是想哭一会
  - 第2节：他愣了，没追问，去倒了杯水放旁边，我反而哭得痛快了
  - 第3节：我一直在用"合理解释"证明我的眼泪有资格，不解释的那一刻才松下来

**参考来源**：近期"停止讨好/收回自我"系列
