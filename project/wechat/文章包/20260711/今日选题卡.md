## ⭐ 选题 ① ｜ 方向：夫妻关系
**标题**：我在老公抽屉里翻到一张我没拍的照片
**开局类型**：悬念物件型 ｜ **结尾类型**：循环呼应
**情绪钩子**：好奇 → 鼻酸
**结构**：找螺丝刀翻抽屉翻到照片 → 照片背面老林的字与日期 → 才意识到那年自己多累、他全看在眼里 → 没说破，照片放回原位
**锚点**：时间戳+地理+身份+凭证暗示+对话+感官+"后来才知道"+前后对照+收尾呼应

## ⭐ 选题 ② ｜ 方向：夫妻关系
**标题**：我开始每天给老公留一盏灯
**开局类型**：自我宣言型 ｜ **结尾类型**：反问留白
**情绪钩子**：温暖 → 错位 → 安心
**结构**：宣言留灯 → 老公问起 → 反转他没那么晚，有几次在楼下抽烟拖到半夜怕吵醒我 → 双向的"留"
**锚点**：时间戳+地理+身份+品牌+对话+感官+前后对照+第三方见证+收尾呼应

## ⭐ 选题 ③ ｜ 方向：职场人生
**标题**：公司让所有人签一份自愿放弃年假的承诺书
**开局类型**：对话切入型 ｜ **结尾类型**：戛然而止（本批仅此一篇）
**情绪钩子**：荒诞 → 沉默 → 不签
**结构**：组长推来承诺书 → 老同事都签 → 想起去年父亲住院请不出假 → 放下笔没签 → 组长看了眼没说话
**锚点**：时间戳+身份+地理+对话+凭证暗示+数字+"后来才知道"+前后对照+收尾呼应

## ⭐ 选题 ④ ｜ 方向：人生感悟
**标题**：今年春节三天，我收到一百一十二条群发拜年
**开局类型**：数字冲击型 ｜ **结尾类型**：金句提炼
**情绪钩子**：数字冲击 → 失语 → 释然
**结构**：数群发拜年112条 → 逐条翻发现没一条来自真正记得她的人 → 真正关心的人发的都是具体的话 → 删与留
**锚点**：时间戳+身份+对话+第三方见证+前后对照+凭证暗示+品牌+收尾呼应
