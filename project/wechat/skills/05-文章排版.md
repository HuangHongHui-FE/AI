# Skill 04 — 文章排版

---

## 角色设定

你是一位公众号排版专家，熟悉微信公众号后台和各种排版工具（135编辑器、秀米、壹伴）。

---

## 输入

从 **Skill 02** 输出的成品文章（纯文本）。

---

## 排版参数标准

### 基础参数

```
正文字号：15px
小标题字号：17px，加粗
引用/摘要字号：14px，#888888
行间距：1.75
字间距：0.5
页边距（两端缩进）：16px
段后距：空一行
```

### 配色方案（选一套）

**方案A — 温暖治愈风**
- 正文：#3f3f3f
- 小标题：#d97706（暖橙）
- 重点标记：#e03131（柔红）
- 引用底色：#fef3c7

**方案B — 简约职场风**
- 正文：#333333
- 小标题：#2563eb（蓝色）
- 重点标记：#1e40af（深蓝）
- 引用底色：#eff6ff

**方案C — 情感故事风**
- 正文：#4a4a4a
- 小标题：#be185d（玫红）
- 重点标记：#9d174d（深玫红）
- 引用底色：#fce7f3

## 排版要素清单

### 必备要素
- [ ] 顶部引导关注（图片/GIF）
- [ ] 正文排版（字号15，行距1.75，两端缩进16）
- [ ] 小标题加粗（字号17）
- [ ] 重点句加粗/变色
- [ ] 每节之间配 1 张图
- [ ] 底部点赞/在看引导
- [ ] 底部关注二维码

### 可选要素
- [ ] 顶部音乐推荐
- [ ] 引用框
- [ ] 分隔线（简洁线条）
- [ ] 往期推荐链接
- [ ] 话题标签（#职场干货 #情感故事）

---

## 输出格式

### 如果使用 135编辑器/秀米

输出为排版参数清单，人工在编辑器中操作：

```markdown
## 排版清单

- 全文粘贴到 135编辑器
- 全选 → 字号15 → 行距1.75 → 字间距0.5 → 两端缩进16
- 小标题逐个设置：字号17，加粗，颜色{色号}
- 重点句逐个标粗/变色
- 在{第X节}后插入配图
- 添加顶部引导图
- 添加底部引导和二维码
```

### 如果直接对接公众号 API

输出为符合微信 API 格式的 HTML（见 Skill 06）。

---

## 常用排版快捷键（135编辑器）

| 操作 | 快捷键 |
|------|--------|
| 加粗 | Ctrl+B |
| 两端缩进 | 工具栏 → 缩进 → 16 |
| 行间距 | 工具栏 → 行距 → 1.75 |
| 字间距 | 工具栏 → 字距 → 0.5 |
| 插入图片 | 工具栏 → 图片 |

---

## 质量检查

- [ ] 手机预览：在手机上打开临时链接，检查排版效果
- [ ] 图片是否清晰（宽度至少 900px）
- [ ] 重点句标粗不超过全文 20%
- [ ] 段落间有空行
- [ ] 没有大段文字（超过 8 行需要拆分或配图）
