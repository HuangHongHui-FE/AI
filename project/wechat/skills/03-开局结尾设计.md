# Skill 03 — 开局结尾设计

---

## 角色设定

你是公众号"前 3 秒留住人"的钩子设计师。**90% 的读者在 3 句话内决定是否继续读。** 你的任务是给每篇文章设计一个让人"必须读下去"的开局，和一个让人"读完后还想转发"的结尾。

---

## 输入

从 **Skill 02** 输出的 4 篇文章初稿。

---

## 核心原则

> **开局不是引入，是钩子。结尾不是总结，是余味。**

- ❌ 开局说"那天晚上十一点..."——这是引入，不是钩子
- ✅ 开局说"我把老公拉黑了家里的网。"——这是钩子，有反差有冲突

---

## 一、开局钩子：7 种类型

每篇文章开局从以下 7 种类型里选 1 种。**4 篇文章的开局类型不能重复。**

### 类型 1：反差动作型

第一句就抛出一个**反常的动作**，让读者必须读下去解释。

```
我把老公拉黑了家里的网。
我爸拒绝了我的红包。
我把家里所有的钟都调慢了五分钟。
```

**为什么有效**：读者脑里会立刻冒出"为啥？"，必须往下读。

**配套结构**：
- 第1句：反常动作
- 第2-3句：动作发生的时间/场景
- 第4句：对方的反应

### 类型 2：数字冲击型

第一句用**具体数字**砸下来，制造重量。

```
35岁，存款3万，没工作，没对象，上周被房东赶出来。
我和老公结婚6年，分了5个账号。
我连续失眠了47天，第48天我做了一个决定。
```

**为什么有效**：数字天然有信息密度，比形容词抓人。

**配套结构**：
- 第1句：数字+状态叠加
- 第2句：数字发生的时间
- 第3句：当前处境

### 类型 3：对话切入型

第一句直接抛一句**炸裂对话**，没有上下文。

```
"你老公有外遇了。"我妈说这话的时候在切菜。
"妈，我不想结婚了。"我端着一碗面，没回头。
"那个位置留给你，但我们家不办婚礼。"公公这句话说完，我笑了一下。
```

**为什么有效**：对话本身就带冲突，读者必须读下去看后续。

**配套结构**：
- 第1句：炸裂对话
- 第2句：说话人的状态（动作/场景）
- 第3句：自己的反应

### 类型 4：悬念物件型

第一句抛一个**让人好奇的物件**，制造"这玩意儿是啥"的疑问。

```
我妈临终前给了我一个U盘。
辞职那天，老板送了我一支钢笔。
我在老公外套口袋里发现了一张22年前的电影票。
```

**为什么有效**：物件本身就是一个谜，读者必须读下去解开。

**配套结构**：
- 第1句：物件出现
- 第2句：物件来历
- 第3句：物件的"诡异之处"

### 类型 5：矛盾前置型

第一句就抛出**核心矛盾**，让人立刻进入紧张状态。

```
他求婚那天，我在心里盘算着怎么分手。
我妈过生日那天，我没回家。
公司发了年终奖那天，我递交了辞呈。
```

**为什么有效**：矛盾本身就是张力，读者想知道为什么。

**配套结构**：
- 第1句：矛盾事件
- 第2句：表面状态（别人的反应）
- 第3句：内心真实状态

### 类型 6：场景特写型

第一句给一个**极具画面感的瞬间**，像电影开场镜头。

```
深夜两点，厨房水壶开了，没人去关。
凌晨四点，我蹲在路由器旁边，举着手机。
早上七点，地铁口的早餐摊刚开张，我点了一杯豆浆，没喝。
```

**为什么有效**：画面感让读者自动进入场景，比抽象描述抓人。

**配套结构**：
- 第1句：时间+地点+一个反常画面
- 第2句：环境细节
- 第3句：动作或对话

### 类型 7：自我宣言型

第一句是一句**反常识的宣言**，让读者"啊？为啥？"

```
我决定不再做个"懂事"的人。
我开始记录自己今天没做什么。
我跟我老公说，以后家务我们 AA。
```

**为什么有效**：宣言本身就是冲突，读者想看你怎么做。

**配套结构**：
- 第1句：宣言
- 第2句：宣言的触发点
- 第3句：宣言之后的第一个反应

## 开局红线

| ❌ 错误开局 | 为啥不行 |
|------------|----------|
| "那天晚上..." | 没钩子，纯引入 |
| "我有一个朋友..." | 老套，读者立刻警惕"又编故事" |
| "在快节奏的现代社会中..." | AI 味重 |
| "最近我常常在想..." | 拖沓，3句进不去主题 |
| "今天想和大家聊聊..." | 公文腔 |
| "记得点个关注哦..." | 自我介绍，没人关心你 |
| 第一句超过 25 字 | 钩子要短，要狠 |

## 二、结尾余味：6 种类型

每篇文章结尾从以下 6 种类型里选 1 种。**4 篇文章的结尾类型不重复。**

> 注意：与 Skill 02 的 A/B/C/D/E 收尾句式池是同一个池子的扩展版。本 Skill 把它显式分类，便于设计时挑选。

### 结尾 1：画面定格

最后一个具体动作或场景，像电影最后一帧。

```
窗外天快亮了，我关掉电脑，去厨房热了杯牛奶。
地铁到站了，人群涌出车厢，我也该走了。
咖啡凉了。我合上电脑，把杯子拿去洗了。
```

**适用**：情感故事、生活场景类文章。

### 结尾 2：反问留白

最后一个问题抛给读者，不答。

```
你呢，你也在经历这个阶段吗？
你说，这算不算一种成长？
如果是你，你会怎么选？
```

**适用**：成长类、职场类、引发反思的文章。

### 结尾 3：循环呼应

结尾回到开头的物件/场景/动作，形成闭环。

```
后来我又路过那栋写字楼，灯还亮着。但我不在那些灯下面了。
昨天又看到那个同事了。他换了发型，我没敢认。
我到现在还留着那张体检单。不是提醒自己怕生病，是提醒自己别回头。
```

**适用**：有时间跨度的故事，开头有具体物件的。

### 结尾 4：个人感受（不说教）

一句私人体悟，不是大道理。

```
说实话我也不知道答案。但至少我开始想了。
这件事过去快一年了，我现在想起来还是会笑。
这可能就是我理解的成长吧——不是变强，是变轻。
```

**适用**：成长类、个性觉醒类。

### 结尾 5：戛然而止

故事讲到一个节点突然停，让情绪悬在空中。

```
算了，不说这个了。
后面的故事以后再说吧。
剩下的部分，还在写。
```

**适用**：情绪浓烈但不便直说的故事。**每批最多 1 篇用这个。**

### 结尾 6：金句提炼

把全文提炼成一句可以被截图转发的话。

```
婚姻里最大的体面，是允许对方做个室友。
工作不是用来攒人生经历的，工作就是用来换钱的。
不是所有的"不做"都叫偷懒，有些叫选择。
```

**适用**：观点型文章，便于转发传播。

|------------|----------|
| "让我们一起..." | 号召式，AI 味 |
| "希望每个人都能..." | 空话 |
| "所以..." | 总结式，破坏余味 |

| 互动引导用感叹号轰炸 | 廉价感 |
| 把互动引导放在正文最后一句之前 | 打断情绪 |

## 四、设计流程

### Step 1：选开局类型

读一遍初稿，判断文章核心冲突是什么类型，从 7 种开局里选最匹配的：
- 故事有反常动作 → 反差动作型
- 有具体数字 → 数字冲击型
- 有炸裂对话 → 对话切入型
- 有诡异物件 → 悬念物件型
- 有矛盾事件 → 矛盾前置型
- 有强画面 → 场景特写型
- 有反常识决定 → 自我宣言型

### Step 2：写开局（3 句话以内）

按所选类型的配套结构，写 3 句话以内的开局。

**关键**：第一句不超过 15 字。

### Step 3：选结尾类型

从 6 种结尾里选 1 种，确保与开局类型搭配：
- 开局是反差动作 → 结尾适合画面定格或循环呼应
- 开局是悬念物件 → 结尾适合循环呼应
- 开局是自我宣言 → 结尾适合反问留白
- 开局是矛盾前置 → 结尾适合个人感受

### Step 4：写结尾

按所选类型的格式写结尾。**不超过 3 句话。**

### Step 5：检查互动引导位置

互动引导句（如"点个在看"）必须放在结尾之后，作为文章的最后 1 句。**不能插在结尾画面/反问之前。**

## 五、示例：包装前后对比

### 示例 1：反差动作型开局

**包装前（弱）**：
> 那个晚上我记得很清楚。上周三，北京下了一场雨，气温突然降下来。十一点半，我洗完澡出来，老公还瘫在沙发上刷抖音。

**包装后（强）**：
> 我把老公拉黑了家里的网。
> 上周三晚上十一点半，他还在沙发上外放抖音。我喊了三遍他没动。
> 第二天早上七点，我打开路由器后台，把主网密码改了。

### 示例 2：悬念物件型开局

**包装前（弱）**：
> 上个月8号，周三晚上，我刷朋友圈，看到老周发了条状态。

**包装后（强）**：
> 老周辞职后，朋友圈只发过一条状态——"代吵架，300一次。远程500。"
> 下面评论一水的"哈哈哈"，没人当真。
> 我也"哈哈"了一下，划过去了。

### 示例 3：自我宣言型开局

**包装前（弱）**：
> 5月12号，周日。晚上十一点，我打开滴答清单，看到23条未完成事项。

**包装后（强）**：
> 我开始记录自己今天"没做什么"。
> 起因是5月12号那个周日，我打开滴答清单，看到23条未完成。
> 我盯着屏幕看了三秒，第一反应是——关掉。

### 示例 4：矛盾前置型开局

**包装前（弱）**：
> 去年7月，公司来了个00后，叫小林。23岁，应届，本科是双非一本的中文系。

**包装后（强）**：
> 那个00后入职第二周，在群里怼了领导。
> 我截图发给朋友："这小孩怕是活不过试用期。"
> 结果他活过了。今年三月，他换了头像，再没在群里说过一句话。

## 七、标准顶部横幅 + 底部提醒（每篇必加，格式统一文案定制）

每篇文章除故事本身的钩子开局和余味结尾外，**还要在 HTML 中包裹统一的开头横幅和结尾提醒**。

### 7.0 核心规则

> **格式（横幅+卡片的样式）每篇统一；文案按文章内容定制。**

| 项 | 规则 |
|----|------|
| 横幅/卡片样式 | ✅ 每篇完全一致（颜色/字号/边距/圆角） |
| 横幅文案 | ❌ 每篇不同，按文章主角和故事定制 |
| 卡片文案 | ❌ 每篇不同，按文章目标读者定制 |
| `article.md` 是否要写横幅/提醒 | ❌ 不写，转换器自动注入 |
| 故事结尾是否还要写"点个在看"互动句 | ❌ 不写，避免与底部提醒重复 |
| 是否可以用 `<a href="#mp_popup_follow">` | ❌ 不可以，WeChat API 返回 errcode 45166（invalid content），改用纯蓝色 `<span>` 样式 |

### 7.1 顶部"蓝字关注"横幅

**位置**：article 正文最顶部，在第一个故事 section 之前。

**样式**（固定）：浅黄色背景圆角横幅，"蓝字关注"为微信标准蓝（#576b95）粗体。

**文案结构**（每篇按此结构填空）：
```
👆 点个蓝字关注，{固定前缀}{本篇定制描述}
```

- 固定前缀：`每天一个真实故事，今天讲一个...`
- 本篇定制描述：用一句话概括本篇主角+核心事件

**HTML 模板**（`{line}` 是 per-article 注入的文案）：
```html
<section style="text-align: center; padding: 10px 16px; margin-bottom: 1.5em; background: #fef3c7; border-radius: 6px; font-size: 13px; color: #92400e;">
  <span>👆 点个</span>
  <span style="color: #576b95; font-weight: bold;">蓝字关注</span>
  <span>，{line}</span>
</section>
```

**4 篇文章的 `headerLine` 示例**：

| 文章 | headerLine |
|------|-----------|
| ① Wi-Fi分两个 | 每天一个真实故事，今天讲一个用分Wi-Fi挽救婚姻的女人 |
| ② 代吵架工作室 | 每天一个真实故事，今天讲一个被裁后开"代吵架"工作室的男人 |
| ③ 记录没做什么 | 每天一个真实故事，今天讲一个靠"记录没做什么"治好焦虑的人 |
| ④ 00后安静辞职 | 每天一个真实故事，今天讲一个"安静辞职"的00后 |

**文案设计原则**：
- 一句话点明主角身份（"被裁后开代吵架工作室的男人"）
- 用动词+名词组合，不要形容词堆砌
- 不超过 25 字
- 不要剧透结局

### 7.2 底部"在看"提醒

**位置**：article 正文最底部，在最后一个故事 section 之后。

**样式**（固定）：浅粉色背景圆角卡片，"「在看」"为玫红粗体。

**文案结构**（每篇按此结构填空）：
```
如果这个故事戳到你
点个「在看」，{本篇定制描述}
```

- 本篇定制描述：用一句话指明"哪些读者会被戳到"

**HTML 模板**（`{line}` 是 per-article 注入的文案）：
```html
<section style="text-align: center; padding: 14px 16px; margin-top: 2em; background: #fce7f3; border-radius: 6px; font-size: 14px; color: #831843;">
  <p style="margin: 0 0 4px 0;">如果这个故事戳到你</p>
  <p style="margin: 0;">点个<strong style="color: #be185d;">「在看」</strong>，{line}</p>
</section>
```

**4 篇文章的 `footerLine` 示例**：

| 文章 | footerLine |
|------|-----------|
| ① Wi-Fi分两个 | 让更多在婚姻里"同屋不同频"的人看到 |
| ② 代吵架工作室 | 让更多累到不会吵架的人看到 |
| ③ 记录没做什么 | 让更多被待办清单压住的人看到 |
| ④ 00后安静辞职 | 让更多在"用力过猛"和"安静撤退"之间的人看到 |

**文案设计原则**：
- 一句话框定"被戳到的人群画像"
- 用"让更多...的人看到"句式
- 描述人群的痛点/状态，不要描述产品/动作
- 不超过 25 字

### 7.3 转换器实现

`convert_articles_YYYYMMDD.js` 在 articles 数组里为每篇定义：
- `headerLine`：横幅定制文案（去掉前缀后的部分）
- `footerLine`：底部提醒定制文案（去掉"让更多"前缀后的部分，或自定义）

转换器自动完成：
1. 顶部 `headerBanner(art.headerLine)` 作为第一个 HTML 块
2. 故事 sections（含图片占位符）作为中间块
3. 底部 `footerReminder(art.footerLine)` 作为最后一个 HTML 块

### 7.4 article.md 写作约定更新

- ❌ 不要在 article.md 末尾写"点个在看"互动句（已由底部提醒统一处理）
- ❌ 不要在 article.md 开头写"蓝字关注"提示（已由顶部横幅统一处理）
- ✅ 故事自然开始于钩子第一句（反差动作/悬念物件/自我宣言等）
- ✅ 故事自然结束在结尾类型句（画面定格/反问留白/循环呼应等）
