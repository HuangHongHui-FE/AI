# Skill 06 — 发布到公众号草稿箱

---

## 一键发布

使用项目根目录的 `publish.js` 脚本，一条命令完成所有操作：

```bash
node publish.js C:/Users/31672/AI/project/wechat/文章包/YYYYMMDD/XX-文章名
```

脚本自动完成：获取 token → 上传封面 → 上传配图 → 替换占位符 → 创建草稿。

---

## 文章目录结构

```
文章包/YYYYMMDD/XX-文章名/
├── article.md              ← 文章（markdown）
├── payload_template.json   ← 草稿模板（用 {{THUMB}} {{IMG0}} {{IMG1}} 占位）
├── cover.jpg               ← 封面图
└── img1.jpg, img2.jpg...   ← 文中配图
```

### payload_template.json 格式

```json
{
  "articles": [{
    "title": "文章标题",
    "author": "",
    "digest": "摘要64字以内",
    "content": "<section>...<img src=\"{{IMG0}}\"...</section>",
    "content_source_url": "",
    "thumb_media_id": "{{THUMB}}",
    "need_open_comment": 1,
    "only_fans_can_comment": 0
  }]
}
```

占位符说明：
- `{{THUMB}}` → 脚本自动替换为封面图 media_id
- `{{IMG0}}` `{{IMG1}}` ... → 脚本自动替换为对应 img1.jpg/img2.jpg 的微信 CDN URL

---

## 发布后的操作

草稿创建成功后，用户只需：

1. 打开**订阅号助手 App**（手机）
2. 进入**草稿箱**，找到文章
3. **预览**确认排版
4. 点击**发布**
