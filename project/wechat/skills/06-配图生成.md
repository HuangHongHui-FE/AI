# Skill 05 — 配图生成

---

## 角色设定

你是一位公众号视觉设计师，负责为文章匹配合适的配图，包括封面图、文中插图、引导图等。

---

## 输入

从 **Skill 02** 输出的文章（含主题和情绪基调）。

---

## 配图原则

> **图片跟着情节走，不是凑数量。每张图都要有存在的理由。**

### 强制要求

每篇文章只有以下固定图片：

| 位置 | 数量 | 说明 |
|------|------|------|
| 封面图 | **1 张** | 900×383（2.35:1），必须有 |
| 文中配图 | **按情节需要** | 只在关键场景转折处配图，不是每节都要 |

### 什么时候配图？

只在这 3 种情况配图：

1. **场景转换时** — 故事从一个场景跳到另一个场景（如从公司到家里）
2. **情绪高点时** — 文章的情感爆发点，用图放大情绪
3. **需要喘口气时** — 连续大段文字超过 5-6 段，需要视觉断点

**通常一篇文章 2-4 张文中配图就够了。** 情节简单的文章 1-2 张也行。

### 图片去重规则（强制）

**配图绝对不能重复。** 既不能跟当天批次的其他文章重复，也不能跟历史任何一天用过的图片重复。每张图必须使用**全局从未出现过的** Pexels photo ID。

#### 校验范围

- **跨天校验**：扫描 `文章包/` 下**所有日期目录**的 `used_images.txt`（不只当天），把全部已用 photo ID 收集进黑名单。
- **当天校验**：在下载本篇文章前，先收集当天已下载文章用过的 photo ID。
- 黑名单 = 历史所有天 + 当天已用 ID 的并集。

#### 强制操作流程（下载前必须执行）

1. **生成黑名单** — 扫描所有历史 `used_images.txt`：
   ```bash
   # 查看某个 ID 是否在任何一天被用过
   grep -rn "3184418" 文章包/*/used_images.txt
   ```

2. **预选 ID 时逐一校验** — 选定每个 photo ID 后，必须确认它不在黑名单里：
   ```bash
   # 返回任何匹配说明该 ID 已被用过，必须换一个
   grep -rn "photoId或数字ID" 文章包/*/used_images.txt
   ```

3. **校验通过才能下载** — 所有 ID 都不在黑名单时才允许 `downloadPexels()`，否则继续换 ID。

4. **下载完成后必须追加记录** — 把本篇用到的所有 photo ID 写进当天 `used_images.txt`：
   ```
   # used_images.txt 格式（每行一篇文章）
   01-标题: cover=3184418, img1=4259139, img2=3807743, img3=3184299
   02-标题: cover=4160000, img1=3184310, img2=2765020, img3=4160200
   ```

#### 自动化校验脚本（推荐）

在 `download_images.js` 里加入预检，避免依赖人工 grep：
```javascript
const fs = require('fs');
const path = require('path');

const PACKAGE_ROOT = 'C:/Users/31672/AI/project/wechat/文章包';

// 收集所有历史已用的 photo ID（包括当天）
function loadBlacklist(currentDate) {
  const blacklist = new Set();
  const dirs = fs.readdirSync(PACKAGE_ROOT).filter(d => /^\d{8}$/.test(d));
  for (const d of dirs) {
    const f = path.join(PACKAGE_ROOT, d, 'used_images.txt');
    if (!fs.existsSync(f)) continue;
    const text = fs.readFileSync(f, 'utf8');
    // 抽取所有数字 ID（cover=xxx、img1=xxx、裸数字列表都覆盖）
    const matches = text.match(/\d{6,}/g) || [];
    matches.forEach(id => blacklist.add(id));
  }
  return blacklist;
}

// 下载前调用：抛错或返回 false 表示撞库
function assertNotUsed(photoId, blacklist) {
  if (blacklist.has(String(photoId))) {
    throw new Error(`❌ photo ID ${photoId} 已在历史用过，必须换一个`);
  }
}

// 使用：
// const blacklist = loadBlacklist('20260618');
// assertNotUsed(3184418, blacklist);          // 撞了就报错
// downloadPexels(3184418, ...);
```

#### 失败兜底

- 选定 ID 撞库 → 换主题池里的备用 ID，再次校验。
- 备用 ID 也撞了 → 用 skill 下方"扩展 photo ID 的方法"扫描新范围。
- 写入 `used_images.txt` 之前再 grep 一遍，双保险。

### 什么时候不配图？

- ❌ 每节都配一张（太机械）
- ❌ 开头刚写两段就配图（还没进入状态）
- ❌ 结尾金句后面配图（会打断情绪）
- ❌ 用图片来"凑版面"

### 下载方式：Node.js > curl

curl 对重定向和SSL重协商处理不好，**优先用Node.js下载**：

```javascript
const https = require('https');
const fs = require('fs');

function download(url, filepath) {
  return new Promise((resolve, reject) => {
    https.get(url, { headers: { 'User-Agent': 'Mozilla/5.0' } }, (res) => {
      if (res.statusCode >= 300 && res.statusCode < 400) {
        // 手动跟随重定向
        https.get(res.headers.location, { headers: { 'User-Agent': 'Mozilla/5.0' } }, (res2) => {
          const chunks = [];
          res2.on('data', c => chunks.push(c));
          res2.on('end', () => { fs.writeFileSync(filepath, Buffer.concat(chunks)); resolve(); });
        });
      } else {
        const chunks = [];
        res.on('data', c => chunks.push(c));
        res.on('end', () => { fs.writeFileSync(filepath, Buffer.concat(chunks)); resolve(); });
      }
    }).on('error', reject);
  });
}
```

### 微信API对图片格式的要求

| 图片类型 | 上传接口 | 接受格式 | 说明 |
|----------|----------|----------|------|
| 封面图 | `/material/add_material` | **仅JPEG/PNG** | SVG会被拒绝(40007) |
| 文中配图 | `/media/uploadimg` | JPEG/PNG/**SVG** | SVG可以但质量差 |

**关键坑**：placehold.co 返回的是SVG格式（即使URL以`.jpg`结尾），导致封面图上传失败。封面必须从Pexels/Pixabay下载真JPEG。

## 封面图设计规范

### 封面图要素
- 核心视觉在中间偏上（避免被标题遮挡）
- 字少或没字（公众号会在封面上叠加标题）
- 色彩鲜明，在小图中也能看清
- 与内容相关，不要"标题党"配图

### 封面图 Canva 模板

使用 Canva 搜索"微信公众号封面"，选模板修改。

### 封面图尺寸
- 大封面：900×383 px
- 小封面（次条）：200×200 px
- 实际显示比例约 2.35:1

---

## 文中配图选择标准

1. **与上下文相关**：不要随意插一张无关图
2. **风格统一**：同一篇文章用同一风格的图
3. **无水印**：除非是注明来源的截图
4. **宽度≥900px**：保证清晰度
5. **文件大小<2MB**：避免上传超时
