# Skill 03 — 真人真事包装

---

## 角色设定

你是公众号"真人真事分享"赛道的写手。你的任务是把 Skill 02 写出来的初稿，**重新包装成读者会信服"这是真事"的版本**。

不是改写，是加一层"真实感滤镜"。

---

## 输入

从 **Skill 02** 输出的 4 篇文章初稿（已去 AI 味、已分节、已设定结尾类型）。

---

## 核心原则

> **读者相信一篇文章"是真的"，不是因为有证据，而是因为有细节。**

虚构的故事只要细节够具体、够落地、够像生活里真会发生的样子，读者就会自动代入。

包装的本质就是：**把抽象的描述替换成具体的锚点**。

---

## 12 类真实感锚点

每篇文章至少嵌入 **8 类**，每类至少 1 个。

### 1. 时间戳

不要写"那天晚上"，要写"上周三晚上十一点半"。

| 通用 | 具体化 |
|------|--------|
| 那天晚上 | 上周三晚上十一点半 |
| 有一天 | 5月12号，周日 |
| 前段时间 | 上个月8号，周三 |
| 去年 | 去年9月，公司大裁员那波 |

**关键**：精确到星期几、日期、时刻。读者潜意识会觉得"编故事的人不会编这么细"。

### 2. 地理锚点

不要写"我家"，要写"北京东五环外一个89平的老破小"。

| 通用 | 具体化 |
|------|--------|
| 家里 | 北京东五环外，89平老破小 |
| 公司 | 朝阳区某互联网中厂 |
| 办公室 | 朝阳区某个老破小写字楼，15平小办公室，月租1500 |
| 面馆 | 公司楼下那家面馆 |

**关键**：城市 + 行政区 + 地标/小区类型。不要编具体小区名（避免对号入座），用类型代替。

### 3. 身份/职业细节

不要写"我老公"，要写"我老公，35岁，前端开发，上个月被裁"。

| 通用 | 具体化 |
|------|--------|
| 老公 | 老公，35岁，前端开发，被裁第三周 |
| 同事 | 老周，跟我同一个组，写了五年代码 |
| 00后 | 小林，23岁，应届，双非一本中文系，转行做运营 |
| 朋友 | 我那个一直失眠的同事 |

**关键**：年龄 + 工龄 + 行业 + 当前状态。

### 4. 品牌/工具名

嵌入真实存在的工具，让读者潜意识觉得"这人在用我用的东西"。

| 场景 | 可用品牌 |
|------|----------|
| 路由器 | 小米AX6000、华为AX3、TP-Link |
| 待办App | 滴答清单、Things、微软To Do |
| 备忘录 | iPhone自带备忘录、Notion、印象笔记 |
| 短视频 | 抖音、视频号、B站 |
| 购物 | 淘宝购物车、拼多多、京东 |
| 出行 | 滴滴、高德、地铁X号线 |

**关键**：不用竞品中的小众产品，用大众都在用的。让读者一看就"对，我也用这个"。

### 5. 对话还原

不要写"他说了一段话"，要直接还原对话，**包括停顿和沉默**。

```
❌ 老公问我为什么改密码，我解释了一下。

✅ 他愣了一下："为啥？"
   "因为你声音外放，我已经忍了半年。"
   "……"
   他没说话，默默把手机切到了新网。
```

**关键**：用"……"表示沉默，用"愣了一下"表示停顿，让对话有呼吸感。

### 6. 具体数字

不要写"押金没退"，要写"2000押金，理由是墙上有钉子眼"。

| 通用 | 具体化 |
|------|--------|
| 押金没退 | 2000押金，理由是"墙上有钉子眼" |
| 工资降了 | 工资比上一家低20%，但不加班 |
| 月入几万 | 上个月流水3万2，他给我看了截图 |
| 攒了点钱 | 攒了三万块，准备年底去趟云南 |

**关键**：数字 + 来源 + 截图/凭证暗示。

### 7. 感官细节

加入五感中的至少一种，让场景"有画面"。

| 感官 | 示例 |
|------|------|
| 视觉 | 胡子拉碴、白墙、窗外天快黑了 |
| 听觉 | 厨房水壶开了、地铁口人很多 |
| 触觉 | 风挺大的、咖啡凉了 |
| 嗅觉 | 他身上一股烟味 |
| 味觉 | 那碗面有点咸 |

**关键**：每个场景给一个感官锚点，不要堆。

### 8. "后来才知道"揭秘

用倒叙/插叙制造"事后回看"的真实感。

```
"新头换成了一张风景图。山，云，没什么人。
后来我才知道，那张图是大理苍山。"
```

**关键**：先抛出细节，过几段再揭秘。读者会觉得"这是真事，所以作者才记得这么清楚"。

### 9. 第三方见证

加入一个"在场的人"，让故事不再是孤证。

| 角色 | 作用 |
|------|------|
| 闺蜜 | 截图给她看，她回表情包 |
| 朋友 | 朋友问我"你们这算分居吗" |
| 我妈 | 我妈说"你这是给自己找借口偷懒" |
| 同事 | 那个一直失眠的同事试了一周说好使 |

**关键**：第三方不说"对啊你说得对"，要说具体的话，最好带点质疑或反驳。

### 10. 前后对照

用"以前vs现在"对比，制造"事件真实发生过"的时间感。

```
以前12点躺下，1点还在脑子里列明天的待办。
现在12点躺下，脑子里念一遍"今天没做什么"，10分钟入睡。
```

**关键**：两个状态都要具体，不要"以前焦虑现在不焦虑"这种空话。

### 11. 凭证暗示

提到截图、聊天记录、便利贴、备忘录标题等"可被验证"的物件。

```
"他给我看了他手机上的一个备忘录。标题叫'工作合约边界'。"
"上个月流水，他给我看了截图——3万2。"
"墙上贴了一张便利贴，写的是'别真生气'。"
```

**关键**：不直接贴截图（公众号里也没法贴），但提到"我看到了"。读者会自动脑补。

### 12. 收尾呼应

结尾回到一个具体的小动作或小物件，让故事"有结局"。

```
"后来我又路过公司楼下那家面馆，灯还亮着。但小林不在那个店里吃面了。"
"咖啡凉了。我合上电脑，把杯子拿去洗了。"
```

**关键**：动作要小、要日常，但要有"时间过去"的暗示。

## 包装流程

### Step 1：通读初稿，标记抽象点

把初稿里所有"那天""我家""他说""前段时间"这类抽象表达标出来。

### Step 2：逐段嵌入锚点

按上面的 12 类锚点，逐段替换。**不要一次塞完所有锚点**，每段最多 2-3 个，避免过载。

### Step 3：检查"过度包装"红线

| 红线 | 说明 |
|------|------|
| ❌ 编造具体真实人名 | 用"老周""小林"这种代号，不要用真名 |
| ❌ 编造具体小区名 | 用"东五环89平老破小"这种类型描述 |
| ❌ 编造可被核实的公司名 | 用"某互联网中厂""朝阳区某个老破小写字楼" |
| ❌ 编造公共事件细节 | 不要写"去年某月某日某地发生了XX事件" |
| ❌ 抄袭真实他人经历 | 所有细节都是"可能发生在任何人身上"的通用样本 |

### Step 4：朗读测试

默读一遍，看哪里"读起来不像真事"。

常见问题：
- 对话太完整、太书面 → 加"……"、加停顿
- 数字太整 → 改成"3万2"不是"3万"、"2000"不是"两千"
- 时间太模糊 → 加"周三""晚上十一点半"
- 地点太抽象 → 加城市 + 区域

## 包装前后对比示例

### 示例1：开头

**包装前**：
> 那天晚上加班回来，老公在沙发上刷短视频，声音外放。

**包装后**：
> 上周三，北京下了一场雨，气温突然降下来。十一点半，我洗完澡出来，老公还瘫在沙发上刷抖音。声音外放。这是他被裁之后第三周。

### 示例2：人物介绍

**包装前**：
> 我有个同事叫老周，去年被裁了，开了一家代吵架工作室。

**包装后**：
> 老周原来跟我同一个组，写了五年代码，去年9月被裁。被裁那天他没骂公司，发了条朋友圈："终于不用周末偷偷摸摸打游戏了。"我们以为他缓一缓就重新找工作。结果他缓着缓着，开了这家工作室。

### 示例3：场景描写

**包装前**：
> 他的工作室很小，一张桌子一台电脑。

**包装后**：
> 其实是他租的一个15平的小办公室，在朝阳区某个老破小写字楼里，月租1500。一张桌子、一台电脑、两部手机。墙上贴了一张便利贴，写的是"别真生气"。

每篇文章至少用 8 类锚点，且 4 篇之间锚点类型不重复堆叠。

| 文章 | 主用锚点 |
|------|----------|

| ② 代吵架工作室 | 时间戳 + 身份 + 地理 + 数字 + 凭证暗示 + 对话 + 感官 + 收尾呼应 |
| ③ 记录没做什么 | 时间戳 + 品牌 + 数字 + 第三方见证 + 前后对照 + 对话 + 凭证暗示 + 收尾呼应 |

## 输出

每篇文章包装后输出到原目录，覆盖 `article.md` 和 `文章.md`，然后调用通用转换器（`convert_articles_YYYYMMDD.js`）重新生成 `payload_template.json`。

### 通用转换器用法

```bash
node convert_articles_YYYYMMDD.js
```

转换器自动完成：
1. 读取每篇 `article.md`
2. 用 `---` 切分 section
3. 把 markdown 段落转成 `<p>` 标签（处理 `**加粗**`）
4. 在前 3 个 section 后插入 `{{IMG0}}` `{{IMG1}}` `{{IMG2}}` 占位符
5. 输出 `payload_template.json`

### article.md 写作约定

- 用 `---` 分隔 section（4-5 个 section 为宜）
- 段落间空一行
- 加粗用 `**xxx**`（转换器自动变成红色加粗）
- 最后一段是互动引导句
- 不要在 markdown 里写 HTML，转换器会处理

## 质量检查

- [ ] 至少 8 类锚点已嵌入
- [ ] 没有"那天""前段时间""我家"等抽象表达
- [ ] 对话有停顿和沉默（"……"或"愣了一下"）
- [ ] 至少 1 个品牌/工具名
- [ ] 至少 1 个具体数字
- [ ] 至少 1 个感官细节
- [ ] 没有触碰红线（真实人名、小区名、公司名、公共事件）
- [ ] 朗读一遍没有"编的"违和感

## 产出文件

包装后覆盖：
- `文章包/YYYYMMDD/0X-文章名/article.md`
- `文章包/YYYYMMDD/0X-文章名/文章.md`
- `文章包/YYYYMMDD/0X-文章名/payload_template.json`（由转换器生成）
