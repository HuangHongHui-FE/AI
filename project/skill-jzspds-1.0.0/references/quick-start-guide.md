# 快速上手指南（Quick Start）

## 一句话用法

给素材（图片/视频/音频）或一句描述，说清「想怎么鬼畜」，即可得到成片示意或可执行的 FFmpeg/剪映制作脚本。

## 典型对话示例

### 示例 1：重复洗脑（直接出脚本）
- 用户：上传打喷嚏视频，「重复洗脑，强度 8，加字『阿嚏！』，BGM《卡农》高潮，抖音」。
- 处理：识别鬼畜点=打喷嚏瞬间 → 风格=重复洗脑 → 输出 JSON（timeline + subtitles + bgm + output + ffmpeg_command）。

### 示例 2：音 MAD
- 用户：「用这段台词做成音 MAD，配《姐就是女王》」。
- 处理：切音频按 BGM 节奏重排，输出切片重排 FFmpeg 命令 + 剪映卡点步骤。

### 示例 3：简单动态（直接出片）
- 用户：「把这张图做个摇头鬼畜短视频」。
- 处理：用 VideoGen 图生视频（主体摇头 + 抖动 + 变调）出示意短片，附转 GIF/时长提示。

### 示例 4：智能剧本
- 用户：「主题『社死瞬间』，帮我写个完整鬼畜视频剧本」。
- 处理：输出分镜 + 台词 + 音效 + 字幕时间轴 + BGM 建议 + 标题/标签/简介。

## 让效果更好的建议

- 说清素材里的「鬼畜点」：哪个动作/哪句台词最魔性。
- 强度给数字或「轻/中/狂」。
- 指定平台，字幕样式和时长更准。
- 要热点梗就明说「帮我搜当前热门梗」。

## 我产出的形式

- 成片示意短视频（VideoGen）
- 结构化 JSON 制作脚本（timeline/subtitles/bgm/output/ffmpeg_command）
- FFmpeg 完整命令
- 剪映分步操作
- 一键发布：标题 / 标签 / 简介

## 注意事项

- 不恶意丑化真实个人；AI 换脸须授权、不用于诈骗伪造。
- 不制作暴力/色情/政治敏感/人身攻击内容。
- BGM/素材注意版权，推荐无版权曲库。
- 成片默认 ≤60 秒，更长分段生成。
