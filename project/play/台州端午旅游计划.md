## 📅 Day 1 — 6月19日（周五·端午当天）

**主题**：到临海、逛古城、吃遍紫阳街

| 时间 | 安排 |
|------|------|
| **上午** | 高铁抵达**临海站**，打车/租车前往古城（约20分钟），办理入住 |
| **中午** | **紫阳古街**美食扫街，边逛边吃 |

### 🍜 紫阳街必吃清单（按顺序吃）：

| # | 美食 | 推荐店铺 | 说明 |
|---|------|----------|------|
| 1 | **海苔饼** | 紫阳街99号老店 | 咸甜酥脆，刚出炉的最香，买2个尝尝 |
| 2 | **蛋清羊尾** | 老街随处可见 | 蛋清打发油炸，外酥里嫩，撒白糖 |
| 3 | **麦虾** | 紫阳街老字号 | 临海版"面疙瘩"，汤鲜料足 |
| 4 | **糟羹** | 街边小店 | 米粉糊配各种料，临海人的乡愁 |
| 5 | **乌饭麻糍** | 紫阳街中段 | 端午时令甜品，软糯香甜 |
| 6 | **姜汁调蛋** | 古城周边 | 端午暖胃，台州特色 |
| 7 | **扁食** | 街边小摊 | 类似大馄饨，皮薄馅多 |

| 时间 | 安排 |
|------|------|
| **下午** | 吃饱后回民宿**午休1-2小时**（轻松游的核心就是不硬撑！） |
| **16:00** | 趁光线最好时逛**东湖**（免费/低价），亭台楼阁倒映水中，人少清静，适合拍照 |
| **17:30** | 登**台州府城墙（江南长城）**，黄昏时分光线柔和，俯瞰古城和灵江，游客也少了 |
| **晚上** | 回到紫阳街，**灯笼亮起后很美**，找一家临街小馆吃晚饭，喝点杨梅酒 |

> 🏮 端午当天紫阳街可能有包粽子、赛龙舟等民俗活动，留意现场公告。

## 📅 Day 2 — 6月20日（周六）

**主题**：天台山禅意一日游

| 时间 | 安排 |
|------|------|
| **上午 9:00** | 睡到自然醒，古城吃个悠闲早餐（推荐**炊饭+豆浆**的路边店） |
| **10:00** | 自驾前往**天台山**（约1小时车程） |
| **11:00** | 抵达**国清寺**（免费！），千年古刹，天台宗祖庭 |

### ⛩️ 国清寺 — 必看

- 隋代古刹，真古迹而非重建，古朴至极
- 寺内有**隋梅**（千年梅花树）、**七佛塔**、**大雄宝殿**
- 安静地走一圈约1-1.5小时，人少时非常治愈
- 素斋有名，但需提前确认是否开放

| 时间 | 安排 |
|------|------|
| **中午** | 天台县城吃午饭——**饺饼筒**（天台版春卷，馅料丰富）、**糊拉汰**（类似煎饼果子） |
| **下午 14:00** | **天台山大瀑布**（高325米，中华第一高瀑） |

### 🏞️ 天台山大瀑布

- 2024年全新升级，栈道平缓，步行强度不高
- 瀑布前拍照非常出片，水雾扑面很凉爽
- 游玩约2小时，不用爬到顶也能看到壮观景色

| 时间 | 安排 |
|------|------|
| **16:30** | 返程临海，回民宿休息 |
| **晚上 19:00** | **重头戏：新荣记总店晚餐** 🍽️（如果约到了的话） |

### 🥢 新荣记推荐菜（人均¥500-800档）

| 菜名 | 说明 |
|------|------|
| **沙蒜豆面** | 台州第一名菜，汤汁浓郁，必点 |
| **脆皮乳鸽** | 皮脆肉嫩，限时供应 |
| **鲳鱼饭** | 鱼肉鲜甜，米饭吸饱鱼汁 |
| **红糖糍粑** | 饭后甜品，完美收尾 |
| **临海糟羹** | 地方传统味 |

> 💡 约不到新荣记？备选：**荣小馆**（新荣记旗下亲民品牌，人均¥150，也在临海）或古城内 **老台州** 等本地菜馆。

## ⚠️ 端午出行特别提示

1. **住宿**：端午热门，**现在就订房**，临海古城民宿数量有限
2. **新荣记**：现在就可以打电话约了（0576-85227777），能约到是此行亮点
