# 🎋 台州一日游 · 临海古城美食精华

**适合人群**：周末快闪 / 中转路过 / 想吃想逛时间紧
**节奏**：紧凑但不赶，一天吃遍台州精华

---

## 🚄 交通

| 方式 | 说明 |
|------|------|
| **高铁** | 买到**临海站**，杭州出发约1.5h，宁波出发约40min |
| **站到古城** | 打车约20分钟，¥30左右 |
| **古城内** | 全程步行，所有景点步行可达 |

## 🗺️ 行程总览

```
临海站 → 紫阳街逛吃 → 台州府城墙 → 东湖 → 新荣记/荣小馆 → 返程hua
```

## ⚠️ 贴士

1. **早起出发**：一日游时间紧，建议买早上7-8点到临海的票
2. **穿运动鞋**：江南长城有台阶，平底鞋走石板路也舒服
3. **打包海苔饼**：现烤的和密封装两个口感，都买
4. **荣小馆免预约**：比新荣记好排，随到随吃，性价比高
5. **不去天台/仙居**：一日游时间不够跑远，临海古城集中且精华

---

> 🎯 一日游的核心逻辑：临海古城 = 台州文化心脏 + 美食集中地，半天逛完 + 半天吃透，不折腾、不赶路。
