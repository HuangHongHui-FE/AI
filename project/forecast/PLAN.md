# 板块涨跌预测 Skill 方案

> 目标：每个交易日收盘后跑一次，用公开接口抓当日行情/资金/消息，按固定框架给次日各板块方向打分，输出「涨/跌/震荡 + 置信度 + 理由 + 风险」。
>
> 定位：方向性研判工具，**不是投资建议**。隔夜黑天鹅不可预测，结果仅供观察市场结构。

## 二、数据源（全部 curl 公开接口）

| 数据 | 接口 | 备注 |
|------|------|------|
| A股ETF行情(实时/收盘) | `push2.eastmoney.com/api/qt/stock/get` 按 secid=1.515880 | 返回价/涨跌幅/量/额/开盘/最高/低 |
| A股板块多标的批量 | `push2.eastmoney.com/api/qt/ulist.np/get` 一次取多个 secid | 减少请求数 |
| 港股ETF行情 | 东财 secid=116.513120（港股前缀116） | 同上字段 |
| 基金估值 | `fundgz.1234567.com/js/<code>.js` | 当日盘中估值，含估算净值 |
| 北向资金 | 东财 `datacenter-web.eastmoney.com/api/data/v1/get` 北向流向 | 盘后才完整 |
| 主力净流入 | 东财板块资金流 `push2.eastmoney.com/api/qt/clist/get` | 个股主力净额聚合 |
| 隔夜美股指数/期货 | 新浪 `hq.sinajs.cn` 或东财 `secid=100.XSPX` 等 | 纳指/费半/美债/美元 |
| 财经电报/新闻 | 财联社电报、东财新闻 | curl 抓正文，给消息面判断 |

- **UA 伪装**：统一加移动端/浏览器 UA + Referer，规避限频（参考记忆 `[[cn-hotspot-via-curl]]`）
- **重试**：接口偶发限频，每个请求失败重试 2 次，指数退避
- **缓存**：当日抓到的原始 JSON 落到 `cache/YYYYMMDD/`，便于复盘和断点续跑

## 三、分析框架（五维打分）

每个板块按 5 维打分，每维 -2~+2，加权求和后映射到「涨/跌/震荡」。

| 维度 | 权重 | 数据依据 | 信号示例 |
|------|------|---------|---------|
| 1. 外盘/先行 | 0.25 | A50期指、纳指/费半、美债、美元 | 纳指大涨+A50升→成长板块加分 |
| 2. 资金面 | 0.25 | 北向、板块主力净流入连续N日趋势 | 主力连续3日净流入→加分 |
| 3. 技术面 | 0.25 | 相对5/10/20日线、量价、连涨/连跌天数 | 缩量站上5日线+动量→加分；连涨5日均值回归→减分 |
| 4. 情绪面 | 0.15 | 板块涨停股数、龙虎榜、舆论热度 | 涨停家数多→情绪高(短期正,过热负) |
| 5. 消息/政策 | 0.10 | 当日行业级利好利空(集采/补贴/制裁/并购) | 利好政策→加分；集采/制裁→减分 |

- 综合分 > +0.5 → **看涨**；< -0.5 → **看跌**；中间 → **震荡**
- 置信度：|综合分| 大 + 五维同向 → 高；方向不一致 → 低

## 四、Skill 文件结构

```
forecast/
├── PLAN.md                      # 本方案
├── skills/
│   └── market-forecast/
│       ├── SKILL.md             # skill 入口（流程编排）
│       ├── sectors.json         # 板块清单 + 代理标的 + secid
│       ├── fetch_quote.sh       # 抓行情(批量)
│       ├── fetch_flow.sh        # 抓北向/主力资金
│       ├── fetch_overseas.sh    # 抓隔夜外盘/期货
│       ├── fetch_news.sh        # 抓财经电报
│       └── score_template.md    # 五维打分输出模板
├── scripts/
│   └── run_forecast.sh          # 一键：抓数→落盘→喂给Claude分析→输出→归档
├── cache/
│   └── YYYYMMDD/                # 当次原始数据快照(quotes/flow/overseas/news)
└── results/
    ├── YYYYMMDD.md              # 当次预测结果(完整版)
    └── INDEX.md                 # 历史结果汇总表(时间倒序,只放方向+分数,方便横向对比)
```

`SKILL.md` 是给 Claude 读的流程说明：依次调用各 fetch 脚本落盘 → 读取缓存 → 按五维框架逐板块打分 → 套模板输出 → 归档到 results。

## 五、执行流程

**先判断时点**（以 A 股 15:00 为准）：

```
当前时间 < 15:00  →  盘中模式：预测「今日收盘」方向
当前时间 ≥ 15:00  →  收盘模式：预测「T+1」方向
```

### 通用步骤
1. **抓数**（`run_forecast.sh`）
   - 交易日判断（初版跳周末）
   - 批量抓板块代理标的行情 → `cache/YYYYMMDD/quotes.json`
   - 抓北向/主力资金 → `cache/YYYYMMDD/flow.json`
   - 抓隔夜外盘 → `cache/YYYYMMDD/overseas.json`
   - 抓当日电报 → `cache/YYYYMMDD/news.txt`
2. **分析**（Claude 读 SKILL.md）
   - 按当前模式选择打分框架
   - 逐板块五维打分，每条理由**带原始数据值 + 出处文件**
   - 报告末尾附「原始依据摘要」，摘录当日关键数据(北向/主力/外盘/涨停/电报)，指向 cache 快照

### 盘中模式（预测今日收盘）
- 用截至当前实时盘口 + 隔夜外盘（已确定）+ 昨日数据
- 五维调整：
  - 外盘/先行：用昨夜已收盘外盘（固定项）
  - 资金面：**当日实时**主力净流入、北向实时
  - 技术面：今日盘中走势相对昨收 + 5/10日线位置
  - 情绪面：截至当前涨停家数
  - 消息面：今日盘前+盘中已出消息
- 预测目标：今日收盘 vs 昨收 的涨跌

### 收盘模式（预测T+1）
- 用当日完整收盘数据 + 当夜外盘（美股/A50期货）
- 预测目标：T+1 收盘 vs T 收盘 的涨跌
3. **输出 + 归档**（见下）
   - 完整结果写 `results/YYYYMMDD.md`
   - 同时把每板块方向/分数追加到 `results/INDEX.md` 顶部（时间倒序）

### 历史汇总 `results/INDEX.md`（时间倒序，方便横向对比）

每行一个板块当次方向，按日期分组置顶。一眼看趋势演变：

```markdown
# 板块涨跌预测历史

| 日期 | 时点 | 半导体 | CPO | AI算力 | 港股创新药 | 恒生科技 | ... | 实盘 | 总结 |
|------|------|--------|-----|--------|-----------|---------|-----|------|------|
| 0716 | 盘中 | ▲中 +1.2 | ▲低 +0.6 | ▲高 +1.8 | ▼中 -1.0 | ▲低 +0.4 | ... | ▲ | 成长偏多 |
| 0715 | 收盘 | ▼中 -0.8 | ▲低 +0.5 | 震荡 0 | ▼高 -1.6 | ▼中 -0.9 | ... | ▼ | 防御 |
| 0712 | 盘中 | ▲高 +1.5 | ▲高 +1.6 | ▲中 +1.1 | ▲低 +0.3 | 震荡 0 | ... | ▲ | 全面偏多 |

> 图例：▲看涨 ▼看跌 △震荡；置信 高/中/低；数字=综合分。
> 时点：盘中=预测当日收盘 / 收盘=预测次日。
> 实盘列=该日实际收盘涨跌(▲/▼/平)，复盘时回填，用于算命中率。
> 点击日期进入当次完整报告。
```

- `run_forecast.sh` 跑完自动把当日每板块「▲中 +1.2」+ 时点追加为表格新行（插在首行数据行之上）
- 板块列顺序固定（按 `sectors.json`），缺数据的填 `—`
- 实盘列当天不填，T+1 收盘后回填，用于长期命中率统计
