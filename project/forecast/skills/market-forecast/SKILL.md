# 板块涨跌预测 Skill

预测 A 股/港股各板块方向，输出方向+置信度+可追溯依据，归档便于对比。

## 执行流程

1. **抓数**：`bash scripts/run_forecast.sh` —— 抓行情/外盘/资金/新闻落盘 `cache/YYYYMMDD/`，并打印时点判断
2. **判时点**：当前 <15:00 → 盘中，预测**今日收盘**；≥15:00 → 收盘后，预测**次日**
3. **读数**：读 `cache/YYYYMMDD/` 下 quotes.json(行情) / overseas.json(外盘) / flow.json(行业板块资金收盘聚合,可能缺) / flow_intraday.json(重点板块盘中逐分钟机构/游资/散户流入流出曲线,可能缺) / sentiment.json(全市场情绪:涨跌家数+涨停跌停+赚钱效应+情绪温度,可能缺) / earnings.json(各板块龙头中报业绩预告 + 未来N天A股预约披露日 + 美股巨头财报窗口) / news.txt(新闻,可能缺)
4. **当日实盘解读**：先用同一批数据解释"今日各板块为何这样涨跌"，表格给出 今日涨跌+机构/散户方向+原因，每条带原始值+出处 — 见下"当日实盘解读"
5. **逐板块五维打分**（见下），每条理由带原始值+出处文件 — 预测次日方向
6. **输出**：终端打印 + 落盘 `results/YYYYMMDD-HHMM.md`（**每次分析新建独立文档，文件名=日期+时分，如 20260716-1951；不覆盖、不追加**，因不同时刻抓的实时数据/A50期指会变，需独立留存）+ 套 score_template.md（{{DATE}} 填 `YYYYMMDD-HHMM`）+ 调 `python3 skills/market-forecast/md2html.py results/YYYYMMDD-HHMM.md` 生成同名 `.html`（红涨绿跌+表格斑马纹，便于浏览器对比）
7. **归档汇总**：往 `results/INDEX.md` 表格首行追加一行（日期列填 `MMDD-HHMM`，时点+各板块预测方向+总结，实盘列留空）；同日多次分析即多行
8. **T+1实盘回检**：每次分析时，回填 `INDEX.md` 中**上一次预测的目标日已收盘**那一行的「实盘」列——从 `cache/<目标日>/quotes.json` 取该日各板块收盘 pct，按 ▲(>+0.5%)/▼(<-0.5%)/△(中间)+涨跌幅 填入对应板块格，末尾「实盘」列汇总命中率=方向命中数/总板块数(▲▼算命中、△与▲▼互不算命中)。盘中预测今日收盘者：今日未收盘则跳过本步、留待收盘后或次日分析时回填；收盘后预测次日者：次日收盘后回填。每次预测文档末尾另起「上次预测回检」段，摘录上次预测方向 vs 本次抓到的实盘，点明命中的主线与落空的板块。

## 当日实盘解读

用抓到的数据解释今日盘面，按板块给涨跌+机构/游资/散户三方买卖方向+原因。维度同预测但视角是"归因"而非"前瞻"：
- **机构/游资/散户三方方向**：优先用 **flow_intraday.json** 取该板块末点(15:00)累计净额——**机构**=main(=superbig超大单+big大单)、**游资/大户**=medium(中单)、**散户**=retail(小单)；正值=净流入、负值=净流出。flow_intraday 缺该板块时退回 flow.json 收盘聚合，两者皆缺标"未取到"不反推。**注意：ETF本身无主力/散户拆分(东财ETF资金字段无效),故用东财行业板块代理(半导体→半导体板块、CPO→通信设备、AI应用→软件开发等)**
- **三方结构判断**：机构+散户同向流入=健康共振(最强信号)；机构流入+散户流出=主力吸筹(偏多)；机构流出+散户流入=主力派发(偏空)；游资(中单)大幅流入=短线投机热度，持续性存疑
- **资金流向动态**：差分 flow_intraday klines 看尾盘30分钟主力曲线斜率——尾盘主力抢筹(末段陡升) vs 加速出逃(末段陡降)，作为次日方向的前瞻信号
- **外盘传导**：昨夜美股/费半/纳指 → 今日A股成长科技联动；恒指期货 → 港股
- **盘口**：收阳/收阴、是否破今开、上下影线、量价配合
- **情绪温度**：sentiment.json 给全市场涨停家数/跌停家数/赚钱效应(涨家数占比)/情绪温度(涨停-跌停)，用于判断今日是普涨/普跌/分化及投机热度
- **消息**：news.txt 有相关消息则引，无则标注"盘面反推"
- 落盘理由带数值+出处，如"半导体-5.73%：费半-2.08%传导+机构累计净流出265亿/散户+131亿(机构派发,散户接盘) — overseas/flow_intraday.json"

## 五维打分（每维 -2~+2）

读 `skills/market-forecast/sectors.json` 知板块清单与代理标的。

### 1. 外盘/先行 (权重0.25) — overseas.json
- **A50期指**：跌→全A板块偏空(-)；涨→偏多(+)。A50反映今夜对明日A股预期，权重最高
- **恒指期货**：港股板块(港股创新药/恒生科技/港股互联网/恒生红利/港股金融)直接跟随
- **纳指/费半**：成长板块跟随，**半导体/CPO 尤其跟费半**；创新药跟纳指生物科技情绪
- 标普作大盘情绪参考
- 落盘理由要带数值，如"费半-2.08%(-2) — overseas.json"

### 2. 资金面 (权重0.25) — flow_intraday.json(主) + flow.json(辅)
- **盘中逐分钟三方角色流向（flow_intraday.json，优先用）**：重点板块逐分钟累计净流入，角色拆分 main(机构=超大+大)/superbig/big/medium(游资/大户)/retail(散户)。看两点：
  - **尾盘累计结构**：机构 vs 游资+散户 谁在流入流出。机构大幅流出+散户流入=派发(偏空)；机构流入+散户流出=吸筹(偏多)；三方同向=共振
  - **流向动态**：差分 klines 看每分钟增量，**尾盘最后30分钟**主力抢筹(末段主力曲线陡升)→次日看多加分；尾盘主力加速出逃(末段曲线陡降)→次日看空减分
  - 落盘理由带末盘累计值+动态，如"机构累计-265亿/游资+135亿/散户+131亿(机构派发,散户接盘) +尾盘主力继续出逃 -1 — flow_intraday.json"
- **flow.json 收盘聚合作辅**：东财行业板块主力净额/占比，flow_intraday 缺时用之；两者都缺才降级到 quotes 成交额反推
- **降级**：flow_intraday.json 与 flow.json 均限频时，用 quotes.json 成交额+涨跌方向近似（放量上涨=资金流入+，放量下跌=资金流出-），并标注"资金面数据缺失,以成交额反推，角色拆分不可用"

### 3. 技术面 (权重0.25) — quotes.json
- 当前仅有单日盘口(多日均线趋势待补历史抓取)。用盘口近似：
  - 收阳(price>prevclose)/收阴 / 是否守住今开(price vs open)
  - 上下影线(high/low vs price、open)
  - **是否放量**：盘中无昨日成交额基准时,用绝对量级+跌幅粗判——大跌且成交额显著(相对板块流通盘/日内活跃度)→**放量下跌**;微跌且成交额极小→**缩量抗跌**;大涨且成交额显著→**放量上涨**。**作为独立记录项**,在结果"原始依据摘要"按板块汇总放量/缩量/平量状态
  - 量价配合：大涨+放量(+2) / 大跌+放量(-2) / 缩量(幅度减半)
- 理由如"放量收阴破今开(-2) — quotes.json"

### 4. 情绪面 (权重0.15) — sentiment.json + quotes.json
- **全市场情绪**（sentiment.json，先看，定基调）：赚钱效应=涨家数占比，>60%偏热、<40%偏冷；情绪温度=涨停-跌停，正偏热负偏冷；涨停家数>50=投机过热(短线负值注意均值回归)
- **板块情绪**（quotes.json，板块自身）：板块涨跌幅+成交额，大涨+放量=板块情绪高，大跌+放量=恐慌/冰点
- 情绪用法：全市场赚钱效应<40%时，多数板块情绪面统一给负（系统性恐慌）；该板块若逆势抗跌或领涨 → 情绪面给正(资金抱团/逆势强)
- 大跌+放量=恐慌，短线可能超跌反弹→短线给负但标注"超跌反弹预期"；大涨+放量过热 → 短线正但标注"过热风险"
- 理由如"市场赚钱效应35%偏冷,板块-5.73%领跌情绪冰点(-1) — sentiment/quotes.json"

### 5. 消息/政策 (权重0.10) — earnings.json + news.txt
- **板块龙头业绩预告(最强事件,优先看)**：earnings.json 的 a_leaders 给各板块龙头(2-3只)已披露的中报业绩预告,按 INCREASEL 判预增/预减/扭亏
  - 龙头**预增/扭亏**(如五粮液+89%、北方稀土+112%) → 该板块消息面 **+1**(业绩兑现前资金埋伏/利好)
  - 龙头**预减/续亏**(如长安汽车-67%、招商蛇口-65%) → 该板块消息面 **-1**(业绩雷)
  - **背离警示**：预告与当日资金/盘面背离时必标——如龙头预增却机构派发(北方稀土+112%但机构-21.5亿)→"利好兑现出货",消息面给正但风险列标注;预减却逆势涨→"利空出尽/预期已消化"
- **财报事件(确定性高,优先于传闻)**：earnings.json 另给未来N天A股中报预约披露日 + 美股巨头财报窗口
  - 美股巨头财报前1-2日 → 相关A股板块提前反应：英伟达→算力/CPO/半导体、苹果→果链/消费电子、特斯拉→新能源车/智驾、Meta/Alphabet/亚马逊→AI应用/互联网
  - A股权重股中报披露日临近(earnings.json的a_share) → 当日/前日该板块波动放大，业绩预喜前可给正(资金埋伏)，但披露日本身不确定性高，给分不超±1并标注"财报事件"
- **电报/新闻**：news.txt 有则挑与该板块相关的当日消息(利好+/利空-)
- **降级**：news.txt 标"缺失"时，用盘面反推(板块异常大跌/大涨疑似有事件)，标注"消息面数据缺失,盘面反推"

## 综合与置信度

- 综合分 = Σ(维度分×权重)；数据缺失维度的权重**重新归一化**到其他维
- 综合分 > +0.5 → ▲看涨；< -0.5 → ▼看跌；中间 → △震荡
- 置信度：|综合分|≥1.2 且各维同向 → 高；|分|0.5~1.2 → 中；<0.5或各维分歧大 → 低

## 输出要点

- **次日预测按分组表格输出**（A股科技成长 / A股宽基防御周期 / 港股 三张表），每维格=分数+简短理由(≤15字)+出处，列：板块|代码|方向|置信|综合分|外盘|资金|技术|情绪|消息|风险 — 套 score_template.md 的三段表格，不再逐板块列表
- 每板块综合分 + 五维理由(带原始值+出处) + 一条风险
- 资金面理由须体现机构/游资/散户三方角色流向(吸筹/派发/共振)，优先用 flow_intraday.json 末点累计值+尾盘动态，不只主力净额
- 情绪面理由须引 sentiment.json 全市场赚钱效应/情绪温度，再叠加板块自身情绪
- 消息面理由优先引 earnings.json 板块龙头业绩预告(预增/预减,确定性高+背离警示)，再引美股财报窗口/news.txt 电报
- 报告末尾「原始依据摘要」摘录当日关键数据(盘面涨跌统计/外盘/资金三角色/情绪指标/财报事件/新闻状态)
- 「原始依据摘要」须含**是否放量**统计:按板块标 放量下跌/放量上涨/缩量抗跌/缩量收阴,数据源 quotes.json(成交额+涨跌幅)
- 最后「一句话总结」点明今日/明日谁偏多谁偏空
- 全程可追溯：每条理由指向 cache 快照文件

## 限制

- 技术面缺多日历史(均线趋势)，当前单日盘口近似，后续可补 fetch_history
- 资金/情绪/新闻易限频，降级时明确标注，不影响其他维
- sentiment.json 的涨停家数(f107)/跌停(f108)按东财市场级口径取值，含接近涨停未封板的近似与少量ST/20%板误判
- 不构成投资建议；隔夜黑天鹅(外盘/政策)不可预测
