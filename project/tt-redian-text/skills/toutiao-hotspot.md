## 触发条件

用户说「写热点文章」「今天发热点」「来几篇热点」「发一波」之类，要的是**当下实时热点**，不是用户指定主题。

**执行原则**：触发后**不再问任何澄清问题**，直接跑完整流程——抓榜 → 选点 → 去重 → 找图 → 抓事实 → 生成 → 自查 → 推草稿 → 写日志。中途的模糊判断（标题怎么起、CTA 选哪类、哪张图更贴、时段怎么排、知识增量讲哪个点）自己定。除非真正阻塞（接口全挂、所有图都下不下来、头条登录态失效且无法重登），才停下来报告。

---

## ⚠️ 调性红线：知识科普型，不是中年叙事

本号发到今日头条，调性是**知识科普型热点文**——每篇把热点事件 + 涉及的专业/行业/机制/历史讲透，帮读者涨知识。**不写微信那种「我愣了/我琢磨/我们这代人」中年感悟流水账**。头条读者要的是「原来如此」「涨知识」，不是「共情」。

每篇结构：**事件简述（1-2 段）→ 专业知识深挖（主体，讲透 ≥1 个专业知识点）→ 个人判断/类比 → 知识收口**。

**知识增量硬要求**：每篇须讲透 ≥1 个专业知识点（专业概念/行业机制/历史脉络/科学原理），通俗讲法把「为什么」说清楚。答不出专业知识点 → 弃写换题，不为凑数硬写。详见 [[toutiao-daily]]「知识增量硬要求」。

## ⚠️ 低创作度规避红线（参考微信官方四类，适配头条原创标）

头条对 AIGC/搬运也有限制（原创标机制），规则与微信低创作度不完全相同，但同质化/搬运/低信息量/低价值 AIGC 四类是通用判罚逻辑，逐类对照规避：

**一、同质化**（重复发表/框架一致/短期大量发表）。**规避**：标题不得「我X了」收尾；禁六段全套模板，三件套（编号小标题+每段引言+每段加粗）至多用两件；**每篇结构+排版 theme 须与近 5 篇不同形**。

**二、疑似搬运洗稿**（大篇幅复述、机械拼接、不含个人观点/知识增量）。**规避**：不能只「热点复述+套话感悟」，每篇须有**个人判断 + 知识增量**——对事件有自己的判断、类比、追问，并讲透一个专业知识点。

**三、低信息量**（简单拼凑、图文无关/看图说话、引用存疑数据、无依据夸大）。**规避**：每篇 ≥3 条可查证事实（人名/数字/时间/地点/引语），其中 ≥1 条带外部出处；选点后先 curl 抓新闻正文补事实；知识增量须有学科依据不臆测；自标存疑的细节一律删。

**四、低价值 AIGC**（直接用 AI 生成原文不改）。**规避**：每篇须**融入个人判断/知识增量**（独到分析、类比、专业讲解），而非照搬 AI 套话；口头禅跨篇去重，一周不重复。

**总则**：不过关的回炉重写或弃写，**不为凑数推残次品**。

## 选点规则（核心：不挑，自动取每平台 top2）

### 1. 抓多平台实时热榜

按 [[hotlist]] 抓。主路径 `node src/fetch-hot.js`（tophub 聚合，含百度/抖音/B站/贴吧等），tophub 没聚合今日头条时补 curl 头条官方 `toutiao.com/hot-event/hot-board/`。微博/知乎抓不到不补。

### 2. 每平台取热度最高的 2 条

- 头条：`data[]` 按 `HotValue` 降序，取前 2
- 抖音：`data.word_list[]` 按 `hot_value` 降序，取前 2
- B站：`data.trending.list[]` 按 `heat_score` 降序，取前 2
- 百度：`data.cards` 顺序即热度序，取前 2（百度无稳定热度数字，按榜单顺序）
- tophub 聚合的其它榜（贴吧/少数派/掘金等）：按各榜顺序取前 2 作补充池

→ 候选池最多 8-10 条。**不让用户挑，直接进下一步。**

### 3. 去重（默认不重复，极火爆热点可破例再写）

**a. 跨平台同主题合并**：不同平台同事件算同一条，合并保留热度最高那条的标题，只写一篇。Claude 自己判断同义。

**b. 历史已写过的不写**：扫所有 `logs/*.md` 的「话题」列 + `knowledge_point` 列。**注意话题列措辞常与今次选题不同**（如历史「台风巴威朝浙江来了」vs 今次「台风巴威又改路线了」），务必对候选选题的**关键实体词**（人名/事件名/地名）单独 `grep -h` 扫一遍：

```bash
# 全量话题列
grep -hE '^\| [0-9]' logs/*.md | awk -F'|' '{gsub(/^ +| +$/,"",$4); print $4}' | sort -u
# 关键实体词再扫，防漏判
grep -h '巴威\|晋江\|李建波' logs/*.md
```

候选话题若和历史上某篇同事件（语义相同即算），**该平台顺延取第 3 条**，再不顺延取第 4 条……直到拿到全新话题。每平台最终仍只出 2 条全新话题。

**c. 例外：极火爆热点可破例再写一篇**。满足以下任一继续写（一篇）：
- 跨 **3 个及以上平台**同时上榜（= 真全民热点，热度真实）
- 或单平台热度极高：头条 `HotValue ≥ 3000 万` / 抖音 `hot_value ≥ 1000 万` / B站 `heat_score ≥ 500 万`

破例再写时**必须换角度 + 换知识增量点**（不同于历史那篇的切入与讲解），不能复读旧文：

| 历史角度/知识点 | 这次换什么 |
|---|---|
| 防灾应对 / 路径预警 | 路径再变新进展 / 灾后重建 / 灾害成因机制 |
| 赛事结果 / 比分 | 球员表现 / 球迷反应 / 历史意义 / 战术机制 |
| 事件通报 | 后续追责 / 当事人回应 / 类似旧案对照 / 涉及规则 |

标题贴原词 + 带**新进展关键词**（「又改路线」「再被查」「晋级后」），让读者认出是同一热点最新一话而非旧文重发。

**同热点不无限重复**：历史已写过 **≥ 2 次**的挡掉顺延不再破例。**同一天若已跑过一批**：先读当日 `logs/YYYY-MM-DD.md` 看已发哪几条别撞今早选题。

### 4. 适性过滤（只挡写不了的）

不挑热点，但以下三类**写不出知识科普、直接挡掉顺延**：
- 游戏版本 / 充值活动（Steam夏促、和平精英派对、手游神装）
- 纯政策口号（「教育强国这样建设」「十五五规划」这类无故事无知识点的）
- 纯国际战况简报（俄乌伤亡数字、空泛外交表态）

其余一律照写——体育（讲战术/规则/历史）、民生（讲机制/规则）、物价（讲市场逻辑）、教育代际（讲制度）、社会事件（讲法律/机制）、人物争议（讲行业/历史）、自然灾害（讲成因/防灾）都行。**判断标准：能不能讲出一个专业知识点，能就写。**

### 5. 最终篇数（每日上限 3 篇）

去重 + 过滤后候选池可能 5-7 条，但**每日只发 ≤ 3 篇**——「短期大量发表」是同质化铁证，一天 5+ 篇 × 连续多天本身即触发。取候选池热度最高前 3 条写，余下记日志「**顺延次日**」，次日开跑前先读当日 log 把顺延的补进候选池再抓新榜。

**全部写的 ≤ 3 篇全推草稿，不人为再砍**——但每篇须过 `preflight.js` 硬门 + 自查 A/B/C 全套门槛，不过关回炉或弃写，不为凑数推残次品。

## 标题起名规则（贴原词 / 不贴原词两套池随机）

热点标题核心矛盾：贴原词蹭搜索/信息流流量，但连发易套路同质；不贴原词破套路有人味，但蹭不到流量。**两套池并存随机轮换**，不贴原词那条线靠正文 ≥3 带来源原词事实兜底信息量。

### 硬底线
- ✅ **贴原词池**：标题须含原词关键名词（人名/事件名/地名/数字）。
- ✅ **不贴原词池**：标题不出现原词，但**正文必须含原词事实**。不贴原词 ≠ 空喊抽象议题，标题要有事实内核锚点（人物/数字/场景/机制），不是「教育焦虑」纯虚词。
- 🚫 共用：不得「我X了」收尾（看懵了/愣了下/笑了/慌了/乐了/有点小激动/看很久）——AIGC 味铁证；不标题党（无「震惊/速看/刚刚」）；**≤30 字**（头条标题上限放宽，但建议 14-24 字信息流最优）。

### 轮换规则
- **两段随机**：写 `article.json` 前先抽池子（A 贴原词 / B 不贴原词），再从该池 20 骨架随机抽一个，避开近 5 篇 title_style。
- **比例建议**：池 A 为主蹭流量（约 7 成），池 B 偶尔破套路（约 3 成），别连续多篇走池 B。
- **池 B 兜底**：标题不贴原词时，正文必须含原词 ≥3 带来源事实，否则判低信息量回炉。
- **记日志**：`title_style` 格式 `贴-骨架名` / `离-骨架名`，格式不可变。
- **同形即重起**：抽到的与近 5 篇撞，换再抽。
- **情绪尾限频**：「我X了」尾被判低创，一周至多 2 篇带情绪尾，`recent.js` 已扫日志统计，≥2 即警告本篇禁用。
- **调性签名防隐性同质**：`recent.js` 把标题骨架归类到调性（反问/对仗/留白/转折/对照/递进/场景/数据/断言），某调性 ≥3 篇即标 ⚠ 扎堆，本篇标题须换到该调性以外。

### 自检
1. 贴原词池 → 标题有原词？不贴原词池 → 正文有原词事实？缺则重起。
2. 是不是「我X了」收尾？是 → 重起。
3. 本篇 `title_style` 与近 5 篇撞吗？撞 → 换风格重起。
4. 不贴原词池 → 标题是空喊抽象议题还是有人物/数字/场景/机制锚点？空喊 → 重起。

## 开头钩子轮换（20 式随机）

开头是 AIGC 味最重的区，做 20 式开头钩子随机轮换，每篇抽一种、与近 5 篇不撞、记日志。**钩子是切入方式，事实仍须 1-2 段讲清**（先事实后判断不变），钩子只是「第一句怎么进事实」。

| # | 钩子 | 写法 | 示例 |
|---|---|---|---|
| 1 | 场景代入 | 一个具体场景起 | 「异国路边，导航没了，只剩方向盘转。」 |
| 2 | 数据冲击 | 关键数字起 | 「三十多个小时，一辆智能车从智能变智障。」 |
| 3 | 反常识断言 | 一句反常识 | 「买车这事，现在买的不全是车。」 |
| 4 | 原话开场 | 当事人一句起 | 「『车是我买的，凭什么服务器一断就变半废。』」 |
| 5 | 提问起 | 抛一个问题 | 「智能车的命脉，到底在谁手里？」 |
| 6 | 时间锚点 | 时间切入 | 「7月22日，一位开新能源车跨境自驾的车主发了条视频。」 |
| 7 | 身份代入 | 某类人切入 | 「开新能源车的中年人，最近都被一条新闻扎了一下。」 |
| 8 | 矛盾呈现 | 反差起 | 「钥匙在手，车却开不动智能——这事就发生在跨境自驾路上。」 |
| 9 | 悬念缺口 | 留个缺口 | 「一辆开不坏却用不动的车，停在了异国路边。」 |

## 发文流程（复用 [[toutiao-daily]]）

对每条选题，按顺序：

0. **生成前读已用维度（必做）**：`node src/recent.js 5`，输出近 5 篇十一维已用值 + 撞形扎堆警示 + 调性签名 + 情绪尾统计。**把整段输出拼进生成 prompt 开头**作「本篇须避开的已用维度」。撞形扎堆标 ⚠ 的维度强制换值。

1. **找图**：必应图片 `cn.bing.com/images/async` curl 搜 + 下载到 `input/NN-话题.jpg`（头图），**并多下 2-3 张内文图**到 `input/NN-话题-内图1.jpg` 等，供正文多处插入。Read 预览确认相关性。详见 [[toutiao-daily]]「找图流程」。多篇可并行搜图下载，看图串行。

2. **抓正文取事实（必做，根治低信息量）**：选点后不能只靠榜单标题脑补，须 curl 抓 2-3 条新闻源正文，摘出**人名/数字/时间/地点/当事人原话**。**多源兜底链**（搜狗新闻命中率最高，按顺序试）：

   ```bash
   UA="Mozilla/5.0 (iPhone; CPU iPhone OS 16_0) AppleWebKit/605.1.4 Mobile/15E148 Safari/604.1"
   enc=$(python3 -c "import urllib.parse,sys;print(urllib.parse.quote(sys.argv[1]))" "关键词")
   # ① 搜狗新闻（优先，国内新闻收录最好）
   curl -sL -m 15 -A "$UA" "https://news.sogou.com/news?query=$enc&mode=sort" -o /tmp/sg.html
   # ② 必应搜索
   curl -sL -m 15 -A "$UA" "https://cn.bing.com/search?q=$enc" -o /tmp/bing.html
   # ③ 百度 m 站（最后兜底，常返验证码）
   curl -sL -m 15 -A "$UA" -H "Referer: https://m.baidu.com/" "https://m.baidu.com/s?word=$enc" -o /tmp/bd.html
   # python 正则按句切分筛含关键词的句子，看有人名/数字/时间/原话
   ```
   三源都不命中的，按 C 段③事实不足弃写换题，不硬凑。

   **硬性标准**：每篇 ≥3 条可查证事实，其中 ≥1 条带外部出处。**另：知识增量硬要求**——选题后先想清楚「这篇要讲透哪个专业知识点」，答不出弃写换题。

3. **生成 article.json**：按 [[toutiao-daily]] 的长度/结构/调性/反 AI 味/JSON 字段要求，写到 `output/YYYY-MM-DD/NN-话题/article.json`。CTA 按主题选型。**结构每篇须与近 5 篇不同形**。**生成时须避第 0 步 recent.js 输出的已用维度，撞形扎堆的维度强制换值**。**`knowledge_point` 字段必填**（本篇讲透的专业知识点）。

4. **推草稿前硬门（必做）**：`node src/preflight.js "output/YYYY-MM-DD/NN-话题/article.json"`，grep/正则程序化判定——标题「我X了」情绪尾、≤30 字、digest≤100、ASCII 双引号「」、正文外链、存疑词、六段全套、字数 800-1200、禁用词、AI 金句句式≥3。任一 FAIL 即 exit 1 拒推，回炉改对应段落再扫。通过硬门才进下一步。**自查 A/B/C 清单仍要逐条过，preflight 是兜底不是替代**。

5. **自查**（写完每篇必做，见下。A 痕迹 + B 头条规范 + C 低创作度四类硬否决逐类扫，不过回炉重写或弃写，不可跳过）。

6. **半自动发布**（头条无草稿API，全自动存草稿做不到，见 [[toutiao-daily]]「现状天花板」）：`node src/publish.js --from-json "output/YYYY-MM-DD/NN-话题/article.json" --image "input/NN-话题.jpg" --out-dir "output/YYYY-MM-DD/NN-话题/"`。脚本自动：关 AI 抽屉遮罩 → 填标题（textarea，type 逐字）→ 填正文（`.ProseMirror`，真实剪贴板 Meta+V 粘贴 HTML）→ 保持浏览器开 5 分钟。**用户手动两步**：①封面区点「单图」上传 `output/.../cover.jpg`（file input 隐藏，脚本传不了）②点底部「预览并发布」发布。**串行，不能并行**——Playwright 多实例互踩。每篇发布后用户回话「NN发完」再推下一篇。

7. **写日志**：`logs/YYYY-MM-DD.md`，每篇记标题 / 话题 / knowledge_point / 时段建议 / 十一维已用值（title_style / 收口方式 / 收口句式 / 开头钩子 / 结构配方 / 叙事口吻 / 切入角度 / 段间衔接 / cta提问类型 / 格式组合 / theme / 口头禅）。余下未写的候选记「顺延次日」。**日志格式不可变——recent.js 靠这些行解析**。

文件编号 `NN` 从 `01` 起，按「头条2条 → 抖音2条 → B站2条 → 百度2条」顺序，去重/过滤后空缺不补位、顺延连续编号。

## 自查清单（写完每篇必过，不过则重写）

### A. AI 痕迹自查（目标：像真人知识科普长文）

逐条扫 `body_markdown`：

- [ ] **字数 800-1200**：去 markdown 符号后纯文字字数，不足 800 扩写、超过 1200 精简。
- [ ] **≥3 条可查证事实且 ≥1 条带来源**：至少 3 处具体事实（人名/数字/时间/地点/原话），其中 ≥1 条有外部出处（媒体名/机构名/时间）。生活常识/通用科普不算可查证事实。
- [ ] **知识增量硬要求**：讲透 ≥1 个专业知识点（专业概念/行业机制/历史脉络/科学原理），有学科依据不臆测。答不出 → 弃写换题。
- [ ] **先介绍热点再判断**：开头 1-2 段把事件讲清楚，个人判断/类比放在事实与知识之后，判断占比 ≤ 事实+知识。
- [ ] **内文插图 2-3 张**：正文多处用 `![图说明](input/NN-内图1.jpg)` 插入热点相关图，图说明具体有信息增量。
- [ ] **含个人判断增量（非搬运洗稿）**：有自己的判断/类比/追问，非纯复述新闻+套话。
- [ ] **融入知识讲解（非照搬 AIGC）**：把专业知识点讲透，非 AI 套话原文照搬。
- [ ] **框架不与近 5 篇一致**：结构 + theme 须与近 5 篇不同形。
- [ ] **开头钩子轮换**：20 式随机抽一种，与近 5 篇不撞，记日志。
- [ ] **结构配方轮换**：20 套随机抽一套，记日志。
- [ ] **叙事口吻轮换**：20 套随机抽一种，记日志。
- [ ] **切入角度轮换**：20 套随机抽一种，记日志。
- [ ] **段间衔接轮换**：20 套随机抽一种主基调，记日志。禁用词零容忍。
- [ ] **cta提问类型轮换**：20 类随机抽一种，记日志。
- [ ] **格式元素组合轮换**：17 种抽 4-6 种组合，记日志。多用 callout/stat/表格/有序列表。
- [ ] **无六段全套**：三件套至多用两件。
- [ ] **标题不以「我X了」收尾**。
- [ ] **标题骨架轮换**：40 骨架随机抽一个（贴/离），与近 5 篇不撞，记日志 `title_style`。
- [ ] **标题贴原词**（贴原词池）：标题有原词关键名词。不贴原词池 → 正文兜原词事实。
- [ ] **口头禅跨篇不重复**：与近一周已发篇不撞，撞了替换。

- [ ] **收口句式跨篇不撞**：判断式金句的句式骨架也纳入日志去重。
- [ ] **排版 theme 跨篇轮换**：`publish.js` 自动随机抽避开近 5 篇，Claude 不必指定；日志记实际所用 theme。

- [ ] **段落长短不齐**：6 段里至少 1 段只 1 句、1 段 6-8 行，不每段等长。

- [ ] **标题**：≤30 字，有钩子但不标题党。贴原词/不贴原词两套池随机。
- [ ] **摘要 digest**：≤100 字，不含换行、不含外链。
- [ ] **正文无外链**：`body_markdown` 里不能有 `[文字](url)` 正文链接（头条正文超链接会被洗）。引用来源用文字描述。
- [ ] **图片合规**：封面 1:1 正方形、正文图 < 10MB、JPG。不盗用带明显水印的图。
- [ ] **无诱导违规词**：不含「转发抽奖」「集赞」「强制分享后可见」等。
- [ ] **无敏感红线**：不涉政治人物评价、不涉医疗诊断/处方、不涉金融具体投资建议（金价跳水可写机制不能写「建议买入」）、不涉未审案件定性（用「涉嫌」「被刑拘」原样转述，不预判）。命中即换角度或弃写。
- [ ] **标点**：全中文标点，无中英混用逗号。无错别字。
- [ ] **加粗/引言/分隔符**：`**加粗**` 2-4 处、`> 引言` 0-1 处、`---` 分章节，不过度。三件套不得同时出现。
- [ ] **JSON body 引号**：`body_markdown` 引号一律中文「」，不用 ASCII 双引号。

不合格 → 改到合格再推草稿。

### C. 低创作度四类硬否决（发文前逐篇必过，不过即回炉重写或弃写）

**① 同质化**
- 否决：个人增量 + 知识增量占比 < 公共事实段。全网同话题都在写时，个人增量+知识增量须明显盖过公共事实才发。
- 否决：结构/收口/theme 与近 5 篇撞形。

**② 搬运洗稿**
- 否决：复述媒体/他人报道的段落 ≥2 段且无个人增量+知识增量兜底，弃写。
- 否决：单篇引用他人原话 >3 句且无自己分析。
- 改：复述段必须跟「个人判断/知识讲解」绑定，非孤立复述。

**③ 低信息量**
- 否决：自标存疑的细节一律删——「没法证实」「据传」「疑似」「据说」带出的具体细节必须删或改成可查证公开事实。
- 否决：可查证事实（带来源）<3 条，或用生活常识凑数。
- 否决：讲不出 ≥1 个专业知识点（知识增量硬要求）。

**④ 低价值 AIGC**
- 否决：全篇 AI 味金句句（「X 比 Y 更真/更重」「不是 A 是 B」「A 的尽头是 B」）≥3 处。
- 否决：无具体知识讲解/个人判断，纯议论。

**执行**：生成 article.json 后、推草稿前，逐类扫。命中任一否决 → 回炉改对应段落再扫；改不动弃写，不为凑数推残次品。

## 已知坑

1. **头条无官方草稿箱 API + 自动保存不触发**（2026-07-27 实测天花板）：草稿/发布统一走 `POST /mp/agw/article/publish`，带 `a_bogus`+`msToken` 反爬验签（脚本无法生成，直接调返 7050）；编辑页无「存草稿」按钮，「草稿将自动保存」在自动化下不触发。**全自动存草稿做不到**，故半自动：publish.js 自动填标题+正文到 `.ProseMirror`，用户手动传封面+点预览并发布。详见 [[toutiao-daily]]「现状天花板」。登录态存 `.auth/toutiao.json`，`npm run login` 扫码（cookie 轮询检测）。
2. **Playwright 要 Node 20+**：Node 18 报错，`.nvmrc` 写 20，跑前 `nvm use 20`。
3. **publish.js 选择器首篇现场调**：头条编辑页 DOM 无法文档阶段确定，`--inspect` 探真实 DOM 改 `S` 对象。
4. **正文富文本粘贴**：`insertHTML` 可能被 React/prose-mirror 编辑器拒，回退设 `innerHTML` 或现场改 clipboard paste。
5. **去重要 grep 实体词不能只比对完整话题串**：历史日志话题列措辞常与今次不同，务必对候选人名/事件名/地名单独 `grep -h` 扫一遍。
6. **头条时政外交话题慎写**：写知识科普易踩政治人物评价红线，选点时宁可顺延换 top4，不要硬写。

## 不要做

- 不跨天重复选题（每次开跑先扫 `logs/`；极火爆跨 3 平台热点除外，按规则 c 换角度+换知识点可破例再写一篇）
- 不为凑数写适性过滤挡掉的话题
- 不跳过自查/preflight 直接推（自查是发文前最后一道关）
- 不对历史已写 ≥2 次的热点再破例
- 不定时任务（用户喊才跑）
- 不照搬微信「中年叙事」调性，头条版走知识科普
