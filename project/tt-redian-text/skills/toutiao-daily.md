## 文章生成要求

### 长度与结构
- 800-1200 字（下限 800 必须达到，用具体细节/事实/知识铺开，不堆废话）
- 结构灵活 2-6 段，可用 `##` 副标题（副标题要有内容），也可不分小标题纯自然段。**每篇结构须与近 5 篇不同形**。
- **禁六段全套**：`## 一~六` 六段 + 每段 `>` 引言 + 每段 `**加粗**` + 结尾「讲真」收口——三件套同框=同质化铁证。三件套至多用两件。
- 段落长短不均（1-8 行穿插），不要每段等长——等长是 AI 痕迹。

### 头条知识科普调性（核心，区别于微信中年叙事）
- **事件简述 → 专业知识深挖 → 个人判断 → 知识收口**。
  - 开头 1-2 段把热点事件讲清楚（什么事/谁/何时何地/经过/结果/为何重要）。
  - 主体段把热点涉及的**至少 1 个专业知识点**讲透（见下「知识增量硬要求」）。
  - 个人判断/类比放在知识之后，占比 ≤ 知识段。
  - 收口给一个知识落点或判断，不空喊。
- 不写「我愣了」「我琢磨」「我们这代人」中年感悟流水账。头条读者要的是「涨知识」，不是「共情」。
- 有判断有落点，不端着说教，不贩卖焦虑。

### 知识增量硬要求（头条版核心门槛）
- 每篇须讲透 **≥1 个专业知识点**——把热点背后的专业概念/行业机制/历史脉络/科学原理讲明白，通俗讲法把「为什么」说清楚。
  - 写「某新能源车跨境被远程锁车」须讲清：车机云端控制权机制、智能车 OTA 权限边界、车主 vs 厂家控制权归属。
  - 写「某金融事件」须讲清：涉及的产品/规则/资金链。
  - 写「某自然灾害」须讲清：灾害成因机制/历史同类/防灾原理。
- **生活常识 ≠ 知识增量**：「细菌会繁殖」是结论不算；「西瓜切开后糖水分成温床，常温下细菌两小时翻倍」带原理才算。
- 知识须有学科依据（可查证的科学/行业常识，非臆测），不编造数据/原理。
- **答不出专业知识点 → 弃写换题**，不为凑数硬写。

### 事实增量（必做，否则判低信息量）
- **先介绍热点，再写判断**：开头 1-2 段必须把事件讲清楚，不能上来就个人感受。
- **每篇 ≥3 条可查证事实**：具体人名/数字/时间/地点/当事人原话，其中 **≥1 条带外部出处**（媒体名/机构名/时间，如「中新网7-18」「央视报道」）。
- 热点文章尤须先 curl 抓新闻正文补事实（见 [[toutiao-hotspot]]「抓正文取事实」），不能只靠榜单标题脑补。例：写「纯国产卡训出万亿模型」须答出哪家公司、卡型号、模型名、参数量、耗时、对标国外哪档——答不出说明事实没抓够，别发。

### 内文插图（2-3 张）
- 除封面外，正文加 2-3 张热点相关图（现场/人物/数据/对比/机制示意），在 `body_markdown` 用 `![图说明](input/NN-话题-内图1.jpg)` 标记插入位置。
- `src/publish.js` 推草稿时自动上传替换。图说明用一句具体说明（「重庆垮塌救援现场」「茅台出厂线」），不要空 alt。

### 反 AI 味清单
- 删禁用词：「值得注意的是」「总而言之」「此外」「综上所述」「综上」「在当今社会」「不仅如此」「不仅而且」「既...又...」「毋庸置疑」「众所周知」「由此可见」「应该说」「某种程度上」。
- 不要工整排比和对仗；偶尔一段只一句话；偶尔用省略号结尾。
- 开头不用「在快节奏的现代社会中...」「随着...的发展」。
- 标题不「我X了」收尾（看懵了/愣了下/笑了/慌了/乐了/有点小激动）。
- **跨篇去重口头禅**（一周不重复）：`讲真` `我说一句实在的` `咋说呢` `说白了` `说真的` `退一步说` 等。每篇用到的记日志，下一篇避开。

### 标点与高亮
- `**加粗**` 2-4 处情绪/知识高点；`> 引言` 0-1 处冲击力金句（与编号小标题、每段加粗不同时出现）；`---` 分章节。
- 全中文标点，无中英混用逗号。`body_markdown` 里引号一律用中文「」，**不用 ASCII 双引号**（会破坏 JSON 解析）。

## 脚本用法

> 所有命令在项目根目录跑，前置 `source ~/.nvm/nvm.sh && nvm use 20`。代码在 `src/`，日常发文不碰代码。

### 抓热榜
```bash
node src/fetch-hot.js          # → hot.json，tophub 聚合多平台
```
头条榜缺失时补 curl，详见 [[hotlist]]。

### 生成前读近 N 篇已用维度（喂 prompt 做轮换去重，必跑）
```bash
node src/recent.js 5           # 输出近 5 篇十一维已用值 + 撞形扎堆警示 + 调性签名 + 标题情绪尾统计
```
把整段输出拼进生成 prompt 开头作「本篇须避开的已用维度」，撞形扎堆标 ⚠ 的维度强制换值。

### 推草稿前硬门（必跑，FAIL exit 1 拒推）
```bash
node src/preflight.js "output/YYYY-MM-DD/NN-话题/article.json"
```
程序化检查：标题情绪尾/字数（标题≤30、摘要≤100）/六段全套/存疑词（据传/疑似/据说）/禁用词/AI 金句句式/ASCII 双引号/正文外链/字数 800-1200。任一 FAIL exit 1，回炉改对应段落再扫，不可跳过。

### 推头条草稿/发布（Playwright，半自动）

> ⚠️ **现状天花板（2026-07-27 实测确认）**：今日头条**无官方草稿箱 API**，草稿/发布统一走 `POST /mp/agw/article/publish`，带 `a_bogus`+`msToken` 反爬验签（每次不同，脚本无法生成），直接调 API 不可行（返回 7050 保存失败）。编辑页无「存草稿」按钮，页面提示「草稿将自动保存」但自动保存在自动化下不触发（等 60 秒/真实粘贴/paste 事件/点预览都不发保存请求）。**全自动存草稿箱在头条技术上做不到**。故采用**半自动**：脚本自动填标题+正文到编辑器，用户手动上传封面 + 点「预览并发布」发布。

```bash
# 首次登录（扫码，cookie 轮询检测自动保存，无需按 Enter）
node src/publish.js --login

# 单篇 dry-run（只生成封面+HTML预览，不开浏览器）
node src/publish.js --from-json "output/YYYY-MM-DD/NN-话题/article.json" --image "input/NN-话题.jpg" --out-dir "output/YYYY-MM-DD/NN-话题/" --dry-run

# 单篇半自动发布（填标题+正文到编辑器，保持浏览器开 5 分钟，手动传封面+点预览并发布）
node src/publish.js --from-json "output/YYYY-MM-DD/NN-话题/article.json" --image "input/NN-话题.jpg" --out-dir "output/YYYY-MM-DD/NN-话题/"

# 探编辑页 DOM（打印 input/contenteditable/button，自动退出，不交互）
node src/publish.js --from-json ... --image ... --out-dir ... --inspect
```

publish.js 自动完成：关 AI 助手抽屉（`.byte-drawer-mask` 遮罩会挡编辑区点击，重试 60 次卡死）→ 填标题（`textarea[placeholder*="文章标题"]`，keyboard.type 逐字触发 React input 事件，fill 不触发）→ 填正文（`.ProseMirror`，grant 剪贴板权限 + 写 HTML 到 clipboard + Meta+V 真实粘贴，让 ProseMirror paste handler 真正处理 state；insertHTML/dispatchEvent paste 只改 DOM 不更新 ProseMirror state，自动保存不触发）→ 保持浏览器开 5 分钟等手动操作。**用户手动两步**：①封面区点「单图」上传 cover.jpg（file input 隐藏，脚本无法自动传）②点底部「预览并发布」发布。

## 头条号登录态维护（Playwright）

登录态存 `.auth/toutiao.json`（Playwright storageState，`.gitignore` 已忽略）。

### 首次登录
```bash
node src/publish.js --login
```
启动有头 chromium 打开 `mp.toutiao.com` 首页，浏览器扫码登录头条号，脚本**轮询 cookie 检测**（URL 离开 login/sso/passport 且 title 非 404 且出现 sessionid/sso_uid 等登录 cookie 才保存，240 秒超时回退手动按 Enter）。⚠️ 不要用 URL 变化检测（404 页 URL 也满足条件会误判保存空态，已踩过，cookie 数 0）。

### 登录态失效（cookie 过期/被踢）
推草稿时报「未登录/跳登录页」→ 重跑 `node src/publish.js --login` 刷新登录态。storageState 一般维持数天到数周，失效再登。

### Node 版本与 Playwright
- **Node 20+**（`.nvmrc` 写 20，Playwright 1.62 要 Node 20），跑前 `source ~/.nvm/nvm.sh && nvm use 20`。
- **macOS 13 arm64** 装 `playwright@1.48`（1.62 的 chromium build 不支持 mac13-arm64，报 "does not support chromium on mac13-arm64"）。`package.json` 已固定 `playwright: 1.48.0`，`npx playwright install chromium`。

### 选择器调试（首篇必跑一次）
头条编辑页 DOM 选择器无法在文档阶段确定，`src/publish.js` 顶部 `S` 对象放了候选选择器（标题输入框/正文富文本编辑器/封面上传 input/存草稿按钮）。首篇发布时：
1. 先 `--inspect` 打开编辑页暂停，用 Playwright Inspector 看真实 DOM。
2. 把确认的选择器改进 `src/publish.js` 的 `S` 对象。
3. 正式 `node src/publish.js ...` 推草稿，终端打印每步结果，失败哪步报哪步。

正文贴法：聚焦富文本编辑器 → `document.execCommand('insertHTML', false, html)` 贴正文 HTML；失败回退直接设 `innerHTML`。封面上传：`input[type=file]` 的 `setInputFiles`。存草稿：点「存草稿」按钮。

## 找图流程

用户给主题（或自动选点后），Claude 自己搜图下载到 `input/NN-话题.jpg` + 2-3 张内文图。

### 1. 搜图（必应图片 async 接口最稳）
```bash
UA="Mozilla/5.0 (Macintosh; Intel Mac OS X 10_15) AppleWebKit/605.1.4 Mobile/15E148 Safari/604.1"
enc=$(python3 -c "import urllib.parse,sys;print(urllib.parse.quote(sys.argv[1]))" "主题词")
curl -s -m 12 -A "$UA" "https://cn.bing.com/images/async?q=$enc&first=1&count=35&mmasync=1" -o /tmp/bing.html
python3 -c "import re;h=open('/tmp/bing.html').read();print('\n'.join(re.findall(r'murl&quot;:&quot;([^&]+)&quot;',h)))"
```
备用：360 图片 `https://image.so.com/j?q=<URL编码>&sn=0&pn=30`（json `list[].img`）。

### 2. 下载到 input/
```bash
curl -sL --max-time 30 -H "User-Agent: Mozilla/5.0 ... Chrome/120.0.0.0 ..." \
  "<候选URL>" -o "input/NN-话题.jpg" -w "HTTP:%{http_code} size:%{size_download}\n"
```
验收 HTTP 200 + >30KB。403/404/过小立刻换下一个候选 URL，不回头问用户。新浪图床防盗链把 Referer 换 `https://www.sina.com.cn/`。

### 3. 看图确认相关性
用 `sharp.resize(900)` 生成预览版 Read 看一眼，确认图的人/物/场景跟主题对得上。下错图换下一个候选。**不跳过**。

### 4. 并行优化
N 个主题并行搜图+并行下载（一条消息发 N 个 curl）。看图串行（一次 Read 一张）。

## 已知坑（2026-07-27 实测）

1. **草稿保存天花板**：头条无官方草稿 API，草稿/发布统一走 `POST /mp/agw/article/publish`，带 `a_bogus`+`msToken` 反爬验签（脚本无法生成），直接调返回 7050 保存失败。编辑页无「存草稿」按钮，「草稿将自动保存」在自动化下不触发（等 60 秒/真实粘贴/点预览都不发保存请求）。**全自动存草稿箱做不到，只能半自动**（脚本填标题+正文，手动传封面+点预览并发布）。
2. **正文粘贴必须真实剪贴板**：`insertHTML`/`dispatchEvent(paste)` 只改 DOM 不更新 ProseMirror state，自动保存不触发；必须 `grant 剪贴板权限 + navigator.clipboard.write HTML + Meta+V` 让 ProseMirror paste handler 处理 state（已验证 textLen 1246 字符填入）。
3. **AI 助手抽屉遮罩**：编辑页加载后右侧 AI 抽屉的 `.byte-drawer-mask` 挡住整个编辑区，标题 click 会重试 60 次卡死。publish.js 已加自动关抽屉（点 mask + Escape）。
4. **编辑页 URL 与选择器**（已确认）：编辑页 `https://mp.toutiao.com/profile_v4/graphic/publish`（不是 profile_v4_graphic/publish，那个 404）；标题 `textarea[placeholder*="文章标题"]`（placeholder="请输入文章标题（2～30个字）"）；正文 `.ProseMirror`；后台首页 `profile_v4/index`（不是 profile_v4_index/home）。
5. **Cmd+S 危险**：会触发 `POST /article/publish`（发布，不是存草稿），已从 publish.js 去掉，别加回。
6. **draft_save 端点全 404**：`/mp/agw/creator_center/draft_save`、`/mp/agw/article/draft_save` 等猜测端点全 404，头条无独立草稿保存端点。
7. **登录态检测**：必须 cookie 轮询（sessionid/sso_uid 出现才保存），不能用 URL 变化（404 页 URL 也满足条件误判保存空态，cookie 数 0）。
8. **Playwright 版本**：macOS 13 arm64 装 `playwright@1.48`（1.62 的 chromium build 报 "does not support chromium on mac13-arm64"）。Node 20+。
9. **封面上传 file input 隐藏**：编辑页 `input[type=file]` 数量 0（隐藏/动态），脚本无法自动传封面，必须手动点「单图」上传 cover.jpg。
10. **sharp 中文渲染**依赖系统字体（PingFang SC），文字渲染失败回退无文字封面，不挂管线。
11. **JSON body 内引号一律用中文「」**，ASCII 双引号会破坏 JSON 解析。
12. **头条原创标/AIGC 声明**：头条对 AIGC 有「AI 生成」声明机制，本流程走「AI 辅助 + 大量个人知识增量」路线，不打 AI 标。细则首篇发布时查证补入。
