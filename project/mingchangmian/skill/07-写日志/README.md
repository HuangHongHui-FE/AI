# 07 写日志

> **输入**：`06-出物料` 的产物路径 + 本篇的素材来源（BV号 / 时间码，或流程 B 的素材文件名 + 钩子段）
> **产出**：`logs/YYYY-MM-DD.md` 追加一行
> **可扩展点**：加字段（发布回填、阅读量、CTR、二次改写记录）就往右边加列，改本文件的表头

---

## 这一步做什么

每出一篇物料追加一行日志。日志不只是记录 —— 它同时是 **`01-选题` 的去重依据**和 **BV号/时间码的素材库**。

## 记什么

写到 `logs/YYYY-MM-DD.md`，每篇记一行：

| 编号 | 标题 | 名场面 | BV号 + 时间码 | 物料 | 时段建议 |
|---|---|---|---|---|---|

- **名场面**：`01-选题` 的去重脚本按这一列扫（`grep -hE '^\| 0[0-9]' logs/*.md | awk -F'|' ...`），所以这列必须填，且用能唯一识别这一场的写法
- **流程 B 也写同样的列**：把「素材文件名 + 钩子时间段」填进 `BV号 + 时间码` 那一列
- **物料**：填 `output/YYYY-MM-DD/NN-名场面/`（`06-出物料` 会把 `发布物料.md` 放在这里）
  - ⚠️ 这一列**原来是 `media_id`**（推草稿返回的），2026-10-10 起改成自留发布后不再有 media_id。**旧日志保持 `media_id` 表头不动**
- **时段建议**：什么时间发这类内容更合适

## 编号

文件编号 `NN` 从 `01` 起，每天独立计数。

---

## 本步的坑 / 不要做

- 日志表的**列序不要乱改**——`01-选题` 的去重脚本按 `|` 切分取 `$3`+`$4`（表头 `| 编号 | 标题 | 名场面 | ... |` 前面有个空段，所以名场面是第 4 段）。加列一律**往右边加**。
- **不跳过日志**：漏一篇，去重就漏一条，下次可能重复发同一场。
- 日志记在**出物料时**，不记在发文后 —— 去重靠它，晚记一天就多一份重稿的风险。真实发布状态（哪天发了哪个平台）由人自己回填到 `物料` 列或末尾备注。
