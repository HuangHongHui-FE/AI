# 07 写日志

> **输入**：`06-推草稿` 返回的 media_id + 本篇的 BV号 / 时间码
> **产出**：`logs/YYYY-MM-DD.md` 追加一行
> **可扩展点**：加字段（阅读量回填、CTR、二次改写记录）就改本文件的表头

---

## 这一步做什么

每发一篇追加一行日志。日志不只是记录——它同时是 **`01-选题` 的去重依据**和 **BV号/时间码的素材库**。

## 记什么

写到 `logs/YYYY-MM-DD.md`，每篇记：

| 编号 | 标题 | 名场面 | BV号 + 时间码 | media_id | 时段建议 |
|---|---|---|---|---|---|

- **名场面**：`01-选题` 的去重脚本按这一列扫（`grep -hE '^\| 0[0-9]' logs/*.md | awk -F'|' ...`），所以这列必须填，且用能唯一识别这一场的写法
- **流程 B 也写同样的列**（别加列、别改顺序 —— 去重脚本按 `$4` 取值）：把「素材文件名 + 钩子时间段」填进 `BV号 + 时间码` 那一列，成品视频的路径写在 `media_id` 后面或末尾备注里
- **BV号 + 时间码**：记下来下次同名场面直接复用，自然积累成素材库
- **时段建议**：什么时间发这类内容更合适

## 编号

文件编号 `NN` 从 `01` 起，每天独立计数。

---

## 本步的坑 / 不要做

- 日志表的**列顺序不要乱改**——`01-选题` 的去重脚本按 `|` 切分取 `$4`（表头 `| 编号 | 标题 | 名场面 | ... |` 前面有个空段，所以名场面是第 4 段）。加列往右边加，改列序必须同步改 `01-选题` 里的字段号。
- 不跳过日志：漏一篇，去重就漏一条，下次可能重复发同一场。
