# 04 写正文

> **输入**：`03-起标题` 的标题 + `01-选题` 的名场面
> **产出**：`output/YYYY-MM-DD/NN-名场面/article.json`（首图自动用 `02-切图` 那张 GIF，不用手贴）
> **可扩展点**：改调性、改段落结构、加新文体（比如「盘点体」「对比体」），都改本文件

---

## 这一步做什么

写 800-1200 字的解读，落成 article.json。

## 文章结构（名场面解读，不是中年叙事）

名场面号的调性是 **「懂行 + 共鸣」**，不是 wechat-img 的中年叙事。篇幅 800-1200 字，6 段左右：

1. **开头**：直接抛台词或场景，不套「在...的今天」；也**别用「≤8字短句。＋展开」**（「635元。这个数字…」是 62% 历史稿的开头骨架，被硬门禁）。
2. **场景还原**：一两句交代这是哪场戏、谁对谁、什么处境（让没看过的人也接得住）。
3. **为什么牛**：选 1-2 个角度切——台词的弦外之音 / 拍法（长镜头、构图、节奏）/ 演员细节（即兴、微表情）/ 幕后（删改、现场）——**别面面俱到**，深挖一点胜过流水账。
4. **共鸣落点**：这场戏戳中了什么（代际、阶层、爱情、尊严）。落点用 **群体观察 / 客观数据 / 历史类比**写，**不要用「我」**（见下）。
5. **金句收**：回到那句台词，给一个比开头更深的读法。**别塌进万能骨架**（「不是X是Y」「说到底，」「真正X的是Y」「X的是Y」名词化升华、「这才是X留给我们的」——这几条占历史结尾 42%，全部硬 FAIL），不号召不升华。
6. （可选）**一句互动钩子**：问读者「你第一次看懂这句是几岁」之类。

> 网络梗类（giao/卢本伟）结构略变：开头抛梗→它怎么火的→为什么好笑/上头→一句人情味收（别端着分析亚文化）。

## 落笔前必须知道的硬约束

这几条来自 `wechat-img/src/preflight.js` 硬门（656 篇历史稿进化出来的），**违反就直接拒推**，详见 `05-自查`：

| 约束 | 说明 |
|---|---|
| **第一人称禁用** | 全文「我」**最多 1 处**。禁「我认识/我朋友/我觉得/我有个/我们这代人」。改用群体观察 / 客观数据 / 历史类比。剧名《我的前半生》含「我」，引一次就吃掉额度 |
| **存疑词禁用** | 「据传/疑似/据说/有消息称/有说法称」 |
| **事实段 ≥ 情绪段** | 含数字的段落数 ≥ 含心理动词的段落数 |
| **结尾骨架禁用** | 「不是X是Y」「说到底，」「真正X的是Y」「X的是Y」「这才是X留给我们的」 |
| **开头骨架禁用** | 「≤8字短句。＋展开」 |
| **口语引导词限次** | 「说到底/说白了/归根结底」≤2 次；以口语引导词起段 <3 段 |
| **加粗 3-5 处** | 超 6 处告警 |
| **JSON 内引号用「」** | ASCII `"` 会破坏 article.json 解析，硬 FAIL |

## 落到文章 JSON

推送脚本 `wechat-img/src/index.js` 实际只读四个字段：

```json
{ "title": "...", "digest": "...", "cover_slogan": "...", "body_markdown": "..." }
```

- 路径：`output/YYYY-MM-DD/NN-名场面/article.json`，`NN` 从 `01` 起
- `digest` ≤54 字、无换行无外链；`cover_slogan` ≤12 字（叠封面用，但当前封面是 plain 样式不叠字）
- 旧的 `cta_question` / `cta_follow` 字段**推送脚本根本不读**，写了也不出现在文章里——互动问句要真的露出来，得写进 `body_markdown` 末段
- **首图就是 `02-切图` 那张 GIF，body 头部由推草稿脚本自动嵌入，不用手贴图**
- 排版 / 长度 / CTA 细节见 [[wechat-daily]]（wechat-img 项目）

---

## 本步的坑 / 不要做

1. **JSON body 内引号一律中文「」**：`body_markdown` 用 ASCII `"..."` 会破坏 article.json 解析，推送报 `Unexpected token`，硬门也拦。直接用「」。
2. **正文无外链**：`body_markdown` 里不能有 `[文字](url)`；B站/豆瓣链接一律不放（微信会变纯文本），引用来源用文字描述。
3. 不端着说教：没有「我们应该」「让我们珍惜」式号召结尾。
4. 写完必过 `05-自查`，不过则重写。
