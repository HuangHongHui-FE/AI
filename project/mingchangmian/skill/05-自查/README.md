## A. AI 痕迹自查

逐条扫 `body_markdown`：

- [ ] **禁用词全删**：「值得注意的是」「总而言之」「此外」「综上所述」「综上」「在当今社会」「在快节奏的」「不仅...而且」「不仅如此」「毋庸置疑」「众所周知」「由此可见」「应该说」「某种程度上」——命中即改写。
- [ ] **第一人称全面禁用**（2026-09-14 决定）：**全文「我」最多 1 处**。禁「我认识/我朋友/我觉得/我想/我有个/我们这代人」等一切作者自我叙述。
  - 替代写法：**群体观察**（「这类人普遍…」）/ **客观数据事实** / **历史跨行业类比**
  - 注意：剧名《我的前半生》本身含「我」，出现一次就吃掉整个额度——正文里最好只引一次剧名，其余用「这部剧」指代
  - 引用他人原话不受限（禁的是作者自我叙述），但正则只按字面匹配，**引语里带「我」照样计数**，须避开
- [ ] **无存疑词**：「据传」「疑似」「据说」「有消息称」「没法证实」「有说法称」「有人传」——命中即删或改成可查证事实。
- [ ] **无工整排比对仗**：没有「不是A而是B；不是C而是D」连续堆叠；没有连续三句字数句式雷同。
- [ ] **段落长短不齐**：至少 1 段只 1 句、1 段明显长，别每段都 3-5 行。
- [ ] **开头不套话**：第一段直接进台词或场景，既不是「随着...的发展」「最近...引发热议」，也不是「≤8字短句。＋展开」（如「635元。这个数字…」）。
- [ ] **结尾不塌进万能骨架**：末句不出现「不是X是Y」「说到底/归根结底/说白了，」「真正X的是Y」「X的是Y」名词化升华、「这才是X留给我们的」。
- [ ] **有具体细节**：≥2 处具象（一句原台词 / 一个镜头动作 / 一个幕后数字），不纯抽象议论。
- [ ] **事实段 ≥ 情绪段**：含数字的段落数要不少于含心理动词（难受/感动/眼眶/心里咯噔…）的段落数。
- [ ] **口语感但别滥用**：要有口语（「压根」「堵死」「护犊子」这类），但——
  - 全篇「说到底/说白了/归根结底」**≤2 次**
  - 以口语引导词起段的段落**<3 段**
- [ ] **不端着说教**：没有「我们应该」「让我们珍惜」式号召结尾。

## B. 微信公众号规范自查

- [ ] **标题**：≤22 字，贴名场面原词/原台词（自检：标题里有原台词关键词或片名吗？没有→重起），无标题党限流词（震惊/速看/刚刚/突发），**结尾不能是「情绪词+了/着」**（如「…看哭了」「…破防了」，被判低创的批次全是这个格式）。
- [ ] **摘要 digest**：≤54 字，无换行无外链。
- [ ] **正文无外链**：`body_markdown` 里不能有 `[文字](url)`；引用来源用文字描述。B站/豆瓣链接一律不放正文（微信会变纯文本）。
- [ ] **GIF 合规**：单张 < 10MB（实际应 < 3MB，见 `02-切图` 约束），是 GIF 格式。不带别家平台明显水印——注意**第三方搬运工具水印**（如「CR VideoMate」）比 B站水印更难看，能裁则裁。
- [ ] **封面比例**：公众号封面是 **2.35:1**，GIF 通常是 1.89:1，合成时上下会各裁一刀。**烧在画面底部/顶部的字幕会被裁掉**——切图时先想清楚首帧在 2.35:1 下还剩什么。
- [ ] **无诱导违规词**：无「转发抽奖」「集赞」「关注领取」等。
- [ ] **敏感红线**（名场面号高发）：
  - 抽象系（孙笑川/nmsl/老八）**只引用台词、不出现原人物画面、不渲染低俗**，风险高的整条弃写换题
  - 涉政治人物的影视（如某些主旋律片段）不评价现实政治
  - 暴力/血腥镜头的 GIF 不切（选台词窗口而非打斗窗口）
  - 未审案件相关名场面用「涉嫌」原样转述，不预判
- [ ] **标点**：全中文标点，引号统一用「」（**JSON body 内严禁 ASCII 双引号 `"..."`，会破坏 article.json 解析**），无中英混用逗号，无错别字。
- [ ] **加粗/引言/分隔符**：`**加粗**` 3-5 处（超 6 处等于没加）、`> 引言` 1-2 处。

## C. 版权与原创度自查（2026-10-17 新增）

> **为什么单列这一节**：2026-10-17 用户反馈成片在多个平台「申请不了原创声明」且被判「已有相似视频 / 侵权影视作品」。
> 视频号后台当时已有处罚记录：**「原创声明能力使用不当提醒」**、**「因多次违反原创条款，10月20日后可继续使用」**。
> 根因不是流程 bug —— 是「影视片段 + 字幕」这种形态本身就踩线：既够不上平台对「二次创作程度」的要求，也躲不过版权内容指纹。

### C1. 两个问题要分开看（成因不同、解法不同）

| 问题 | 平台判定依据 | 解法 |
|---|---|---|
| **申请不了原创声明** | 平台对「二次创作程度」的判定，**与侵权无关** | 提高原创投入占比（见 C3）|
| **判定侵权 / 已有相似视频** | 版权方投诉 + 内容指纹比对 | 降低原片占比、换素材来源（见 C2/C3）|

平台官方口径（抖音/西瓜《原创标准》）——二次剪辑类作品的合格线是：

    在适度引用原视频素材基础上，二次创作成为一个丰富、有信息量、
    有自己编辑思路、有独创性的新视频作品

**明确不能声明原创的**：「二次创作程度不高的内容」「内容丰富度低，如对原有素材进行简单剪辑」「未获授权发布影视剧等版权内容」。

### C2. 别指望「改一改躲过查重」（重要）

平台用的是**视频指纹**技术。公开指标（华为云视频指纹）：

    转码 / 改帧率 / 改分辨率 / 改比例 / 旋转 / 镜像 / 模糊 /
    加噪声 / 加文本 / 加 logo / 加边框
    → 相似识别准确率 99% 以上

所以**加滤镜、镜像、变速、加边框这条路是死的**。更糟的是：一旦被认定在「规避检测」，性质比单纯搬运更重。

- [ ] **没有**为了躲查重而做无意义的画面变换（镜像/变速/加噪点等）。要改就改**内容形态**，不是改像素。

### C3. 原片占比硬指标（视频类必查）

按业界常见审核口径（与平台审核方向一致，非法律硬线）：

- [ ] **单个原片镜头 ≤ 3 秒**
- [ ] **原片素材累计占比 < 10%**（成片总时长里，清晰可辨的原片画面）
- [ ] **原创解说/观点占比 > 50%**（配音或字幕字数、时长都算）

> ⚠️ **「模糊压暗当底片」不算规避**。把原片模糊后铺满全屏，虽然肉眼不构成「原片画面」，但指纹仍可能命中，且平台可能判定为规避。
> 更稳的做法是**换掉底片**（纯色/渐变/原创图形），只在论据处插入 ≤3 秒清晰镜头。

**算占比的方法**（成片出来后实测，不要估）：

```bash
cd skill/05-自查
python3 check_copyright.py <成片.mp4> --clip 3.0,3.0,2.8 --speech-sec 88.9
#   --clip       每个原片清晰镜头的时长（秒，逗号分隔）—— 从合成脚本抄，最可靠
#   --speech-sec 原创解说配音总时长（秒）
# 不合格会 exit 1；有项没校验也会 exit 1（不说「全过」）
```

> ⚠️ **脚本只量「占比」这类可计算指标**。C2/C4/C5 靠人眼，仍需照清单过。
> 不传 `--clip` 时会尝试按画面清晰度自动识别，但那是启发式近似，**以合成脚本记录为准**。
> 脚本退出码为 0 才算 C3 过 —— 有未校验项时它**故意**返回 1，别把「没报错」当「过了」。

### C4. 素材来源（选材时就要判）

- [ ] **标注来源**：解说里口播或字幕标明作品名 + 年份（如「2003 年的电视剧《征服》」）。**不标是最容易被投诉的点。**
- [ ] **优先选已授权/可商用素材**：平台官方版权素材库（**名单经常变，去后台确认当前有效期**）、公有领域（老片/默片/历史影像）、自拍素材
- [ ] **热门影视名场面默认按「未授权」对待** —— 它们之所以是名场面，正因为是受版权保护的热门作品。别默认「大家都剪所以没事」
- [ ] **避免高风险片段**：暴力/血腥镜头不剪（选台词窗口而非打斗窗口）；抽象系人物只引台词不出画面（同 B 节）
- [ ] **别勾「声明原创」**（在内容形态改造到位之前）—— 名场面片段是搬运的影视内容，勾了与事实不符，且会累积处罚

### C5. 文章侧（`body_markdown` + GIF/封面）

文章路线的风险低于视频，但**首图 GIF 和封面同样是影视截图**：

- [ ] 正文以**解读/观点为主**，原台词引用**短引**（不是大段复述剧情）
- [ ] **不在正文里放「几分钟看完」式的剧情复述** —— 那是典型的实质性替代
- [ ] 首图 GIF 选**台词窗口**而非打斗/血腥窗口（同 B 节）
- [ ] 封面/首图**裁掉搬运工具水印**（见 B 节）
- [ ] 文章里**标注作品名 + 年份**
