## A. AI 痕迹自查

逐条扫 `body_markdown`：

- [ ] **禁用词全删**：「值得注意的是」「总而言之」「此外」「综上所述」「综上」「在当今社会」「在快节奏的」「不仅...而且」「不仅如此」「毋庸置疑」「众所周知」「由此可见」「应该说」「某种程度上」——命中即改写。
- [ ] **第一人称全面禁用**（2026-09-14 决定）：**全文「我」最多 1 处**。禁「我认识/我朋友/我觉得/我想/我有个/我们这代人」等一切作者自我叙述。
  - 替代写法：**群体观察**（「这类人普遍…」）/ **客观数据事实** / **历史跨行业类比**
  - 注意：剧名《我的前半生》本身含「我」，出现一次就吃掉整个额度——正文里最好只引一次剧名，其余用「这部剧」指代
  - 引用他人原话不受限（禁的是作者自我叙述），但正则只按字面匹配，**引语里带「我」照样计数**，须避开
- [ ] **无存疑词**：「据传」「疑似」「据说」「有消息称」「没法证实」「有说法称」「有人传」——命中即删或改成可查证事实。
- [ ] **无工整排比对仗**：没有「不是A而是B；不是C而是D」连续堆叠；没有连续三句字数句式雷同。
- [ ] **段落长短不齐**：至少 1 段只 1 句、1 段明显长，别每段都 3-5 行。
- [ ] **开头不套话**：第一段直接进台词或场景，既不是「随着...的发展」「最近...引发热议」，也不是「≤8字短句。＋展开」（如「635元。这个数字…」）。
- [ ] **结尾不塌进万能骨架**：末句不出现「不是X是Y」「说到底/归根结底/说白了，」「真正X的是Y」「X的是Y」名词化升华、「这才是X留给我们的」。
- [ ] **有具体细节**：≥2 处具象（一句原台词 / 一个镜头动作 / 一个幕后数字），不纯抽象议论。
- [ ] **事实段 ≥ 情绪段**：含数字的段落数要不少于含心理动词（难受/感动/眼眶/心里咯噔…）的段落数。
- [ ] **口语感但别滥用**：要有口语（「压根」「堵死」「护犊子」这类），但——
  - 全篇「说到底/说白了/归根结底」**≤2 次**
  - 以口语引导词起段的段落**<3 段**
- [ ] **不端着说教**：没有「我们应该」「让我们珍惜」式号召结尾。

## B. 微信公众号规范自查

- [ ] **标题**：≤22 字，贴名场面原词/原台词（自检：标题里有原台词关键词或片名吗？没有→重起），无标题党限流词（震惊/速看/刚刚/突发），**结尾不能是「情绪词+了/着」**（如「…看哭了」「…破防了」，被判低创的批次全是这个格式）。
- [ ] **摘要 digest**：≤54 字，无换行无外链。
- [ ] **正文无外链**：`body_markdown` 里不能有 `[文字](url)`；引用来源用文字描述。B站/豆瓣链接一律不放正文（微信会变纯文本）。
- [ ] **GIF 合规**：单张 < 10MB（实际应 < 3MB，见 `02-切图` 约束），是 GIF 格式。不带别家平台明显水印——注意**第三方搬运工具水印**（如「CR VideoMate」）比 B站水印更难看，能裁则裁。
- [ ] **封面比例**：公众号封面是 **2.35:1**，GIF 通常是 1.89:1，合成时上下会各裁一刀。**烧在画面底部/顶部的字幕会被裁掉**——切图时先想清楚首帧在 2.35:1 下还剩什么。
- [ ] **无诱导违规词**：无「转发抽奖」「集赞」「关注领取」等。
- [ ] **敏感红线**（名场面号高发）：
  - 抽象系（孙笑川/nmsl/老八）**只引用台词、不出现原人物画面、不渲染低俗**，风险高的整条弃写换题
  - 涉政治人物的影视（如某些主旋律片段）不评价现实政治
  - 暴力/血腥镜头的 GIF 不切（选台词窗口而非打斗窗口）
  - 未审案件相关名场面用「涉嫌」原样转述，不预判
- [ ] **标点**：全中文标点，引号统一用「」（**JSON body 内严禁 ASCII 双引号 `"..."`，会破坏 article.json 解析**），无中英混用逗号，无错别字。
- [ ] **加粗/引言/分隔符**：`**加粗**` 3-5 处（超 6 处等于没加）、`> 引言` 1-2 处。
