# 01 选题

> **输入**：用户的一句话（「写名场面」/「写一场 XXX」），或空 → 自动选
> **产出**：一条确定的选题 = **片名 + 名场面 + （可选）倾向的角度**，交给 `02-切图`
> **可扩展点**：想加新的选题来源（新号、新题材、新榜单）就改本文件「选题来源」那几条

---

## 这一步做什么

定「今天写哪一场」。这是整条流程唯一需要判断力、也最影响流量的环节。

## 选题来源（按优先级）

a. **用户指定**：用户点名某场（「写无间道天台戏」），直接用，跳到 `02-切图`。
b. **蹭当下影视热点**：若当下有相关热点（新片上映的同系列旧作、演员去世/获奖、某老片/老梗翻红），优先选与热点挂钩的名场面——这是名场面号最大的流量来源。用 WebSearch 探一下近 3 天影视圈热点。
c. **自选未写过的**：从下列清单里挑一条 `logs/` 没写过的（清单非穷尽，可自行扩展）：
   - **华语经典**：让子弹飞「站着挣钱」/ 无间道天台「对不起我是警察」/ 大话西游「一万年」/ 霸王别姬「不疯魔不成活」/ 喜剧之王「我养你啊」/ 英雄本色「等了三年」
   - **鬼畜万恶之源**：三国演义「从未见过如此厚颜无耻之人」/ 甄嬛传「臣妾做不到」/ 范志毅「脸都不要了」/ 康熙王朝
   - **网络梗/短视频**：giao 哥「一给我嘞giaogiao」/ 冬人「奥利给干了兄弟们」/ 卢本伟「我卢本伟没有开挂」/ 周立齐「打工是不可能打工的」/ 影流之主
   - **抽象系（高风险，见 `05-自查` 红线）**：孙笑川系列、岛市老八等——**只引用台词不出现原人物画面**，降低封号风险

## 去重（不写写过的）

扫 `logs/*.md` 的「名场面」列：

```bash
# 同时取出「名场面」和「标题」两列，不依赖列序（历史日志的列序不统一）
grep -hE '^\| 0[0-9]' logs/*.md | awk -F'|' '{gsub(/^ +| +$/,"",$3); gsub(/^ +| +$/,"",$4); print $3" | "$4}' | sort -u
```

> **列序坑**：`logs/` 下的历史文件列序不统一——`2026-07-08.md` 是 `编号|名场面|标题|BV号|时间码|状态`，`2026-07-11.md` 是 `编号|标题|名场面|BV号+时间码|media_id|时段建议`。按 `|` 切分后第 1 段是空串，所以**只取 `$4` 会在两版文件上取到不同的东西**。上面的命令取 `$3`+`$4` 两个都打出来，无论哪版都能覆盖。
>
> 新写的日志一律按 `07-写日志` 的标准格式（`编号|标题|名场面|BV号+时间码|media_id|时段建议`）。

候选若和历史上某篇同一场（语义相同即算），换一条。

## 篇数

默认 **1 篇**（用户喊「来几篇」「发一波」才多写）。每篇独立选点、独立切图、独立推。

---

## 本步的坑 / 不要做

- 不跨天重复同一场（每次开跑先扫 `logs/`）
- 不为流量硬上抽象系高风险人物画面（台词引用 OK，画面不出现）
- 不定时任务（用户喊才跑）
- 选点相关的模糊判断（写哪场、什么角度）**自己定，别停下来问**
