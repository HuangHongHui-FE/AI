# B4 出视频物料

> **输入**：`B1-剪成片` 的成片（`名场面/成品/<素材名>.mp4`）+ `03`/`04` 定下的文章调性
> **产出**：`article.json` 里的 `video` / `video_short` / `video_desc` / `douyin` / `kuaishou` 五个字段，并在 `06-出物料` 生成的 `发布物料.md` 里落成可复制文本
> **终点**：**Claude 不发布**。视频号 / 抖音 / 快手由人手动发

---

## 这一步做什么

给成品视频配**文案** —— 短标题 + 描述。写进 `article.json`，`06-出物料` 会把它渲染成「复制即用」的块。

```json
{
  "video": "名场面/成品/024-我靠，袁华.mp4",
  "video_short": "袁华举着鱼叉撞上来那一刻",
  "video_desc": "有个渔船撞我们船上了，看着像碰瓷的#名场面 #夏洛特烦恼",
  "douyin": "有个渔船撞我们船上了，看着像碰瓷的#名场面 #夏洛特烦恼",
  "kuaishou": "……"
}
```

| 字段 | 用途 |
|---|---|
| `video` | 成片路径（相对仓库根）。**没有这个字段 = 这篇没配套视频**，`06-出物料` 只出公众号段 |
| `video_short` | 视频号**短标题** |
| `video_desc` | 视频号**描述**，惯例 `<台词>#名场面 #人物/片名` |
| `douyin` / `kuaishou` | 抖音 / 快手文案。没有特殊要求时**和 `video_desc` 写一样**就行 |

## ⚠️ 短标题不能带逗号（最容易踩）

平台限制：**只允许 书名号《》/ 引号「」/ 冒号：/ 加号+ / 问号？/ 百分号% / 摄氏度℃**，其余标点一律不行，**逗号要用空格代替**。

```
袁华举着鱼叉撞上来那一刻，太扎心了   # ✗ 含全角逗号
袁华举着鱼叉撞上来那一刻 太扎心了     # ✓ 逗号换空格
```

**为什么这条要单列**：违反它平台**不报错** —— 点保存后按钮变灰、什么都不发生、草稿箱计数不变，实测卡了很久才定位到是全角逗号。**发布失败先查短标题字符。**

`06-出物料` 会按同一份白名单（`_已停用/B4-发视频号/publish.py:19-20`）扫一遍 `video_short`，发现非法标点就告警。

## 写文案的三条约定

1. **描述以原台词开头** —— 名场面号的视频文案惯例是 `<台词>#名场面 #人物>`，台词本身就是钩子，别改写成标题党
2. **短标题讲「这段是什么」，不剧透笑点** —— 和 `03-起标题` 的文章标题是两套：文章标题可以带解读，视频短标题要短、要能一眼认出来
3. **话题标签只挂 `#名场面` + 一个具体的**（片名或人物）—— 挂一堆泛标签反而稀释
