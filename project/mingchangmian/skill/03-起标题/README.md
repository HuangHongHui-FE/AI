# 03 起标题

> **输入**：`01-选题` 的片名 + 名场面；`02-切图` 的 GIF（确认拍的是哪句台词）
> **产出**：一个 ≤22 字、含原台词关键词的标题，写进 `04-写正文` 的 article.json
> **可扩展点**：换钩子套路、改字数上限、加新号风格，都改本文件

---

## 这一步做什么

起标题。名场面号的标题**必须含原台词关键词或片名**——读者在信息流里一眼认得出是哪场，搜索流量才吃得着。

## 做法

1. 写下原台词/片名核心词（如「让子弹飞 / 站着把钱挣了」）
2. 保留核心词，加一个轻钩子（「这段我看十遍」「就这一句封神」「长大后看懂了」）
3. **≤22 字**，不标题党（无「震惊/速看/刚刚」限流词）

## 正反例

| 名场面 | ✅ 贴原词标题 | ❌ 离原词太远 |
|---|---|---|
| 让子弹飞·站着挣钱 | 让子弹飞「站着把钱挣了」，这段我看十遍 | 成年人最该补的一堂课 |
| 无间道·天台 | 无间道天台「对不起我是警察」，就这一句封神 | 两个男人的宿命对峙 |
| 大话西游·一万年 | 大话西游「爱你一万年」，长大后看懂了 | 错过的爱情都在台词里 |
| 三国演义·厚颜无耻 | 诸葛亮「从未见过如此厚颜无耻之人」 | 古人骂人有多雅 |

## 自检

标题里有没有原台词/片名关键词？**没有 → 重起。**

---

## 本步的坑 / 不要做

- 不为了文艺感丢掉原台词关键词——信息流里认不出是哪场，等于白写
- 标题里的引号统一用「」（JSON 内严禁 ASCII 双引号，会破坏 article.json 解析）
