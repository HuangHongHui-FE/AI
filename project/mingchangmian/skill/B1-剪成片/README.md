# B1 剪成片

> **输入**：用户给的源视频（`名场面/素材/<素材名>.mp4`）+ **钩子时间段**（写在文件名里）+ 标题文字
> **产出**：`名场面/成品/<素材名>.mp4`（成品视频）
> **可扩展点**：风格参数（卡时长、打字速度、水印周期/透明度、画质）都在 `剪辑模板.py` 顶部常量区，改那里统一全站风格

---

## 这一步做什么

把用户给的源视频剪成成品，固定四段：

```
[① 钩子段] → [② 打字机标题卡] → [③ 正文（完整源视频）] → [④ 片尾关注卡]
```

这是**流程 B 的起点**，和流程 A 的 `01-选题` + `02-切图` 是**并列关系**，不是上下游 —— 每次只跑其中一条。

## 钩子时间段从文件名读（约定）

用户给素材时就**把钩子段写在文件名里**，不需要再问：

```
<编号>-<标题>-<起始秒>-<结束秒>.mp4
   019-爆笑吕子乔 肾宝，味道好极了-50-56.mp4   → 钩子取源视频 50–56 秒
   023-我没上车，我还没上车-101-106.mp4        → 钩子取源视频 101–106 秒
   024-我靠，袁华-0-4.mp4                      → 钩子取源视频 0–4 秒
```

解析规则：**从右往左取最后两段**用 `-` 分隔的纯数字，倒数第二段是起始秒、最后一段是结束秒；编号是开头三位数字；中间剩下的部分是标题。

三个值各自的用途：

| 取自文件名 | 用途 |
|---|---|
| 编号（如 `019`）| 给成品和首图命名，避免和流程 A 的产物撞名 |
| 标题 | **打字机标题卡的文字**（清洗规则见下）|
| 起始秒 / 结束秒 | `--hook-range 起始-结束`，同时是 `B2-切首图` 用的时间段 |

**标题清洗规则**（文件名是人手敲的，会有杂讯）：

- `#话题标签` 去掉（`026-… #甄子丹-15-18` → 标题不含 `#甄子丹`）
- 连续多个空格压成一个
- 其余原样保留，不擅自改写用户写的标题

## 命令

在**仓库根目录**跑即可，不用先 cd：

```bash
python3 skill/B1-剪成片/剪辑模板.py "素材/<素材名>.mp4" "<标题>" \
    --hook-range 起始-结束 \
    --cta "成品/004-食s了你-2月16日.mp4"
```

`素材/`、`成品/` 这些相对路径**统一按仓库的 `名场面/` 解析**（脚本里 `MEDIA_ROOT`）。不传 `output` 时成品落到 `名场面/成品/` 下、与源文件同名。

`--cta` 指任意一个已有成品的片尾（目前固定用 `成品/004-食s了你-2月16日.mp4`，它末尾有 2 秒关注卡）。

**批量出片**用同目录的 [`批量剪.py`](批量剪.py)：扫 `名场面/素材/` 自动解析文件名里的钩子段，跳过已成品和缺秒数的。

```bash
python3 skill/B1-剪成片/批量剪.py                 # 全量
python3 skill/B1-剪成片/批量剪.py --only 019,020   # 挑着剪
python3 skill/B1-剪成片/批量剪.py --force          # 已成品也重剪
```

## 规则（铁律）

1. **钩子段要播两遍**：开头预告一次，正文里再完整播一次（正文是**完整源视频，不挖除钩子段**）。
   所以成品总长 = `钩子时长 + 3 + 源片长 + 2`。**别「优化」成只播一遍。**
2. **标题卡期间音频不能断**：实现方式是钩子的音频多取 3 秒盖住标题卡。改成静音就是 bug。
3. **钩子时间段从素材文件名读**（格式见上），不要自己猜、也不要改用户给的范围。
   文件名里没有秒数就先问用户 —— **别自己看片估一个**。
4. **水印**：斜向移动的「名场面」，标题卡和片尾关注卡期间自动关闭（否则会压在卡上）。

> 模板的完整细节 —— 四段结构表、全部参数、抽帧定位法、6 条已知坑 —— 见 [`../../名场面/剪辑流程.md`](../../名场面/剪辑流程.md)。
> **那份是权威说明，本文件不复制它**，避免两边漂移。

## 验证

跑完必须核对，别盲推：

```bash
FF=$(python3 -c "import imageio_ffmpeg;print(imageio_ffmpeg.get_ffmpeg_exe())")
# 1) 时长应 = 钩子 + 3 + 源片长 + 2
"$FF" -i "成品/<素材名>.mp4" 2>&1 | grep Duration
# 2) 标题卡那 3 秒不能是静音（这是最容易出错的地方）
"$FF" -ss <钩子时长> -t 3 -i "成品/<素材名>.mp4" -af volumedetect -f null - 2>&1 | grep mean_volume
# 3) 钩子在正文里确实又播了一遍：取开头一帧和正文里对应位置那一帧，比 PSNR（同内容应 >30dB）
```

再加一步目视：抽缩略图总览看四段结构对不对。

## 本步的坑 / 不要做

- **脚本位置**：`剪辑模板.py` 和 `批量剪.py` 都放在本文件夹（`skill/B1-剪成片/`），
  素材和成品在 `名场面/` —— 相对路径由脚本里的 `MEDIA_ROOT` 统一解析，所以**不用 cd**。
  挪动脚本时记得同步改 `MEDIA_ROOT`（它按 `脚本位置/../../名场面` 算）。
- **字体硬编码**：`剪辑模板.py` 里写死了 macOS 字体 `/System/Library/Fonts/PingFang.ttc`，换机器要改。
- **不改脚本逻辑**，要调风格改顶部常量区。
- 素材若比「钩子 + 标题卡」还短，脚本会自动缩短标题卡并打印提示 —— 那是保护，不是 bug。
- 不自作主张改用户给的钩子时间段。
