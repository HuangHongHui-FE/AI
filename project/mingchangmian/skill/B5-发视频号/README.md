## 这一步做什么

用**操作浏览器**的方式把成片发进视频号草稿箱。视频号**没有面向个人的发布 API**（官方只开放橱窗/留资/直播数据/带货数据），所以只能走浏览器自动化 —— 业界所有工具都是这么做的。

| 要填的字段 | 从哪来 |
|---|---|
| 视频文件 | `名场面/成品/<素材名>.mp4` |
| 视频描述 | `article.json` 的 `video_desc`（惯例 `<台词>#名场面 #人物>`）|
| 短标题 | `article.json` 的 `video_short`（**≤16 字**，见下）|
| 封面 | **不用管**，微信自动从视频里抽两张（个人主页 3:4 / 分享卡片 4:3）|
| 位置 | 默认「杭州市」，不用改 |

## 命令

```bash
cd skill/B4-发视频号
python3 vh_draft.py "<成片路径>.mp4" \
    --desc "一给我嘞giao giao#名场面 #giao哥" \
    --short "一给我嘞giao giao 八年"
```

首次跑（或会话过期）会弹 Chrome 提示扫码 —— **视频号的登录态和公众号不共用**，
即使公众号那个 profile 已登录，视频号仍要单独扫一次（用微信小号「名场面哦」那个号扫）。
登录态存在同一个持久化 profile（`~/Library/Caches/mingchangmian-mp-profile`）里。

## ⚠️ 短标题两条硬规则（都会「静默失败」）

平台**不报错、不弹窗**，只是让「保存草稿」变灰点不动 —— 看起来像异步提交中，其实是校验没过。

### 1. 不能超过 16 字

实测：`一给我嘞giao giao 这句喊了八年`（20 字）→ 输入框下面出红字 **「标题超过16字限制」**，
保存按钮点不动。脚本会**在跑之前就拦下来**（`SHORT_MAX_LEN = 16`）。

```
一给我嘞giao giao 这句喊了八年   # ✗ 20 字
一给我嘞giao giao 八年          # ✓ 16 字
```

> 空格也算 1 个字。`len()` 直接量。

### 2. 标点只允许这几个

**书名号《》/ 引号「」/ 冒号：/ 加号+ / 问号？/ 百分号% / 摄氏度℃**，其余一律不行，**逗号要用空格代替**。

脚本的 `clean_short_title()` 会自动把非法标点换成空格并打印清洗结果。

> 想换行/分段也不行，短标题是单行。

## 页面结构的坑（都已在脚本里绕过）

1. **登录态不能只看 `page.url`** ⚠️ 2026-10-17 踩到。
   登录二维码是**同 URL 页面里嵌的 iframe**（`open.weixin.qq.com/connect/qrconnect`），
   登录前后 URL 都是 `channels.weixin.qq.com/platform/`。
   用 URL 判会**误报「已是登录态」**，然后在登录页上瞎操作。
   正确判法：**还有没有 qrconnect/login.html iframe** + **有没有后台侧边栏（`text=内容管理`）**。

2. **Wujie 微前端：`frame.evaluate` 和 `frame.locator` 看到的不是同一个文档**。
   `evaluate("document.querySelector('.input-editor')")` 能命中，
   同一个 frame 上 `locator(".input-editor")` 却可能解析不到。
   → **选 frame、探状态、点按钮一律用 locator**，不要用 evaluate 判存在性。
   （也因此：想读页面文字做判断时，`inner_text` 常常读不到表单内容 —— 别依赖它，
   要判断就判断按钮的 `is_enabled()`。）

3. **必须从首页点「发表视频」进**。直接开 `/platform/post/create` **表单不渲染**。

4. **上传要等 `video.readyState >= 2` 且 `duration > 0`**，不是等描述框出现就算好。
   脚本的 `wait_video_ready()` 就是干这个的。

5. **上传**：用 `.ant-upload-drag-container` 触发 file chooser
   （不要点那段「上传时长8小时内…」文字，那是长文本节点点不中）。

6. **描述框上传后才挂载**：`.input-editor[contenteditable]`。

7. **保存/发表是异步的**：点完**别急着跳走**，等 30 秒。
   禁用态和可用态**都是灰色**，光看截图分辨不出来，要用 `is_enabled()` 判。

8. **核实草稿箱**：左侧第 1 个图标展开「内容管理」→ 点「草稿箱」，
   路由是 `/platform/post/draftListManager`。**列表内容读不到文字**（在嵌套 frame 里），
   **只能靠截图看计数**（`草稿箱 (N)`）。

## 本步的坑 / 不要做

- **默认且只能存草稿**。`vh_draft.py` 没有 `--publish`，不会点发表。
- **短标题先量长度**（≤16 字），再查标点。
- **别勾「声明原创」** —— 名场面片段是搬运的影视剧内容，勾了与事实不符。
  （当前账号该功能还被限制着：「因多次违反原创条款，10月20日后可继续使用」。）
- **换号**要删掉 profile 重新扫码；换号前同步改 `.env`（`WECHAT_APPID`/`WECHAT_APPSECRET` 成对换）。
- 视频号会话会过期，届时重扫即可，脚本会自己提示。
- **别把 profile 目录提交进版本库**（里面有登录态）。
