# B4 发视频号

> **输入**：`B1-剪成片` 产出的成片（`名场面/成品/<素材名>.mp4`）+ 视频描述 + 短标题
> **产出**：**微信视频号（名场面哦）**草稿箱里的一条草稿（默认不发表）
> **可扩展点**：选择器、等待时长都在 `publish.py`；`SHORT_ALLOWED_PUNCT` / `SHORT_BANNED` 是短标题的字符白名单

---

## 这一步做什么

把成片发到微信视频号。**没有官方 API 可用**，所以走浏览器自动化 —— 这不是绕路，业界所有工具（pva、ShortVideo.AutoPublisher、MatrixMedia 等）都是 Playwright/Puppeteer + 持久化会话。

> 官方文档里视频号助手开放的只有「橱窗 / 留资 / 直播数据 / 带货数据 / 达人罗盘」，**不含视频内容发布**。内容发布 API 只面向有资质的企业/服务商。

## 命令

```bash
python3 skill/B4-发视频号/publish.py "名场面/成品/019-爆笑吕子乔 肾宝，味道好极了.mp4" \
    --desc "肾宝，味道好极了#名场面 #孙艺洲" \
    --short "吕子乔这段肾宝广告 太洗脑了"
```

**默认只点「保存草稿」，加 `--publish` 才真正发表**（发布不可逆，别手滑）。

首次跑（或会话过期）会弹 Chrome 提示扫码，登录态存在 `~/Library/Caches/mingchangmian-mp-profile`，和 B3 发公众号草稿**共用同一个 profile**。

## 短标题的字符规则（⚠️ 最容易踩）

平台限制：**只允许 书名号《》/ 引号「」/ 冒号：/ 加号+ / 问号？/ 百分号% / 摄氏度℃**，其余符号一律不行，**逗号要用空格代替**。

```python
"吕子乔这段肾宝广告，太洗脑了"   # ✗ 含全角逗号
"吕子乔这段肾宝广告 太洗脑了"     # ✓ 逗号换空格
```

`publish.py` 里的 `clean_short_title()` 会自动把非法标点换成空格并打印清洗结果。

> **为什么这条要单列**：违反它平台**不报错**——点「保存草稿」后按钮变灰、什么都不发生、草稿箱计数不变。实测卡了很久才定位到是短标题里那个全角逗号。**发布失败先查短标题字符。**

## 页面结构的坑（都已在脚本里绕过）

1. **`frame.evaluate` 和 `frame.locator` 看到的不是同一个文档** ⚠️ 这是最大的坑。
   这个页面是 **Wujie 微前端**（`WUJIE-APP` / `wujie_iframe`）。在同一个 frame 上：
   - `frame.evaluate("()=>document.querySelector('.post-upload-wrap')")` → **能命中**
   - `frame.locator(".post-upload-wrap")` → 在**选错 frame 时**解析不到

   所以**选 frame、探状态、点按钮一律用 locator**，不要用 evaluate 判存在性。脚本里的 `frame_by_locator()` 就是干这个的，
   也**不要**用 `page.frame(name="content")` —— 表单在一个 URL 为空/会变的嵌套 frame 里，名称查不到。

2. **必须从首页点「发表视频」进**，直接开 `https://channels.weixin.qq.com/platform/post/create` **表单不渲染**（SPA 路由问题）。

3. **上传**：用 `.ant-upload-drag-container` 触发 file chooser（不是点那段「上传时长8小时内…」文字，那是长文本节点点不中）。

4. **描述框上传后才挂载**：`.input-editor[contenteditable]`，上传前可能不存在。

5. **保存/发表是异步的**：点完**别急着跳走**，脚本会等 40 秒再核实。禁用态和可用态都是灰色，光看截图分辨不出来，要判 `is_enabled()`。

6. **封面不用管**：微信会**自动**从视频里生成两张（个人主页卡片 3:4 / 分享卡片 4:3）。

7. **核实草稿箱**：左侧第 2 个图标是「内容管理」，展开后点「草稿箱」，路由是 `/platform/post/draftListManager`。

## 本步的坑 / 不要做

- **默认不发表**，只存草稿；要发表显式加 `--publish`。
- 短标题**别带逗号**，脚本会替你换空格，但最好一开始就写对。
- **别勾「声明原创」** —— 名场面片段是搬运的影视剧内容，勾了与事实不符。
- 换号要删掉 profile 重新扫码，并同步改 `.env`（B3/06 那两条通道用的是同一套凭据）。
- 视频号会话会过期，届时重扫即可。
