## 一、方向选型分析（核心结论：纯公司介绍，不写人物/明星）

「介绍类」内容在微信平台天然踩雷，必须先认清：

- **搬运洗稿高危**：维基百科式资料堆砌（公司沿革照搬）= 微信官方「低创作度·疑似搬运」四类判定之一。
- **低信息量高危**：纯复述无增量 = 「低信息量」判定。

由此定方向：**只写公司介绍，不写明星/网红/名人**。

理由：

1. **可查证事实多**：财报、上市/融资、产品、市值、时间线均有出处，天然满足「≥3 条可查证事实」，低信息量风险最低。
2. **分析增量天然成立**：商业模式拆解、成败归因、行业地位判断，本身就带观点，规避搬运洗稿。
3. **平台宽容度高**：财经商业类监管相对松，不踩劣迹艺人/肖像权/隐私红线。
4. **长尾搜索流量稳**：用户高频搜「XX 公司怎么样」「XX 是干嘛的」，长尾转化好。
5. **与你已有项目呼应**：forecast（财经）项目积累了行业/板块素材，写公司介绍时可复用盘面认知，不凭空起步。

子类型（每篇挑一种结构配方，不堆资料）：

- 兴衰史：一家公司怎么起来的 / 怎么倒下的（叙事性最强）
- 商业模式拆解：它靠什么赚钱 / 为什么能卷赢
- 创始人故事：人 + 决策 + 时代背景（写人不写八卦，仅作为公司故事的附属写法，不单独做名人栏目）
- 行业地位：它在产业链里卡哪个位置 / 谁能替代它

### ❌ 不做

纯资料复述、无事实的情绪感悟文、任何明星/网红/名人八卦方向。

## 三、文章结构规范（反低创作度，多维轮换）

**红线**（继承 wechat-img 低创作度经验，逐篇必过）：

- 不堆砌资料：每段必须有**分析/判断增量**，不能只是「XX 年成立，XX 年上市」流水账
- ≥3 条可查证事实（人名/数字/时间/地点/引语），写前 curl 抓新闻正文补事实
- 不逐段套固定模板：结构配方 / 排版 theme / 标题骨架 / 开头钩子 / 叙事口吻 多维轮换，每篇与近 5 篇不同形（短期多篇同框架 = 同质化铁证）
- 标题不雷同收尾（禁「XX，我 X 了」式套句）
- 口头禅跨篇去重，记日志

**结构配方池（先列 8 套，后续可扩到 20）**：

1. 兴衰时间线（起-承-转-合，但不机械按年代）
2. 商业模式拆解（它靠什么赚钱 → 为什么能赚 → 还能赚多久）
3. 一个人 + 一个关键决策（围绕一个转折点写）
4. 产业链定位（上游/下游/替代者视角）
5. 对比双主角（XX vs YY，为什么一个赢）
6. 反常识切入（大家都以为 A，其实 B）
7. 数据驱动（一个关键数字讲全篇）
8. 产品即主角（从一款产品反推公司）

**开头钩子 / 叙事口吻 / CTA / 标题骨架** —— 各列 8-20 套池随机轮换，具体池内容写 skill 时补全（参照 wechat-img hotspot-publish.md 的池格式）。

- `recent.js`（读近 N 篇已用维度拼 prompt）—— 复用

### 4.2 本目录新增

- `skills/intro-publish.md`：主 skill（选对象 → 抓事实 → 找图 → 生成 → 自查 → 推草稿 → 写日志）
- `src/index.js`：入口（参数：`--subject "公司/人名"` 或 `--subject-file`，`--dry-run`）

### 4.5 事实补抓

## 五、Skill 流程（intro-publish.md 主流程）

1. **选对象**：用户给 subject（公司名），或 skill 自动从「热门公司/上市新股」取一个；不挑食，写好即推
2. **抓事实**：curl 抓新闻/百科正文，提取 ≥3 可查证事实（数字/时间/人名/引语）
3. **定类型**：从 8 套结构配方随机选一个（与近 5 篇不撞）
4. **起标题**：贴实体原词（蹭搜索流量）+ 不雷同骨架
5. **找图**：find_img `--news`，用公司 logo / 产品图 / 新闻图，不用人物肖像当封面
6. **生成**：Claude 按「结构配方 + 分析增量 + 事实」生成，多维轮换 theme/钩子/口吻
7. **自查**：AI 痕迹 + 微信规范 + 低创作度四类硬否决（不过回炉）
8. **推草稿**：复用 wechat.js createDraft，串行
9. **写日志**：`logs/YYYYMMDD.md` 记已用维度（theme/封面/结构配方/标题骨架/开头钩子），供下批避撞

## 六、自查清单（写完每篇必过）

### A. AI 痕迹自查（像真人长文，非批量制造）

- 无口头禅堆砌（讲真/我愣了/看懵了/说白了 等跨篇去重）
- 无排比堆砌、无空泛感悟收尾
- 有具体生活场景 / 亲历类比 / 独到判断增量

### B. 微信规范自查

- 字数合规、封面尺寸合规
- 无存疑数据夸大、引用有出处
- 无诱导分享/违规词

### C. 低创作度四类硬否决（不过即回炉或弃写）

1. 同质化：结构+排版与近 5 篇不同形
2. 搬运洗稿：有分析增量，非资料堆砌
3. 低信息量：≥3 可查证事实
4. 低价值 AIGC：融入个人经验/判断，非照搬 AI 套话
