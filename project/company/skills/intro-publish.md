## 触发条件

用户说「写公司介绍」「介绍 XX 公司」「写一篇 XX」「写下一个公司」之类。

**执行原则**：触发后**不再问澄清问题**，直接跑完整流程——`written.js next` 选公司 → curl 抓事实（财报+薪资+风评）→ recent 喂维度 → 生成 K 线图 + 找内文图 → 九段生成 article.json（含表格+图）→ preflight 硬门 → 合成封面 → 推草稿 → `written.js add` 记录 → 写日志。中途模糊判断自己定。除非真正阻塞才停。

**方向红线**：只写公司，**求职跳槽视角**——帮打工人判断「要不要去这家公司上班」。不写明星/网红/名人。不写纯商业分析。

---

## ⚠️ 低创作度规避（固定模板 + 高信息量破同质化）

固定九段模板本是「同质化」高危。破同质化靠**内容数据差异化**：

- 每家数字都不同（薪资区间/营收/市占率/订单全是该家独有真实数据）
- 评分与判断每家不同（100 分制各段打分、适合/慎重措辞各异）
- 段内措辞轻度轮换（开头钩子 / 评分倾向 / 行业口吻 / 口头禅 跨篇不重复，recent 记录）
- 信息密度足够高：每段 ≥2 个真实数字，preflight 扫数字硬门 ≥6 处

**红线**：绝不写空泛段、绝不堆情绪、绝不无数字流水段。宁可少一段，不可少一个数字。

## 抓事实（curl，三线数据）

### 一、财报/营收线（🏢概况 / 📉行业地位 / 📊市值股价 / 📈前景）

```bash
# 东财（上市公司必抓：市值/财报/营收/净利/订单/secid 用于 K线）
curl -s -A "Mozilla/5.0 (iPhone)" "https://so.eastmoney.com/web/s?keyword=公司名" | iconv -f gbk -t utf-8

# 百度新闻 m 站（上市/政策/大事件/订单同比）
curl -s -A "Mozilla/5.0 (iPhone; CPU iPhone OS 16_0) AppleWebKit/605.1.4 Mobile/15E148 Safari/604.1" \
  "https://m.baidu.com/s?word=公司名+营收" | iconv -f gbk -t utf-8
```

提取：成立年份、上市时间代码、营收+同比、净利、订单、市占率、收入结构占比、市值、发行价、大事件、总部、员工、创始人。**记下 secid**（港股 116.xxxxx / 沪市 1.xxxxxx / 深市 0.xxxxxx）供 K 线脚本用。

### 二、薪资线（💰薪资福利，核心）

```bash
curl -s -A "Mozilla/5.0 (iPhone)" "https://www.kanzhun.com/search/?query=公司名"   # 看准
curl -s -A "Mozilla/5.0 (iPhone)" "https://m.zhipin.com/waijian/?query=公司名"      # Boss
curl -s -A "Mozilla/5.0 (iPhone)" "https://maimai.cn/web/search_center?type=feed&query=公司名"  # 脉脉
```

提取分档薪资：校招本科/硕士 base、社招 3 年/5-10 年、核心岗、非研发、生产、工人，年终奖月数，五险一金，福利。抓不到用公开已知 + 标「仅供参考」，**不编造、不用存疑词**。

### 三、风评线（😮‍💨公司风评 / 🎯个人发展）

脉脉 + 看准评价区 + 知乎「在 XX 工作是怎样一种体验」。提取：加班文化、工时、管理风格、晋升通道、跳槽认可度。

### 四、最新热点线（📰最近热点，必抓最新，不能用过时信息）

```bash
# 东财股吧资讯列表（最稳，能抓到近 1 周资讯标题）— secid 换成公司代码
# 港股 hk00700 / 沪市 guba,600519 / 深市 guba,000333
curl -sL -A "Mozilla/5.0 (iPhone)" "https://guba.eastmoney.com/list,hk00700.html" -o /tmp/guba.html
# 提取资讯标题：
grep -oE 'data-postid[^>]*>[^<]{8,60}</a>' /tmp/guba.html | sed 's/.*>//'
```

提取近 1-2 月该公司真实热点事件（产品发布/财报/收购/政策/回购/AI 动态），写进 📰 段。**必须用最新信息**，不可用过时或记忆中的旧闻。抓不到则跳过该段，不可编造。东财股吧抓不到时回退百度新闻 m 站（移动 UA）或必应新闻（`curl -sL www.bing.com/news/search?q=公司名`）。

## 九段固定模板（每篇必循此结构，内容每家不同，100 分评分 + 表格 + 图）

### 🏢 公司概况

成立年份 → 主营/产品 → 上市时间代码（未上市写「未上市」）→ 大事件时间线（2-4 节点带年份）→ 最新营收+同比 → 关键人物 → 总部 → 员工规模。段末嵌总部图：

```
![<公司名>总部](inline-hq.jpg)
```

### 📰 最近热点（必抓最新，近 1-2 月真实事件，不可用过时信息）

列 2-3 条该公司**最新**动态（产品/财报/收购/政策/回购/AI 动态），每条带时间，从东财股吧资讯或百度/必应新闻抓。示例：

```
- 腾讯游戏「AI 全家桶」亮相 ChinaJoy 2026（7 月 31 日至 8 月 3 日），体系化探索游戏 AI 落地
- 本届 ChinaJoy 信号：游戏产业回暖，IP 运营与全球化出海成突围关键
- 腾讯持续大额回购（2026 年仍在执行），但股价未同步上涨，市场对回购效果有分歧
```

> 红线：必须最新信息，写前 curl 抓东财股吧资讯确认；抓不到跳过该段，不编造不写过时旧闻。

### 📉 行业地位：XX/100

100 分评分 → 行业排名/梯队 → 市占率（具体%+细分）→ **靠什么赚钱**（用表格列收入结构）→ 现存挑战。

收入结构表格示例：

```
| 业务板块 | 收入 | 占比 |
|----------|------|------|
| 增值服务 | 3200 亿 | 48% |
| 金融科技与企业服务 | 2200 亿 | 33% |
| 网络广告 | 1200 亿 | 18% |
```

### 📊 市值与股价（上市公司贴，未上市跳过）

市值（最新，注明日期）→ 上市发行价 → 至今涨跌倍数 → 嵌 K 线图：

```
![<公司名>成立以来股价走势](kline.jpg)
```

### 💰 薪资福利（研发体系为主）XX/100

**必须用表格 + 列表**，不可一大段流水文。100 分评分。

校招表格：

```
| 档位 | 本科 base | 年包 |
|------|-----------|------|
| 白菜 | 19-22k/月 | 30-50 万 |
| sp | 25-35k/月 | 40-60 万 |
| ssp | 40k+/月 | 60 万+ |
```

社招表格：

```
| 经验 | 普通岗 | 算法/核心岗 |
|------|--------|------------|
| 3 年 | 40-80 万 | 上浮 |
| 5 年 | 80-150 万 | 上浮 |
| 10 年+ | 150-300 万 | 上浮 |
```

福利/年终/涨薪用列表：

```
- 结构：基本 + 月度绩效 + 年终 + 股票 RSU，12 薪，公积金 12%
- 福利：免费三餐、班车、健身房、年度体检、补充医疗、家属医疗、租房补贴、股票激励
- 年终奖：互娱 BG 最高，爆款 6-12 个月，其他 3-6 个月
- 涨薪：年度调薪 + 晋升调薪，4-7 月评审
```

末尾固定：`请注意：以上数据来源于网络公开资料与员工爆料，仅供参考，最准确的信息请以招聘时 HR 提供的最终方案为准。`

### 😮‍💨 公司风评：加班 XX/100

加班 100 分评分 → 研发岗工时（名义 vs 实际，周工时）→ 生产岗（班制+休）→ 企业风评：优势/缺点（用列表分列）→ 固定声明 `请注意：以上信息来源于网友爆料，仅供参考！如有侵权请联系删除！你要是内部的兄弟，评论区补两句真实的，我修正。`

### 📈 前景判断 XX/100

100 分评分 → 国内（押注方向 2-3 个 + 订单/增长信号）→ 海外（区域+体量判断）。

### 🎯 个人发展

技术岗能学什么 → 晋升通道（双通道/导师/轮岗）→ 跳槽认可度 XX/100 + 跳去哪几家被认。

### ✅ 适合 / ❌ 慎重

适合 2-3 类人；慎重 2-3 类人。用列表分列。

### 综合评价 + 互动

一句综合判断 + 固定钩子：`评论区聊聊：下一家想看哪家企业的真实情况？评论区告诉我，马上安排！`

### 免责声明（固定模板照贴，简洁版）

> 免责声明：信息来自网络公开资料与员工爆料，仅供参考，不构成职业选择依据；如有不实或侵权请联系删除修正。


**写作要求**：

- 九段齐全、emoji 段标题 `## 🏢`、段序固定

- 列表/表格用 markdown 语法，html.js 已优化 ul/li 间距（去换行+减 margin，微信无空列表项）
- **💰薪资段必须用表格 + 列表**，不可流水文
- **📉行业地位段收入结构用表格**
- **上市公司贴 📊 市值与股价段 + K 线图**
- 内文嵌公司相关图（总部/产品/股价图），路径写相对 out-dir 文件名
- 100 分评分 5 处（行业地位/薪资/加班/前景/跳槽认可度）
- 数字密度：薪资段 ≥6 区间、行业段 ≥4，全文可查证数字 ≥10，preflight ≥6
