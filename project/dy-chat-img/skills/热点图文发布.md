# 微信公众号热点图文发布 Skill

> 项目根目录：`/Users/zcy1/code_self/AI/project/dy-chat-img`
> 调用方式：用户说「热点图文」「根据热点写文章」「热点推图」等
> 发布类型：微信公众号图文消息（news），带多图推送
> 参考流程：`../wechat/skills/` 选题/AI生成/开局结尾/配图/发布流程

---

## 触发条件

用户想要根据**实时热点**生成一篇**图文消息**并推送到公众号草稿箱，例如：

- 「热点图文」
- 「根据热点写一篇公众号文章」
- 「查热点，写推图文章」
- 「热点 + 图片 + 文章」

---

## 执行流程

触发后按以下顺序执行，**不再问澄清问题**，中途模糊判断（选题、配图、文案角度、标题）自己定。

### 1. 获取实时热点

使用 `curl` 抓取第三方微博热搜归档站点：

```bash
curl -s -L -A "Mozilla/5.0" "https://weibo.zhaoyizhe.com/date/YYYYMMDD/"
```

- 替换 `YYYYMMDD` 为当天日期，如 `20260710`。
- 解析页面中的话题、累计上榜时长、热度值。
- 按热度值降序排列，取 **Top 1** 作为目标热点。

如果归档站点不可用，改用 WebSearch 搜索「YYYYMMDD 微博热搜榜」作为备选。

> 热点选择原则：默认取热度最高；若最高话题明显不适合情感/故事化写作（如纯体育赛果、政策性文件），可顺延到热度前 5 内最适合作图文故事的话题，并在记录中说明。

### 2. 补充热点背景信息

对选定话题做 1-2 次 WebSearch，获取：

- 事件起因、最新进展
- 涉及的人物/地点/数据
- 官方通报或媒体报道

这些信息用于增强文章的真实感和细节。

### 3. 搜索强相关图片

使用 **搜狗图片** 搜索热点关键词，下载 5-8 张有效图片：

```bash
# 示例：台风巴威
python3 search_sogou_images.py "台风巴威 卫星云图"
python3 search_sogou_images.py "台风巴威 路径"
python3 search_sogou_images.py "台风暴雨 城市"
```

图片筛选标准：

- 单张 >30KB
- 与热点主题强相关
- 优先选择新闻现场、卫星云图、数据图、人物场景图
- WebP 格式需用 `sips` 转为 JPEG

### 4. 创建文章包目录

按以下结构创建目录：

```
文章包/YYYYMMDD/NN-文章标题/
├── article.md              ← 文章正文（markdown，备用/审阅）
├── payload_template.json   ← 微信草稿模板（含 {{THUMB}} {{IMG0}} 占位）
├── cover.jpg               ← 封面图
└── img1.jpg ~ imgN.jpg     ← 文中配图
```

示例：

```bash
mkdir -p "文章包/20260710/01-台风巴威又改路线了"
```

### 5. 撰写文章

参考 `../wechat/skills/` 的写文案流程：

- **定位**：情感故事 × 社会热点观察
- **开头**：用 7 种钩子之一（反差动作 / 数字冲击 / 对话切入 / 悬念物件 / 矛盾前置 / 场景特写 / 自我宣言），3 句话内抓住读者
- **正文**：口语化、短句为主、段落长度不规则、禁用 AI 味词汇
- **结尾**：画面定格 / 反问留白 / 循环呼应 / 个人感受 / 戛然而止 / 金句提炼
- **字数**：800-1500 字
- **互动引导**：不写文末「点个在看」，由底部提醒卡片统一处理

文章需将热点事件与普通人视角结合，避免纯新闻播报。

### 6. 生成 payload_template.json

将 article.md 转换为 HTML，并注入：

- 顶部「蓝字关注」横幅（固定样式，文案按主角定制）
- 故事正文（分多个 `<section>`，配图用 `{{IMG0}}` 占位）
- 底部「在看」提醒卡片（固定样式，文案按目标读者定制）

模板字段：

| 占位符 | 含义 |
|---|---|
| `{{THUMB}}` | 封面图 media_id，发布时替换 |
| `{{IMG0}}` | 第 1 张文中配图 URL |
| `{{IMG1}}` | 第 2 张文中配图 URL |
| ... | ... |

### 7. 发布到草稿箱

调用 `../wechat/publish.js`：

```bash
node ../wechat/publish.js "文章包/YYYYMMDD/NN-文章标题"
```

脚本自动完成：获取 token → 上传封面 → 上传文中配图 → 替换占位符 → 创建草稿。

### 8. 记录结果

更新 `发布结果.md`，记录：

- 操作日期
- 热点来源
- 文章标题
- 草稿 media_id
- 封面及配图 media_id / URL

## 关键参数说明

微信公众号图文消息 `draft/add` 接口要点：

| 字段 | 说明 |
|---|---|
| `title` | 文章标题，≤64 字 |
| `digest` | 摘要，≤120 字，显示在转发/列表中 |
| `content` | 正文 HTML，可包含 `<img>` 标签 |
| `thumb_media_id` | 封面图永久素材 media_id |
| `need_open_comment` | 是否开启评论，填 `1` |
| `only_fans_can_comment` | 是否仅粉丝可评论，填 `0` |

图文消息与贴图消息区别：

| | 图文消息 `news` | 图片消息 `newspic` |
|---|---|---|
| 类型 | 普通公众号文章 | 小绿书/贴图 |
| 正文 | 支持 HTML | 纯文本 + `image_info.image_list` |
| 图片位置 | `<img>` 嵌入正文 | 专门的图片列表 |
| 发布脚本 | `../wechat/publish.js` | `post_draft.js` |

## 注意事项

1. **access_token 2 小时有效**：`publish.js` 会自动重新获取，无需手动维护。
2. **封面和配图必须本地上传**：微信要求先上传到素材库，再拿到 media_id / URL。
3. **图文消息用 `uploadimg` 传文中图**：返回 `url` 直接用于 `<img src>`；封面用 `add_material` 传永久素材，返回 `media_id`。
4. **并发问题**：同 AppID 多次获取 token 会互踩，同一批文章串行发布。
5. **图片版权**：搜索图可能涉及版权，正式群发前建议替换为自有图或已授权图。
6. **灾难/敏感热点**：写作时注意分寸，避免消费灾难、造谣传谣、侵犯隐私。
7. **去 AI 味**：参考 `../wechat/skills/02-AI文章生成.md` 禁用词汇与句式清单。
8. **后台确认**：草稿创建成功后，去公众号后台预览确认排版和配图。

---

## 不要做

- 不要把 `article_type` 用于图文消息（那是贴图消息专用）。
- 不要在 `article.md` 末尾写「点个在看」（由底部提醒卡片统一处理）。
- 不要并发发布多篇图文。
- 不要直接用 WebP 或带水印/版权不明的图片。
- 不要把未经核实的热点细节写进文章。
