## 如何发布到公众号

### 方式一：手动复制

1. 打开 [mp.weixin.qq.com](https://mp.weixin.qq.com)
2. 点击「内容与互动」→「草稿箱」→「新建图文消息/图片消息」
3. 选择「图片消息」（即贴图类型）
4. 按 `贴图草稿-20250708.md` 中的顺序上传 7 张图，并粘贴对应配文
5. 设置封面和标题：`夏日限定｜7 件让人瞬间清凉的小事`
6. 保存为草稿，不群发

### 方式二：自动发布（post_draft.js / skill）

已配置 `post_draft.js`，会读取 `贴图草稿-YYYYMMDD.json`，把图片作为永久素材上传，再以 `article_type: "newspic"` 调用微信 `draft/add` 接口创建图片消息草稿。

完整流程见 `skills/贴图发布.md`。

运行：

```bash
node post_draft.js --draft "贴图草稿-20250708.json"
```

注意：
- 需把脚本里的 `ACCESS_TOKEN` 换成当前有效的 access_token。
- 图片消息（newspic）参数结构与普通图文不同，需使用 `image_info.image_list` 传入永久素材 media_id。
