# find-image —— 批量找图

**给什么**：主体词 + 事件词 + 目标张数
**还什么**：图片文件 + `manifest.json`（来源/尺寸/相关性）+ `manifest.md`（人读清单）

原实现三套已经分叉：`wechat-img/find_img.cjs`（489 行）、`event-thread`（504 行）、`company`（105 行）。此原子以 wechat-img 版为基准合成，并修了分叉后暴露的问题。

## 触发

「找图」「配图」「下 20 张图」

## 用法

```bash
# 批量：下 20 张
node atom/find-image/src/index.mjs --subject "全红婵" --event "全运会夺冠" --out-dir input/ --target 20

# 历史事件：关掉新鲜度门（要抓往年旧图）
node atom/find-image/src/index.mjs --subject "某历史事件" --out-dir x/ --history

# 单张（封面兜底）：优先用指定 URL，否则搜第一张
node atom/find-image/src/index.mjs --query "关键词" --url "https://..." --out cover.jpg
node atom/find-image/src/index.mjs --query "关键词" --out cover.jpg
```

| 参数 | 默认 | 说明 |
|---|---|---|
| `--subject` | 必填 | 主体词（人名/机构/地名） |
| `--event` | 空 | 事件词，与主体组成主轴查询 |
| `--out-dir` | 必填 | 输出目录 |
| `--target` | 20 | 目标张数（不保证一定下满） |
| `--history` | 关 | 历史事件模式，不卡新鲜度 |
| `--max-age-months` | 3 | 非历史模式下允许的最大图龄 |

## 输出

`manifest.json`：
```json
{
  "query": { "subject": "全红婵", "event": "全运会夺冠", "target": 20 },
  "count": 20,
  "skipped_no_date": 0,
  "dup_skipped": 1,
  "images": [{
    "file": "001-主图.jpg", "w": 1694, "h": 1008, "ratio": 1.68,
    "title": "...", "source": "图库-必应", "url": "...", "age_months": null
  }]
}
```

主图固定命名 `001-主图.jpg`，其余 `002.jpg` ~ `0NN.jpg`。

## 四渠道

| 渠道 | 特点 | 弱项 |
|---|---|---|
| 必应图库 | 带时间过滤（近 7 天 / 近 24 小时），保新最好 | 可能返回无日期戳的旧图 |
| 搜狗图库 | 补量 | 标题只写「搜狗图库」，判不出相关性 |
| 360 图库 | 带 title + desc，可查相关性 | 有大量素材站水印图 |
| 新闻正文 | 头条搜索「文章标题+配图」配对，标题可用于相关性校验 | 图床偶发 403 |

## 关键机制

**分档下载**：强相关（多实体全含）→ 部分相关 → 新闻，凑够目标即停。

**主体词降级**：整串搜不到就逐级放宽（`洛阳卤蛋店`→`卤蛋店`→`卤蛋`）。判定「可用」必须是**真下到图**，不能只看候选数——新闻候选常因图床 403 全军覆没。

**主图选择**：优先「够宽 + 像素最多」的一张。不能只按比例挑——实测同一新闻会同时出 450x294 横幅缩略图和 956x1594 大图，纯按比例会选中缩略图当封面。

**内容级去重**（2026-10-29 修复）：不同 URL 可能指向同一张图（实测必应 009/019 字节全同）。原先只用 URL 指纹挡不住，现在下载后按 SHA1 再挡一次。修完实测 20 张 0 重复。

## 已知坑

1. **短队名跨分部误伤**：2 字母级实体（如 `AL`）单用会 70% 误伤，多实体全含也挡不住。**必须逐张 Read 审计后再交用户**
2. **具体案件无现场图**：社会案件、远海事故的当事现场图客观搜不到，必应泛词和新闻源都只返示意图/缩略小图。走场景图 + 写实 alt
3. **官方海报常优于现场图**——尤其体育、时政类
4. **下载的 jpg 可能是 WebP/PNG 假壳**——本原子已统一转标准 JPEG，但 `wechat-draft` 仍会因格式问题报 40137 时，用 `img-normalize --check-dir` 复查
5. **素材站水印图**：699pic/摄图网/包图网等有黑名单过滤，但新站会漏

## 已验证

- `全红婵 + 全运会夺冠`：20 张，无重复，格式全为标准 JPEG
- 修复前同一批出现 009/019 字节级重复（97829 bytes 完全相同）
