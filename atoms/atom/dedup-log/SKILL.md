# dedup-log —— 写作维度避撞

**给什么**：历史日志目录 + 篇数 N
**还什么**：近 N 篇各维度已用值、扎堆项、本篇应排除的值

原实现是 `logdims.js`（解析）+ `recent.js`（渲染）两套，且**各写一套正则解析同一份日志**，格式一变就双双静默失效（2026-08 实况）。此原子合一，并把日志目录参数化。

## 触发

「看看最近写过啥」「避撞」「轮换维度」

## 用法

```bash
# 读近 5 篇，输出结构化避撞清单
node atom/dedup-log/src/index.mjs --logs <日志目录> --n 5

# 同时落 result.json + prompt.md（prompt.md 可直接拼进写作 prompt）
node atom/dedup-log/src/index.mjs --logs <目录> --n 5 --out-dir 03-dedup-log

# 只输出各维度的排除值（最小 JSON，recipe 拼参数用）
node atom/dedup-log/src/index.mjs --logs <目录> --exclude-only

# 把本篇实际所用维度写回日志
node atom/dedup-log/src/index.mjs --logs <目录> --append dims.json
```

`dims.json` 形状：
```json
{
  "date": "2026-10-28", "no": 3, "title": "文章标题",
  "dims": { "theme": "ocean", "收口骨架": "4-数字定格", "切入角度": "13-代价账" },
  "note": "备注"
}
```

## 14 个维度

`title_style`（标题骨架）`收口骨架` `开头骨架` `收口方式` `收口句式` `开头钩子` `结构配方` `叙事口吻` `切入角度` `段间衔接` `格式组合` `cover_style`（封面布局）`theme`（排版）`口头禅`

## 输出要点

| 字段 | 说明 |
|---|---|
| `dims.<维度>.used` | 近 N 篇用过的值（带文章编号） |
| `dims.<维度>.crowded` | 同值出现 ≥2 次 = 已扎堆，本篇**必须**换 |
| `dims.<维度>.exclude` | 本篇应排除的值（去编号的名字列表） |
| `title_words.duplicated` | 标题原词撞车（2026-08-27 起标题用热榜原词） |
| `emotion_tail.over_limit` | 近 N 篇 ≥2 篇用「我X了」情绪尾 = 本周超限 |
| `coverage_warnings` | 日志漏写维度告警——**不处理会让轮换静默失效** |

## 两代日志格式

| 格式 | 时间 | 形态 |
|---|---|---|
| A | ~2026-08-20 | `- 收口方式记录(供下批避撞)：38-2 追问留白式。`（机读行自带编号） |
| B | 2026-08-27~ | `## 06 \| 标题` 分节内 `- 收口方式：2-警示反思式`（编号在分节标题） |

两代都兼容，无需迁移旧日志。

## 追加的四个保证

1. **幂等**：同一篇重复追加 = `no-change`，不产生重复行
2. **不覆盖**：已写的维度行绝不改写（历史日志是避撞唯一依据，写坏=轮换失效）
3. **只补缺**：缺哪维补哪维，`dims-filled` 并报告补了几行
4. **尾巴段保护**：日志末尾常有 `## 顺延次日候选` 这类非文章段，新分节必须插在它**之前**

## 回归

```bash
node atom/dedup-log/fixtures/regression.mjs
```

16 条断言，覆盖解析/扎堆/情绪尾/prompt 渲染/追加幂等/不覆盖/尾巴段插入。不依赖外部目录。

与源 `recent.js` 在 n=3/5/10/20 下输出**逐字符一致**（已对比验证）。

## 已知坑

1. **日志漏写维度**：解析结果里该维为空，轮换会退化成随机。`coverage_warnings` 就是这个告警，别忽略
2. **封面布局重复不告警**：2026-08-27 起固定 `plain`，重复属预期
3. 日志文件名必须 `YYYY-MM-DD.md`，其它名字会被跳过
