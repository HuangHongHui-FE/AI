# 朱雀改写规则（17 份实测报告提炼）

配套样本全文见 `zhuque-samples.md`。**改稿前先读这一页。**

## 一句话结论

朱雀抓的是**「这段叙述是不是被生成出来的」**，不是词汇像不像 AI。
口语化、第一人称、场景描写、堆细节——单独用都过不了。真正有效的是**去掉叙述框架，把稿子写平**。

## 计分方式（2026-11-05 实测补充）

朱雀的总分是**分段按字符数加权平均**，不是取最差分。

- 755 字的稿子被切成 264 字 + 491 字两段，AIGC 分别是 0.5426 / 0.3988，整体 0.449 → 判人工
- 但余量只剩 0.05。**只要有一段落进「疑似 AI」区间，整体就在红线边上**

所以改稿的目标不是「平均分低」，是**没有任何一段单独超过 0.5**。场景化开场最容易单独超标。

## 分档

| AIGC | 档位 | 能不能发 |
|---|---|---|
| 0 – 0.5 | 人工特征 | 能过 |
| 0.5 – 0.99 | 疑似 AI | 过不了 |
| 0.99 – 1 | AI 特征 | 明确判 AI |

## 能过的写法（按效果排序）

1. **按时间/事件顺序平铺**：`第18分钟，福法纳横传，马亚推射，1-0。` 一件事一句，不要合并、不要提炼。
2. **只写发生了什么，不写意味着什么**：不解释原因、不做因果归纳、不升华。
3. **观点一律标出处**：`希勒说得直接：…` `据《都灵体育报》报道…` `据 Opta 统计…` `据新华社电…`
4. **短句 + 直陈**：主谓宾，少用「把/被/让」套娃句，少用从句。
5. **允许流水账感**：直播吧式快讯 0.0007，是全部样本里最低的。
6. **数字直接放句中**：观众 62356 人、17 场只输 1 场、第 127 胜。
7. **结尾停在最后一个事实**：不总结、不展望、不抒情。

## 会判 AI 的写法（实测全部失败）

| 写法 | 实测 AIGC | 为什么 |
|---|---|---|
| 口语化：一闷棍、一边倒、走流程 | 0.8752 | 换词不换结构，生成感还在 |
| 第一人称：我回看了两遍 | 0.6818 | 人称不改变叙述框架 |
| 场景化：声音一下子提上去 | 0.7027 | 细节是「写」出来的，不是「记」下来的 |
| 作者提炼：体系依赖、结构性损耗、天平倾斜 | 0.7198 | 这是模型最典型的总结腔 |
| 正式分析：耻辱性出局、肾上腺素反弹、风格克制 | 0.9748 | 抽象名词 + 因果链，最像 AI |
| 小标题 + 社会评论 + 抒情结尾 | 0.8379 | 深度稿结构本身就是 AI 特征 |
| 信息极全 + 小标题 + 评论收束 | 0.9937 | 细节再多也救不了框架 |
| 纯事实后加一句评论/背景 | 0.8814 | 同一篇纯事实是 0.1912 |

## 改写动作（按优先级，改完再复检）

0. **先拆最像 AI 的那一段**：按段落估分，找出场景化/提炼最多的一段（通常是开头），单独重写。整体分是加权平均，压住最高那段比全文微调更有效

1. **删提炼句**：`这说明 / 这意味着 / 暴露的是 / 指向的是 / 更关键的是 / 更麻烦的是 / 真正的问题是 / 本质上 / 说到底 / 这背后`
2. **删比喻和情绪化判断**：`一闷棍 / 一边倒 / 走流程 / 天平倾斜 / 肾上腺素 / 势头断掉 / 撑不住 / 炸了`
3. **拆因果链**：把「因为 A，所以 B，这说明 C」拆成「A。B。」，C 直接删。
4. **观点改引语**：作者判断 → `某人说 / 据某媒体报道 / 据某统计`。
5. **删小标题和分组**：深度稿的分节、总结段、金句收尾，全部去掉，改成按时间顺序的段落。
6. **删结尾升华**：停在最后一个事实或最后一句引语上。
7. **保留事实、数字、人名、队名、时间、引号原话**——这些不能动。

## 按文体怎么用

- **新闻 / 热点 / 赛事**：直接用「通稿体」——时间 + 事件 + 数据 + 引语。样本里 0.0007–0.13 全是这个写法。
- **人物 / 深度稿**：不能写成通稿，但同样要删掉作者的提炼和升华；把判断交给当事人原话，把结构交给时间线。
- **小说 / 故事**：这批样本不适用「通稿体」，但通用信号仍成立——少用总结腔、少用比喻堆、少用「不是 X 而是 Y」；场景要写成动作和对话，不要写成氛围描写。

## 常见误区

- **误区：加细节就能过。** 15.pdf 细节最多，0.9937。
- **误区：口语化就能过。** 2.pdf 通篇口语，0.8752。
- **误区：第一人称就像人写。** 3.pdf 第一人称，0.6818。
- **误区：写得「好」就能过。** 13.pdf 是全部样本里文学性最强的，0.8379。
- **误区：用了小标题就必死。** 21.pdf 用了 2 个 `###` 小标题，全文 0.0530。拉分的是段落里的作者提炼，不是标题本身。
- **误区：场景化开场显得真实。** 20.pdf 开头逐帧复刻首相弯腰的动作，那一段 0.5426，是全篇唯一超标的一段；改成时间地点直接进事，可降到 0.05 一档。
- **正解：写得「平」才能过。** 17.pdf 几乎像一份赛事记录，0.0226；21.pdf 通稿体全文 0.0530。

## 使用方式

改写时不要一次性重写全文，按这个顺序：

1. 先跑 `ai-flavor` 拿本地分和 `hits[].advice`
2. 读本文件的「改写动作」，按优先级逐条处理
3. 再跑 `ai-flavor`，到 `low` 为止
4. 贴朱雀实测；结果用 `--feedback` 回填

本地规则分和朱雀不是同一套模型。本地 `low` 只说明「明显 AI 特征基本清掉了」，最终以朱雀为准。
