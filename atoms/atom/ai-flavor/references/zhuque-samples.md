## 三、最关键的几组对照

### 1. 同一篇事实：纯罗列 vs 加一句评论

- 16.pdf 段2：纯事实 → **0.1912（人工）**
- 18.pdf 段2：同样的开头，后面加「上观新闻评论 + 热度下降 + 文艺表演」→ **0.8814（疑似）**

结论：**加评论、加背景分析、加因果解释，会把一篇能过的稿子直接推成 AI。**

### 2. 同一场比赛：四种「更像人」的改法全部失败

| 改法 | AIGC |
|---|---|
| 原正式稿 | 0.8116 |
| 口语化（一闷棍、一边倒、走流程） | 0.8752 |
| 第一人称（我回看了两遍） | 0.6818 |
| 场景化（声音提了上去、笑容没挂多久） | 0.7027 |
| **直播吧流水账** | **0.0007** |

结论：**口语化、第一人称、场景描写单独用都没用**。朱雀抓的不是「有没有人味」，而是「这段叙述是不是被生成出来的」。

### 3. 信息量不是护身符

- 15.pdf 段1：信息最全、细节最多 → **0.9937（AI 特征）**
- 17.pdf：同一件事压成平铺直叙 → **0.0226（人工）**

结论：**堆细节不能过检测，去掉叙述框架才能。**

### 4. 观点不是不能写，要标出处

- 10.pdf / 12.pdf 里有大量判断和预测，但全部是「希勒说得直接」「据《都灵体育报》报道」「据 Opta 统计」「本场看好」——**0.13 / 0.0128，能过**。
- 1.pdf / 4.pdf 的判断是作者自己提炼的——「体系依赖」「结构性损耗」「风格层面的克制」——**0.72 / 0.97，过不了**。

结论：**可以写观点，但要写成「某人/某机构说的」，不要写成作者自己的提炼。**

# 第二批：本仓库实写稿（2026-11-05）

来源：`朱雀AI检测助手 20.pdf` / `21.pdf`，是 `ai-flavor` 规则改写后实写的两篇公众号稿。
这是第一批样本（体育稿）之外，**第一次用本原子的写法实测**。

## 评分总表

| 文件 | 篇幅 | AIGC | 档位 | 对应文章 |
|---|---|---|---|---|
| 21.pdf | 713 字 | **0.0530** | 人工（很干净） | 红军为什么必须过草地 |
| 20.pdf 段1 | 264 字 | 0.5426 | **疑似 AI** | 高市早苗（开头：现场场景） |
| 20.pdf 段2 | 491 字 | 0.3988 | 人工 | 高市早苗（后半：事实 + 引语） |
| 20.pdf 整体 | 755 字 | **≈0.449**（加权） | 人工（擦边过） | 高市早苗 |

**关键：朱雀的总分不是最大值，是分段按字符数加权平均。**
20.pdf 有一段 0.54（疑似），但另一段 0.40 把总分拉到 0.449，整体仍判人工。

>

>

> 一篇流传较广的分析把这件事说得很直白：草地从来不是选项之一，它是其他选项全部作废之后剩下的那一个。

>

**它做错的事**：有 2 个三级标题（结构分节）；有「不是勋章给了谁，而是首相的动作」（禁飞骨架，实测量化下来只拉高一点点，没致命）；有「在这套仪式里，视线本身就是流程的一部分」（作者提炼）。
**它做对的事**：大量引语署源、句子短、结尾停在引语上。

## 两批合起来的结论

1. **总分是分段加权平均**，不是最差分。一段 0.54 可以被另一段 0.40 摊平到 0.449 过线，但余量只剩 0.05。
2. **场景化开场仍是最高分段落**。同样是本仓库写的稿，开场写场景的那篇片段 1 = 0.54，开场写时间地点的那篇全文 = 0.053。
3. **小标题不是必死**：21.pdf 用了 2 个 `###` 小标题，全文 0.0530。真正拉分的是「段落里有没有作者提炼」，不是有没有标题。
4. **单句禁飞骨架（不是X而是Y）不会单独致命**，但在已经擦边的稿子里会吃掉最后的余量。
5. **通稿体写法可以压到 0.05**：时间 + 事件 + 数字 + 引语 + 停在具体画面，是目前实测最低的一档。
